# METHOD_DECISIONS.md — 手法決定の正本(現行=正 / 廃止=失敗 の対照表)

このファイルは、パイプラインの各要素について **確定した正しい手法** と **廃止した失敗手法** を
**対で** 記録する正本である。目的は、旧補助関数の無監査流用による **失敗手法の再混入を防ぐ** こと。

**新規スクリプト作成・既存関数流用の前に必ずこの表と照合する。** 「現行」でない手法を書いたら差し戻し。
[.dev/FORBIDDEN.md](FORBIDDEN.md)(応急処置の禁止リスト)と役割分担: こちらは「手法選択」、FORBIDDENは「症状隠し対処」。

再混入を繰り返した経緯(2026-07-19、ユーザー指摘): 立体角1°固定・算術平均エネルギー・固定矩形バブル等が、
修正済みのはずが古い補助関数に残存し流用で復活。**これは重大な品質欠陥**(誤った結果・結論に直結)として重く扱う。

### Loop I 模型の出典確認 (2026-07-23)

`ref/ackermann2014_fermi_bubbles_1407.7905.pdf` 原文を確認した結果:

- **本実装のシェル値は Ackermann+2014 と完全一致**:
  ℓ1=341°, b1=3°, d1=78 pc, r_in,1=62 pc, r_out,1=81 pc /
  ℓ2=332°, b2=37°, d2=95 pc, r_in,2=58 pc, r_out,2=82 pc。**実装は正しい**
- Ackermann は「視線積分のため、一様輝度の2球殻は縁がぼやけた非一様な見え方になる」と明記。
  本実装で shell1 が ROI 全域を覆うのは、**この模型が持つ性質**であって実装の誤りではない
- **[重要な文脈] Ackermann の baseline は Haslam 408 MHz 電波地図の楕円領域**であり、
  幾何2シェル模型は**系統誤差評価用の代替**と位置づけられている。
  Totani §2.3 は幾何模型のほうを採用しているので、**本研究も幾何模型に従う**(論文再現のため)。
  Haslam 版に差し替えるのは Totani からの逸脱になるので**行わない**
