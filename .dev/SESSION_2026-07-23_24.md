## 0. 結論(先頭)

**低エネルギー(1.5〜4.3 GeV)で等方成分が Totani の 1/200 に潰れる問題の原因を、
対照実験により「ICS 成分に由来する緯度形状の不整合」と特定した。**

同じ自由度(緯度 5 帯、追加 +4 パラメータ)を各成分に与える対照実験で、
**ICS に与えたときだけ等方成分が Totani 値と一致するところまで回復する**:

| 自由度を与えた成分 | iso/Totani (Bin1) | ΔlnL | iso/Totani (Bin2) | ΔlnL |
|---|---|---|---|---|
| なし (基準) | 0.000 | 0.0 | 0.000 | 0.0 |
| **ICS** | **1.059** | +120.0 | **0.821** | +61.1 |
| バブル正 | 0.000 | **+229.1** | 0.000 | +47.5 |
| Loop I | 0.189 | +85.4 | 0.000 | +57.6 |
| gas | 0.000 | +39.1 | 0.000 | +31.5 |
| 点源 | 0.000 | +32.9 | 0.000 | +24.6 |

**バブルは当てはまり (ΔlnL) では ICS を上回るのに、等方成分を戻さない。** これが決め手。

**ICS にだけ効く galdef の変更が実在する**: `ISRF_healpixOrder` が canonical の 1 から
**3** に変更されている。ISRF は逆コンプトン計算にしか使われないため、
**ICS の緯度形状に影響しうる唯一の実質的変更**である。検証には GALPROP の再計算が必要だが
webrun 停止中のため不可。

## 2. 直した実バグ (このセッションで発見)

1. **NFW 規格化の基準点** — `argmax(|B_C|)` = ROI 内最高緯度画素 (b=−59.94°) で代用していた。

   `_clean_boundary()` で南北 1 つずつに整形。矩形内割合 57.5%→61.4% (目標 60% を初突破)

   機械読み取り (`digitize_totani_fig6.py` → `_v2.py`) に置換
4. **`audit_fn.py` が v13 をハードコード** — 「版を更新するたびに実行」が常に v13 を見ていた
5. **成分 overlay 図が最大の食い違いをフレーム外に追い出していた** —
   iso 比 0.005 も、負の halo も、線が消えていた
6. **図の線が途中で切れていた** — 参照値の高E 側が未入力だった

## 4. 自己訂正の記録 (誤った主張と、その訂正)

1. **「バブル画像を counts のまま平滑化していたので cos(b) の傾きで歪む」** →
   実測で**効果ゼロ**。σ=1° に対し露出+立体角の傾きが 1.5%/deg と緩いため
2. **「iso と Loop I は分離できないので合算して比較すべき」** →
   **再現を掲げる以上、論文に無い比較単位を独自に作ってはいけない**(ユーザ指摘)。撤回し参考値に降格
3. **「Loop I を外すと iso が 300 倍になる = 縮退の証拠」** →
   **似た形の片方を外せば他方が肩代わりするのは当たり前**(ユーザ指摘)。論証として不成立
4. **「高E のずれは全部 GALPROP のせい」** →
   10・11 ビン目のずれは**私の読み取り誤差**だった
5. **「高E は誤差棒が広くて読み取れない」** →
   **言い訳だった**(ユーザ指摘)。行ごとの横幅でマーカーと誤差棒を分離すれば読める
6. **「本研究の ICS は Totani より平坦」** →
   バージョン・galdef・ISRF が同一なら**テンプレートは同一のはず**。
   この主張は **Totani の f_ics≈1 という未検証の仮定**に依存していた
7. **「GALPROP が標準設定と分かったので、違うのはバブルしかない」** →
   **推論で乗り換えた**のが誤り。対照実験を取ったら**バブルは iso を戻さない**と判明

## 6. GALPROP の素性 (`ref/galprop_webrun_10050003/` から特定)

- **galdef `SLZ6R30T150C2`** — Title・r_max=30・z_max=6・IC_isotropic=1・

- **エネルギー面の選択は正しい**: ネイティブ格子が Totani ビン中心と **0.1% で一致**
- **gas ファイルは完全**: `pi0_decay_healpix` / `bremss_healpix` は全 17 リング・

## 9. 卒論に書ける形 (現時点)

> 全成分の合計は Totani と 0.5〜10% で一致し、20 GeV のハロー超過も比 1.16 で再現できている。
> 低エネルギーで halo が負になる点も Totani の baseline と一致する。
> ただし等方成分のみ Totani の 1/200 に潰れる。対照実験により、これは **ICS 成分に由来する
> 緯度形状の不整合**と特定した。同じ自由度を他のどの成分 (フェルミバブル・gas・Loop I・点源・
> 露出) に与えても等方成分は回復せず、**ICS に与えたときのみ Totani 値と一致する**
> (ΔlnL +120.0、iso 比 0.000 → 1.059)。使用した GALPROP 出力は `ISRF_healpixOrder` が
> 標準値 1 から 3 に変更されており、ISRF は逆コンプトン計算にのみ用いられるため、
> これが ICS 形状差の候補である。GALPROP webrun 停止中のため再計算による検証はできない。
> **なお 20 GeV の主結果はこの問題の影響を受けない** (バブルテンプレートを丸ごと外しても
> f_halo は基準比 0.88〜1.61 倍の範囲)。
