# Cross-Review: Numerical on Physical (iter 001)

対象: `review-physical.md` を数値専門の観点から検証。
参照実装: `code/mcmc_fit_all_bins.py`（`log_prior:238-249`, `_multistart_minimize:266-295`,
`fit_one_bin:298-357`、特に有意度計算 `:334-339`）。

総括: 物理レビュアの C-1（f_halo 非負化 + Chernoff 境界補正）は数値実装として妥当かつ実装は容易。
ただし **f_halo≥0 制約だけでは私が C-1/C-2/I-3 で示した収束不安定性は解消しない**。順序を誤ると
「見かけ上きれいな 0σ」という新たなアーティファクトを生むため、収束修正を先に置くべき。

## 物理レビュア指摘への補足（補強）

### [P C-1 補強] Chernoff 境界補正は数値的に正当。ただし実装の半分は既に存在する
- 物理レビュアの `sig = sqrt(2·max(ΔlnL,0))` を「f_halo_MLE>0 のときのみ非ゼロ」とする処方は、
  Chernoff (1954) / Cowan et al. (2011, EPJC 71:1554) の漸近公式 Z=√q₀（検定統計量
  q が 0.5·δ(0)+0.5·χ²₁ の半カイ二乗混合に従う境界ケース）と一致する。数値的に正しい。
- **重要な実装上の事実**: 現行コード `:339` は既に `significance = sqrt(2·max(delta_lnL,0))` で、
  さらに `:334-336` で `lnL_with < lnL_noh` のとき best を no-halo 解に戻し `delta_lnL=0` に
  フロアしている。つまり「境界 MLE で 0σ」の骨格は**構造的に既に入っている**。欠けているのは
  「f_halo が符号自由なので lnL_with が負側でも最大化されてしまう」点だけ。
- したがって物理レビュアの修正は**新しい分岐を足す必要はない**。`neg_ll`（`:324-327`）と
  `log_prior`（`:238-249`）に f_halo≥0 を課すだけで、非制約 MLE が負のビンでは制約 MLE が
  f_halo=0 に貼り付き、lnL_with = lnL_noh → ΔlnL=0 → Z=0 が**自動的に**出る。これがまさに
  Chernoff の境界ケースそのもので、`:334-336` の既存フロアと二重に整合する。
- **実装上の index 注意（silent バグ源）**: 非負ガードは現状 `p[:5]`（`:317`, `:325`）。
  f_fb_neg は index 5、f_halo は index 6。f_halo だけ足すので `p[:5]` かつ `p[6]≥0` とすること。
  誤って `p[:6]` にすると符号自由であるべき f_fb_neg まで非負化してしまい、`p[:7]` にすると
  f_fb_neg を巻き込む。`log_prior:245` の `[f_gas,f_ics,f_la,f_lb,f_fb]` リストにも f_halo を
  追加（f_fb_neg は入れない）。

### [P C-1 補強] 境界 MLE では emcee 事後の誤差棒が無効化する
- f_halo≥0 を課すと、非制約 MLE が負のビンで事後分布は f_halo=0 の壁で truncate される。
  Wilks/Fisher 情報量に基づく対称誤差棒は境界で成立しない（Chernoff の半分布と同根の理由）。
  `:348-349` の median / 16-84%ile は壁際に walker が堆積して**下側に偏る**。
- さらに walker 初期化 `:342-343` は `pos[:, :5]=np.abs(...)` で先頭5成分のみ非負化しており、
  f_halo（index 6）は best（負値）近傍から出発する。f_halo≥0 prior を入れるなら walker 初期化も
  f_halo≥0 にしないと、全 walker が prior 壁に押し付けられて stuck し、事後が壁に貼り付く。
  → f_halo 事後は「区間」ではなく上限（例 95% 片側 upper limit）として報告するのが数値的に正しい。

## 物理レビュアの見落とし候補（数値観点で重要）

### [N-1] 「再走後 f_halo=-173 と 90σ は消えるはず」（P C-1 step 3）は**部分的にしか成立しない**
- 物理レビュアの予測は「符号を封じれば非物理値は消える」だが、私が C-1/C-2 で定量化した
  不安定性の機構は**符号ではなく収束**にある。f_halo≥0 制約は以下に一切触れない:
  1. **no-halo 側 6D 最適化の未収束**（C-1）。ΔlnL の分母 lnL_noh は f_halo を含まない
     独立最適化（`:321`）で、Bin1 では n=100 でも lnL_noh が単調改善中（未プラトー）。
     f_halo に何の制約を課しても lnL_noh は変わらないので、**ΔlnL 水増しは残る**。
  2. **`np.abs()` 強制正値化バグ**（I-3, `:290`,`:343`）。restart 初期点と walker 初期化が
     全座標を正に潰す。f_halo≥0 なら f_halo にとっては結果的に無害化するが、**符号自由な
     f_fb_neg（index 5）は依然 negative 領域を探索できない**。残差吸収がここへ移るだけ。
- **具体的帰結（重要）**: f_halo≥0 制約を入れると Bin1 の非制約 MLE（-0.11〜-216 で振れる）は
  全て 0 にクリップされ ΔlnL=0 → 0σ になる。物理レビュアはこれを「クリーンな null」と読むだろうが、
  数値的にはこれは**探索不足の null**であって「DM 不在の証拠」ではない。abs バグで正側 f_halo を
  ほぼ探索しておらず、no-halo 始点が支配するため、正の f_halo ベイスンを見逃している可能性がある。
  「Bin1 が 0σ」は収束・広域探索を直した後でなければ物理的 null と解釈してはならない。
- **一方 Bin6（f_halo=2.53, 非制約 MLE が正）では f_halo≥0 制約は有意度を全く変えない**。
  Bin6 は 18.70σ(n=30)→17.57σ(n=100) と no-halo 未収束で依然 ±数σ 振れる（C-1）。
  つまり f_halo≥0 で消えるのは「負 MLE ビンの水増し」だけで、**正 MLE ビンの水増しは無傷で残る**。
  物理レビュアの「まずこれで切り分ける」は、正 MLE ビンには切り分け効果がない。

### [N-2] Chernoff 補正は「収束した ΔlnL」にのみ統計的妥当性を持つ（適用順序の見落とし）
- Chernoff (1954) の半カイ二乗分布は、lnL_with・lnL_noh が**それぞれ真のグローバル最適**である
  ことを前提とする漸近論。現行のように lnL_noh が未収束（C-1）だと、境界補正を**間違った ΔlnL に
  適用する**ことになり、Z の数値は依然無意味。物理レビュアの C-1 修正（prior）と I-3 依頼
  （no-halo 収束）は**独立な前提条件ではなく、後者が前者の妥当性の必要条件**。
  順序を明示すべき: (1) abs バグ撤廃 + no-halo プラトー検証 → (2) f_halo≥0 + Chernoff。
  逆順だと (2) が数値的に空回りする。

### [N-3] emcee 非再現性（I-1 in numerical review）が物理レビュアの検証自体を揺るがす
- 物理レビュアは f_ics のビン間挙動 `0.91,...,0.009,...,11.6`（P I-1）を「erratic ＝ ICS 未制約の
  証拠」と読むが、`main()` が `np.random.seed` を設定せず（私の I-1）、walker 初期化 `:342` と
  emcee 内部 RNG がグローバル状態依存のため、**この f_ics 系列自体が実行ごとに変わる**。
  「erratic さ」の一部は物理的な ICS 縮退ではなく再現性欠如由来の可能性がある。seed 固定で
  再走しない限り、f_ics 系列を物理的証拠として使うのは危険。

## 反証（物理指摘だが数値観点では問題なし / 優先度が違う）

### [反証 P I-1] 「ICS↔halo 縮退が halo 振幅を暴走させる」— 条件数 3.5 では 2000× 振れは説明不能
- 物理レビュアは ics-halo Pearson r=0.747、5テンプレート条件数 ~3.5 を「中程度の縮退」とし、
  これが f_halo 暴走の二次原因とする。**縮退が存在すること自体は私も追認**（gas/ics r≈0.70）。
- しかし数値的に、**条件数 3.5 の線形問題は入力ノイズを高々 ~3.5 倍しか増幅しない**。私が C-2 で
  観測した f_halo 点推定の -0.11〜-216（約 2000× レンジ）は、条件数 3.5 では**桁で説明不能**。
  2000× は線形 ill-conditioning の症状ではなく、**平坦・多峰の尤度 + Nelder-Mead の収束失敗**
  （abs バグで負領域未探索、乗法散布 `x0·(1+U(-1,3))` が x0 に錨づけ、I-3）の症状。
- したがって「縮退が暴走の主因」という因果づけは数値観点から**反証**する。主因は最適化の
  非収束であり、縮退は「平坦方向を提供する舞台」ではあるが**振れ幅 2000× の直接原因ではない**。
  → 実務的含意: f_gas/f_ics に情報 prior を課す（P I-1 推奨）だけでは 2000× 振れは止まらない。
  先に I-3（abs 撤廃・広域散布）と C-1（no-halo 収束）を直すべき。優先度は prior 追加より上。

### [反証 P S-2] NFW 校正の緯度不一致（b=90° vs |b|≈59.5°）は収束・有意度に無影響
- 物理レビュアは `calibrate_nfw_norm` の基準緯度不一致を「f_halo 絶対値の意味づけに効く」とする。
  物理的解釈としては正しいが、**数値観点では halo テンプレート全体の定数リスケール**にすぎず、
  ΔlnL・有意度・seed 依存性・条件数のいずれにも影響しない（f_halo が逆比例で吸収）。
  今回の不安定性問題とは直交する。物理解釈フェーズまで後回しで数値的リスクなし、という
  物理レビュアの「スコープ外」判断を**数値観点から追認**する（優先度は最下位で正しい）。

### [追認 P I-2] gas:ICS 比 0.75 でテンプレート健全 — 数値側も一致
- 反証ではなく追認。私の `gas_ics_correlation.json`（NaN=0・負値=0、r≈0.70）と物理レビュアの
  ics/gas=0.75 は独立に整合。テンプレート生成に数値バグなし。破綻の主因は分離テンプレートでは
  なくフィット側（収束 + 符号自由度）という両レビュアの結論は一致している。

## Manager への要点（数値クロス観点）

1. 物理 C-1（f_halo≥0 + Chernoff）は数値実装として妥当・容易。既存 `:334-339` のフロアと
   二重整合し、新分岐不要。ただし index は `p[:5] & p[6]`（f_fb_neg を巻き込まない）。
2. **順序が critical**: f_halo≥0 prior は私の C-1（no-halo 未収束）・I-3（abs バグ）を解決しない。
   Chernoff 補正は収束した ΔlnL にのみ妥当。修正順は (1) abs 撤廃 + no-halo プラトー検証 →
   (2) f_halo≥0 + Chernoff。逆順は数値的に空回り。
3. 物理予測「90σ は消えるはず」は**負 MLE ビンでのみ成立**。正 MLE ビン（Bin6 等）の
   no-halo 未収束由来の水増しは f_halo≥0 では消えない。
4. 「縮退が halo 暴走の主因」は反証。条件数 3.5 では 2000× 振れは説明不能。主因は最適化非収束。
   f_gas/f_ics prior より I-3/C-1 修正が優先。
