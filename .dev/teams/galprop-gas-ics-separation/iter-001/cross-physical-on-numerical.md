# Cross-Review: Physical on Numerical (iter 001)

## 総括（結論先頭）

数値レビュアの「有意度が n_restarts/seed で桁レベル未収束」「np.abs() が符号自由パラメータの
restart 探索を壊す」は物理観点からも全面的に妥当で、私の物理指摘（f_halo 符号自由、ICS↔halo 縮退）
と**同一の根から出た表裏の症状**である。両者は加法的ではなく**乗法的に悪化**する（下記補足 P-1）。
一方、数値レビュアの提案する修正群には NFW 校正・Totani 手法整合性への副作用リスクがあり（P-4, P-5）、
また一部（restart プラトー検証の厳格義務化・チェイン長）は根本修正後には過剰要求になりうる（反証 R-1, R-2）。

## 数値レビュア指摘への補足（物理的根本原因）

### P-1. なぜ符号自由 f_halo が np.abs() バグの破壊力を増幅するか（最重要の因果連結）
数値レビュア [I-3] の指摘（`:290 start = np.abs(start)` が符号自由方向を探索しない）と、
私の [C-1]（f_halo 非負性違反）は**同一バグの2つの側面**である。因果連鎖:

1. 物理的に DM ハローは ∝ρ²（annihilation）または ∝ρ（decay）で J-map 全域 ≥0、
   よって f_halo≥0 が必須。しかし `log_prior:245` の非負制約は先頭5パラメータのみで、
   **f_halo に符号自由という物理的に禁じられた「負ハロー基底」を開放**している。
2. この負領域は、ICS↔halo の中程度空間縮退（Pearson r(ics,halo)=0.747, R²(halo|gas,ics)=0.57）
   により **「大きな正 ICS − 大きな負 halo」で相殺してモデル残差を吸える方向**になっている。
   尤度面はこの縮退方向にほぼ平坦（数値レビュア [C-2]: f_halo が −0.11〜−216 で 2000 倍振れ、
   emcee walker std=5.8 の「見かけの精度」）。真の最適解はこの禁制の負基底に滑り落ちる。
3. ここで `np.abs(start):290` は restart 初期点を**正象限のみ**に閉じ込める。
   最適解が f_halo≈−170 にあるのに、restart は負領域を1点もカバーせず、Nelder-Mead の
   谷下り任せになる → seed/restart 依存の桁揺れ（数値レビュア [C-1][C-2] の機構的原因）。

**核心（なぜ乗法的か）**: np.abs バグが**届かない領域**（負側）と、符号自由 prior が**誤って開いた領域**
（負側）が**完全に一致**している。もし f_halo≥0 を課せば（私の [C-1]）、禁制の負基底は prior で
枝刈りされ、真の最適解は「np.abs が正しくサンプルできる正象限」に戻る。すると np.abs バグは
f_halo に関して**ほぼ無害化**する。逆に符号自由を放置したまま np.abs だけ直しても、今度は
物理的に無意味な f_halo=−173 を**よく収束して**返すだけで σ 過大評価は残る。
→ 両修正は独立に効かない。**「f_halo≥0 制約」と「np.abs 撤廃」は同時適用が必須**。

### P-2. no-halo 側（6D）が n=100 でも未収束な物理的理由
数値レビュア [C-1] の「Bin1 lnL_nohalo が単調改善し続けプラトー未到達」は、no-halo モデルに残る
**もう1つの符号自由パラメータ f_fb_neg**（バブル負テンプレート, index5, これも `:290 np.abs` の犠牲）
が同じ機構で負基底を探索できないことに起因する。f_halo を抜いても f_fb_neg⇔{ICS,bubble} の縮退が
残るため、no-halo 側も平坦谷を彷徨う。これが ΔlnL 水増し（私の [I-3]）の数値的実体である。

### P-3. 問題は本質的に「凸」——Nelder-Mead が方法選択として不適（数値 [C-1](b) の物理的裏づけ）
μ = iso + Σfᵢ·Tᵢ は全パラメータについて**線形**で、Poisson NLL = Σ(μ − c·lnμ) は μ>0 の凸領域上で
**f について凸**（Hessian Σⱼ cⱼTᵢⱼTₖⱼ/μⱼ² は PSD）。docstring が「谷が浅く広い局所解」と呼ぶものは
真の多峰性ではなく、**縮退による ill-conditioning を導関数フリーの Nelder-Mead が捌けていない**だけ。
数値レビュアの L-BFGS-B / 解析初期値提案 [C-1](b) は物理構造から見て正しい。さらに全 fᵢ≥0 を課せば
**有界凸計画 → 大域最適が一意**となり、multistart 自体が原理的に不要になる（反証 R-1 に接続）。

## 数値レビュアの見落とし候補（物理観点で重要）

### P-4. 提案 [I-4]「f_halo に J-factor 校正 norm の数倍の物理境界」は校正の不確実性を継承する
数値レビュアは f_halo 上限を「J-factor 校正 norm の数倍」に設定せよと提案するが、その**基準となる
NFW 校正 norm 自体が未整理**である（私の物理レビュー [S-2]）: `calibrate_nfw_norm` のコメントは
「b=90°」だが実装はグリッド最大 |b|≈59.5°（`jb_ref=argmax|B_C|`）を使用しており、f_halo の絶対
スケールの意味づけが宙に浮いている。**校正 norm が間違っていれば「その数倍」の境界も間違う**
（過剰制約 or 無制約）。物理境界を課す前に NFW 校正基準（緯度・J-factor 規格化）の確定が先。
順序を逆にすると、数値的に安定だが絶対スケールが誤った f_halo を「測定」と誤認しうる。

### P-5. prior 締め付け（私の [I-1] と数値 [I-4]）は Totani baseline / arXiv:2607.08552 との手法整合を崩しうる
私自身が [I-1] で f_gas,f_ics に log-normal/Gaussian prior（中心1.0, σ~0.3）を提案したが、これは
**Totani (2025) §2.3 の baseline（gas と ICS を独立な自由振幅2成分として扱う）から逸脱**する。
数値レビュア [I-4] の f_halo 物理境界も同様に手法変更を伴う。比較対象 arXiv:2607.08552 が
gas/ICS 振幅をどう扱っているか（自由振幅か固定比か prior 付きか）を確認せずに prior を締めると、
**「手法差」と「物理差」を交絡**させ、有意度の論文間比較が不能になる。数値レビュアは収束・再現性の
観点から prior 締め付けを推奨しているが、**手法整合性という物理・方法論的コスト**を見落としている。
推奨: prior 締め付けは「収束のための便法」ではなく「Totani からの意図的逸脱」として明示的に扱い、
比較3論文の gas/ICS 振幅の扱いを先に確認する。

### P-6. 境界解（f_halo=0）での有意度は Wilks ではなく Chernoff 補正が必須（数値 [S-1] の深掘り）
数値レビュア [S-1] は「sqrt(2ΔlnL) は Wilks 近似の限界がある」と触れているが、**境界パラメータ問題**
という具体的機構まで踏み込んでいない。f_halo≥0 を課すと（P-1）MLE は境界 f_halo=0 に載る場合が多く、
その場合 2ΔlnL は χ²₁ ではなく **50:50 の {δ₀, χ²₁} 混合分布**（Chernoff 1954）に従う。
naive な sqrt(2ΔlnL) はこの境界で**系統的に有意度を過大評価**する。数値レビュア提案の
profile likelihood / 事後評価だけでは境界の混合分布は自動補正されない。私の [C-1](2)
（境界補正付き片側 LRT: f_halo_MLE>0 のときのみ非ゼロ）を prior 締め付けと**併せて**適用する必要がある。

## 反証（数値指摘だが物理観点では過剰・優先度が低い）

### R-1. [C-1] の「各ビンで restart プラトー到達を検証してから採用」の義務化は、根本修正後には過剰
数値レビュアは「no-halo/with-halo 両最適化が n_restarts に対しプラトーに達したことを**各ビンで検証**」を
採用条件に課すよう要求している。しかし P-3 の通り、問題は本質的に**凸**であり、(a) 全 fᵢ≥0 制約 +
(b) L-BFGS-B/解析初期値に切り替えれば**大域最適が一意**となり、multistart もプラトー検証も原理的に不要。
数値レビュアの厳格な per-bin restart-plateau プロトコルは、**Nelder-Mead に留まることを暗黙の前提**とした
過剰要求である。方法を凸最適化に替えれば、この検証コスト自体が消える。
（＝指摘は「Nelder-Mead 継続時のみ」正しい。方法変更を優先すべき。）

### R-2. [I-2] チェイン長不足（post-burn 1100 steps ≈ 11〜20τ < 50τ 推奨）は、本件の物理病理には無関係
チェイン長不足は事後分布の**尾部（16/84%ile）精度**の問題であり、数値レビュア自身も「中央値は概ね出る」
と認めている。本件の物理的病理（負 f_halo・σ 過大評価）は**点推定 MLE の ΔlnL** から生じており、
emcee 事後の尾部精度とは独立。f_halo≥0 と収束を直さないままチェイン長だけ 5000 に伸ばしても
物理的病理は 1 mm も改善しない。**真正の再現性課題ではあるが、iter-001 の採用可否には非クリティカル**。
[I-1]（seed 未固定）と併せて「次 iter で片付ける衛生項目」に格下げしてよい（優先度の反証）。

### R-3. [C-1] Bin6 の「有意度 ±数σ 数値ノイズ」への懸念は、Bin6 に関しては相対的に軽微
数値レビュア自身 [✓] が認める通り Bin6 は f_halo=2.53 が**正で seed/restart に安定**。
18.70σ→17.57σ の ~1σ ドリフトは、Bin1 の 90→39σ 崩壊に比べ桁違いに小さい。Bin6 の物理的結論
（正の広がった超過が存在する）は数値ノイズでは覆らない。Bin6 で真に問われるのは収束ではなく
**ICS↔halo 縮退による系統**（私の [I-1]: f_ics=0.124 まで潰れて halo が肩代わり）であって、
±1σ の restart ノイズではない。数値レビュアの Bin6 収束懸念は**優先度として過大**——Bin6 は
収束問題より縮退問題を先に潰すべき対象である。
