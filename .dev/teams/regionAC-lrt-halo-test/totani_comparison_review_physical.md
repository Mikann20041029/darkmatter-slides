# Physical Review — Totani比較表 事実確認 (緊急レビュー, 2026-07-16)

対象: ユーザー作成の比較表案（戸谷(2025) vs 我々のgas/ICS分離後結果）。
所要: 事実確認とフェアネスに限定。深い新規調査なし。

## 1. GIEM行のフェアネス指摘 → 正しい。修正案を支持する

- `docs/totani2025_reading_guide_ja.md:340-345`（§3.4.5, p.18-21, Fig.15中段）を
  確認。GIEMの6.7/7.4/5.1σは「GALPROPの代わりにgll_iem_v07.fitsをゼロ点として
  使った場合でも超過が残るか」という**系統誤差ロバスト性チェック**であり、
  戸谷のheadline（GALPROP baseline、NFW-ρ²、13-19σ）とは異なる解析条件。
- 我々の値（Bin5/6/7=27.94/25.45/18.99σ）はGALPROP baseline（headline相当）。
  GIEM(戸谷) vs GALPROP(我々)を並べるのはbaselineモデルが異なる比較であり
  ミスリーディング。**ユーザー提案通り、headline 1行 + GIEM行は「baselineモデルが
  異なるため直接比較不可」の注記付き参考行に格下げすべき**。
- 軽微な懸念（SUGGEST）: 「13–19σ(...有意度推定法により変動)」という説明文言は
  出典未確認。`docs/totani_figure_correspondence.md:104-105`によると、Fig.9は
  「太線=ベストフィット、細線=MCMCチェインの上位95%境界」なので、13-19σの幅は
  「推定法の違い」ではなく「点推定 vs 95%信頼区間上端」の可能性が高い。PDF原文
  未レンダリング（poppler-utils未インストールで確認不能）のため断定不可。
  スライドでは「(有意度推定法により変動)」は削除し「(p.13 Fig.9、幅の詳細は
  ベストフィット〜95%信頼区間上端)」程度の中立表現に置き換えることを推奨。

## 2. Bin6=25.45σの出典 → 正しい。最終版(N-1修正後)の値

- `results/mcmc_allbins_gasICS_v1/halo_spectrum.json`を直接確認。
  - Bin5 (12.29 GeV): `significance_sigma=27.938174619303204` → 27.94σ ✓
  - Bin6 (20.76 GeV): `significance_sigma=25.445982812314362` → 25.45σ ✓
  - Bin7 (35.06 GeV): `significance_sigma=18.98854734859232` → 18.99σ ✓
  いずれもユーザー表案の数値と完全一致。
- `.dev/teams/galprop-gas-ics-separation/iter-004/impl-state.md`の「機構分析」表
  (行182)でも同じ値（sig NEW: Bin5=27.94, Bin6=25.45, Bin7=18.99）が独立に
  再掲され整合。この表はN-1修正**後**の勾配関数を使って計算されたもの
  (impl-state.md「1. N-1修正の結果」参照)。
- ファイルmtime（2026-07-16 09:00）は`iter004_before_N1fix/`(2026-07-16 08:50)より
  後で、N-1修正コミット後に上書き保存されたことと整合。旧値（修正前の
  bubble_region矩形制限バージョン、iter-003以前相当）はBin6=15.55σであり、
  ユーザー案の25.45σとは別物。**古い値の誤引用ではない。**

## 3. 教授の前で出して大丈夫か → 現状の表案は危険。注記が必須

- `verdict.md`の結論（`.dev/teams/galprop-gas-ics-separation/verdict.md:8-11,
  27-41`）は「有意度が戸谷報告値(13-19σ)を上回ること自体が**未解明の問題**であり
  ICS-halo縮退・空間非一様性（バブル内外で符号すら反転しうる）が疑われる」という
  もの。我々の方が高い有意度は物理的な優位性の証拠ではなく、**モデル縮退による
  過大評価の疑い**という悪いニュースである。
- 現状のユーザー表案は数値だけを並べており、「我々の方が高い」ことが良い結果に
  見える構成になっている（教授が誤読するリスクが高い）。表に必ず以下を明記する:
  - 「我々の値は full ROI（バブル内外分割なし）。verdict.mdによれば、バブル領域
    (|l|<22°,10°<|b|<55°)内外で無制約フィットの符号が反転する空間非一様性が
    確認されており、球対称ハローなら生じないはずの挙動である」
  - 「25.45σ等の高い値は、ICS成分とhaloテンプレートの空間的縮退
    (Pearson r=0.71-0.86、iter-003)により過大評価されている可能性が高く、
    戸谷の13-19σを上回ることは検出の頑健性向上を意味しない」
- この注記なしで並べると、「我々の解析の方が優れている」という誤ったメッセージに
  なる。verdict.mdの結論（実装は合格・科学的結論はTotani再現に使えない）と
  矛盾しないよう、表の直下に一文で要約することを強く推奨する。
