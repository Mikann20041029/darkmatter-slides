対象: C1 (code/diagnose_regionAC_lrt_v20.py と results/regionAC_lrt_v20_fullroi/regionAC_lrt_v20.json)、C2 (code/mcmc_fit_all_bins.py の MCMC_EXCLUDE_BUBBLE と results/mcmc_allbins_gasICS_v22_nobubble/)、C3 (code/dwarf_consistency_check.py と results/dwarf_consistency/dwarf_consistency.json) を対象とする。W1 対照実験データは w1-control-sweep.md (数値レビュア実行済み) を使用した。重い計算(MCMC・イベントCSV全読み)は実行していない。nfw_j_map() を使った軽量な数値検算(重み付き平均と重みなし平均のJ比較、除外矩形のJ積分計算)のみ実行した(数秒から2分程度、CSV全列読みなし)。

## CRITICAL

### [C1] 「球対称 NFW ハロー仮説の棄却」という結論の言い方は正当化されない — 撤回すべき言い回し

spec.md は C1 を「球対称 NFW ハロー仮説と整合しない」と要約しているが、これは
この検定が実際に排除できる範囲を超えた言い方である。f_halo_A と f_halo_C の不一致
(領域共有背景モデルでの尤度比検定、shared_background_lrt フィールド)という
数値自体は再現できた(下記「通過した検証」参照)。しかし、この非一様性から
言えるのは「ROI 全体で単一の f_halo をかけた NFW-ρ² テンプレートでは領域 A・C の
データを同時に説明できない」ということまでであり、原因は次の3つが少なくとも
同等に妥当で、どれか1つに絞り込む検証がされていない。

1. 真に非球対称なハロー(本当に仮説棄却)
2. 採用している NFW 形状 (rs=21 kpc, d_sun=8 kpc, Via Lactea II) が実際の形状と違うだけ
   (例: より cuspy な内部スロープ、別の rs)。この場合でも「球対称・NFW的な」ハロー自体は
   排除されない
3. フェルミバブル/Loop I テンプレートの引き残し、または GALPROP gas/ICS モデルの
   高緯度過小予測を halo テンプレートが肩代わりしている(空間縮退)

決定的な証拠: .dev/teams/galprop-gas-ics-separation/verdict.md (2026-07) は、
本パイプラインの前身バージョンでまったく同じ現象(バブル内で halo 検出が強く、
バブル外では負に振れる領域非一様性)を既に確認しており、結論は
「GALPROP の gas/ICS モデルが高緯度でデータを系統的に過小予測しており (f_ics≫1)、
この未説明残差を NFW ハロー形状が部分的に肩代わりしている可能性が高い」
「信号は halo テンプレートとフェルミバブルテンプレートの空間的縮退による可能性が高い」
であった。同 verdict の「未実施の追加検証」には「領域A・Cでf_halo共有の同時フィット
+尤度比検定」が明記されており、C1 はまさにこの検証を実施したことになる。
しかし C1 の spec.md はこの先行結論を引用せず、「真の球対称 NFW なら領域によらず
同じ f_halo が出るはず」という順方向の論拠だけを述べて「仮説棄却」と結論している。
自チームの過去の分析が導いた「より尤もらしい説明」を無視した結論の飛躍である。

W1 対照実験(4節の所見)との整合性がこの解釈 (b)/(c) を補強する: バブル領域
(l0=0)を除いたときだけ f_ics が 0.46-1.03 の範囲から 1.025 (物理的な値) に戻る
(下記 IMPORTANT の定量検証を参照)。ICS-halo 縮退がバブル領域に局在している
ことを示しており、halo の空間非一様性の原因として (b)/(c) を強く支持する。

headline への影響: C1 の数値(f_halo_A/C の有意差そのもの)は
「注記付き維持」でよいが、「球対称ハロー仮説の棄却」という解釈的結論は撤回し、
「NFW halo テンプレートの領域間非一様性を検出。原因は特定できておらず、
ICS-halo/バブル残差縮退(2026-07 verdict と整合)が球対称性の破れと同等以上に
有力」と書き換えるべきである。

## IMPORTANT

### [C3, W5] MW の <J> の絶対規格化 (rho_s=8.1e6, Via Lactea II) は v20 の halo 較正と独立であり、headline の 2.69 sigma には未申告の系統不確かさがある

code/mcmc_fit_all_bins.py の calibrate_nfw_norm() を読むと、v20 の halo テンプレートの
物理規格化 (norm) は Totani Fig.8 の 1点のフラックス値のみから決まり、
いかなる rho_s (物理的な DM 密度)も使っていない(コード中 rho = 1.0 / (x * (1+x)**2)
は rho_s=1 の無次元形状のみ)。したがって v20 のフィットで得られる mw_halo_flux
(= f_halo x norm x j_map の ROI 平均)は、原理的に (粒子物理定数) x rho_s^2 という
積でしか制約されず、rho_s 単体は決して分離できない(これは間接検出の一般的な性質であり
バグではない)。

code/dwarf_consistency_check.py はこれを承知の上で、mw_halo_flux (実測) はそのまま使い、
別途 Via Lactea II の rho_s=8.1e6 Msun/kpc^3 を「仮定」して <J>_MW の絶対値を出し、
比 <J>_dwarf/<J>_MW から予測フラックスを導いている。W5 の問いを字義通り解釈すると
「2つの規格化は数学的に整合している必要はない」(v20 側は rho_s を含まないので比較不能)。
しかし物理的に本当に問題なのは、この rho_s=8.1e6 Msun/kpc^3 という選択自体が
恣意的であり、しかもこの選択が headline 数値 (2.69 sigma) に2乗で効く点である。

- rho_s=8.1e6 Msun/kpc^3 が意味する太陽近傍局所密度は rho(8kpc) ≈ 0.42 GeV/cm^3
  (x=8/21=0.381, rho_s/(x(1+x)^2) を GeV/cm^3 に換算)。文献レンジ (Read 2014 等、
  0.2-0.6 GeV/cm^3) の中では妥当だが上寄り。
- <J>_MW は rho_s^2 に比例するので、局所密度として文献の中心値付近 0.3 GeV/cm^3 を採ると
  予測 sigma は 2.69 x (0.3/0.42)^2 で約 1.35 sigma、上限付近 0.6 GeV/cm^3 を採ると
  2.69 x (0.6/0.42)^2 で約 5.4 sigma。
- つまり「粒子物理を仮定していない」という C3 の強みの主張は、sigma_v・m・dN/dE が
  相殺される点では正しいが、局所 DM 密度(=rho_s)という別の仮定にすり替わっている
  だけであり、この仮定の不確かさは開示・伝播されていない。

これは C3 の「非検出は DM 仮説と矛盾しない」という定性的結論そのものは覆さない
(範囲 1.35-5.4 sigma はいずれも実測 -0.18 sigma との非両立を強く主張できるレベルではない)が、
「2.69 sigma」という一意の数値を headline に出すのは不適切で、系統誤差バンドを明示すべき。
特に上限側 (約5.4 sigma) では「非検出とやや緊張」に近づくため、「否定も肯定もできない」を
やや強めすぎている可能性がある。

### [C3, W5] mean_j_mw の空間平均が v20 の実測フラックスの平均規則と食い違っている (約9%)

dwarf_consistency_check.py の mw_mean_j() のコメントは「v20 の halo 成分フラックスが
同じ ROI の単純画素平均なので、ここも同じ valid マスク上の平均を取る」と明記しているが、
これは事実誤認である。実際に component_spectra.json を生成しているのは
code/plot_component_overlay_vN.py であり、そこでの平均は

    spec[c] = E^2 * sum(f*counts_template) / sum(exposure*Omega_pix*dE)

という露出x立体角で重み付けした平均であって、単純画素平均ではない
(該当箇所: plot_component_overlay_vN.py 86-90行目)。数値検算した結果:

    j_shape の単純画素平均 (現在の実装): 65.69 kpc (rho_s=1 単位)
    j_shape の立体角重み付き平均 (実際の v20 の定義に近い): 71.64 kpc
    比 (重み付き/単純) = 1.09

すなわち mean_j_mw は真の値より約 9% 過小評価されており、これは予測 sigma を約 9%
過大評価する方向に効く。上記の rho_s 選択の系統誤差(倍率2-4)に比べれば小さいが、
コードのコメントに書かれた前提が実装と食い違っている点は修正が必要。
(露出の空間分布まで含めた重み付けはさらに数%変わりうるが、露出の ROI 内変動は
.dev/TOTANI_SPEC.md の140行目に「標準偏差/平均 13.4%」と記録されており、オーダーとしては
上記 9% の立体角効果と同程度で、合計しても 2-4 倍の rho_s 系統に対しては劣位。)

### [C2, W1] l0=0 (本物のバブル) の 4.96 sigma は「NFW が明るい領域を消しただけ」では説明しきれない — 定量検証の結果、バブル特異性を支持する

w1-control-sweep.md の指摘(2節)を受けて、nfw_j_map() の shape 値を用いて
除外矩形内の J 積分(および J^2 積分、Fisher 情報の粗い代理量)を実際に計算した
(mcmc_fit_all_bins.py の同一求積 s=linspace(0.01,60,150) を使用、
MCMC 本体は実行せず数値のみ)。

除外中心 l0=0(本物): ROI内J総和に占める除外割合 57.4%、除外中に含まれるJ^2の割合 82.8%
除外中心 l0=+/-20: 除外割合 44.8%、J^2割合 54.5%
除外中心 l0=+/-30: 除外割合 32.8%、J^2割合 25.6%
除外中心 l0=+/-38: 除外割合 25.1%、J^2割合 13.2%

情報損失(J^2の割合、Fisher情報の一次近似)だけから予想される有意度低下
(sigma_pred = 19.00 x sqrt(残存J^2割合)) と実測値を比べると:

l0=0:     sigma_pred は約7.9 sigma、実測4.96 sigma、実測は予測の 63%
l0=+/-20: sigma_pred は約12.8 sigma、実測14.50/15.54 sigma、実測は予測の 113-121%
l0=+/-30: sigma_pred は約16.4 sigma、実測14.34/16.06 sigma、実測は予測の 88-98%
l0=+/-38: sigma_pred は約17.7 sigma、実測13.35/16.25 sigma、実測は予測の 75-92%

この粗い(背景の再相関を無視した対角 Fisher 近似の)モデルでも、l0=0 だけが
系統的に「予測より大きく低い」(63%、他は75-121%でばらつきはあるが l0=0 ほど
一貫して下振れしない)。したがって「NFW が明るい領域を単に消しただけ」という
帰無仮説では l0=0 の落ち込みを説明しきれず、バブル固有の何か(ICS-halo縮退・
バブルテンプレート引き残し)が追加で効いているという w1-control-sweep.md の
所見1は定量的に支持される。ただしこの近似は背景パラメータの再フィットによる
共分散構造の変化(f_ics が l0=0 でのみ 1.025 に戻るなど)を無視した一次近似であり、
「何倍」まで厳密に言い切れるものではない(目安として観測/予測比 0.63 という数字
自体は over-simplified モデルへの依存を明記した上で報告すべき)。

### [C1 x C2 x W1] f_ics の l0=0 特異的な挙動は ICS-halo 縮退の局在を示す — 2026-07 verdict と整合

w1-control-sweep.md 4節の「l0=0 のときだけ f_ics が 1.025 (物理的) に戻り、他は
0.46-0.79」という所見は、galprop-gas-ics-separation/verdict.md の
「GALPROP gas/ICS モデルが高緯度でデータを系統的に過小予測しており、この残差を
NFW ハローが肩代わりしている」という 2026-07 の結論と同一現象の再確認である。
真のバブル位置を除外したときにだけ f_ics が 1 に戻るのは、GALPROP-ICS モデルの
系統誤差(過小予測)が主にバブル/銀河中心方向に局在しており、それが
halo テンプレートと縮退して f_halo・f_ics 双方の値を歪めていたことを強く示唆する。
これは C1 の「NFW 形状の代わりにハローがバブル/GALPROP 残差を肩代わりしている」
という代替説明 (b)/(c) を直接補強する物理的証拠であり、C1 の CRITICAL 項目と
セットで評価すべきである。

### [W7] Bin1/Bin2 (1.51, 2.55 GeV) の高有意度は信用しない

regionAC_lrt_v20.json の shared_background_lrt では Bin1=5.51 sigma, Bin2=0.84 sigma
だが、独立フィット(領域A/Cを完全に独立フィット)では f_halo が -253, +27.9, -41.6
などと非物理的な値になっており、明らかに背景パラメータとの深刻な縮退・多峰性を
抱えている(領域Aは32セルのみに9パラメータをフィットしており、自由度が不足)。
Wilks の定理は漸近正則性(尤度が最尤点近傍で滑らかな二次形式に近似できること)を
要求するが、この規模の多峰性がある状況ではdf=1のカイ二乗漸近は疑わしい。
spec.md も headline として使っているのは Bin4-10 (7-170 GeV) のみであり、この点は
実害はないが、将来 Bin1/Bin2 の数値を引用しないよう明記すべき。

### [C3] SMC (小マゼラン雲) を「暗黒物質支配の矮小銀河」と同列に扱っている

dwarf_consistency_check.py の出力上位に smc (predicted_detection_sigma 最大) が
出ているが、SMC は星形成銀河でガスも豊富であり、宇宙線とガスの相互作用による

「非検出」を DM 制限の根拠として使うのは、古典的暗黒物質支配 dSph (segue_1,
ursa_major_2 等) とは前提が異なる。結果を大きく動かすものではないが、
「45 天体すべてが DM 支配の非検出ターゲットである」という前提は要注意。

## 通過した検証

- 次元解析: dwarf_consistency_check.py の
  J_CONV = (MSUN_IN_GEV/KPC_IN_CM^3)^2 x KPC_IN_CM
  を検算 (MSUN_IN_GEV は約1.1157e57 GeV で太陽質量の静止質量エネルギーの既知値と一致、
  KPC_IN_CM は約3.0857e21 cm)。J_CONV は約4.45e6 (GeV/cm^3)^2 cm / (Msun/kpc^3)^2 kpc となり、
  mean_j_mw = rho_s^2 x mean_shape x J_CONV = 1.918e22 GeV^2 cm^-5 sr^-1 を手計算で再現
  (JSON値と一致)。次元・数値ともに問題なし。
- オーダー評価: rho_s=8.1e6 Msun/kpc^3 (Via Lactea II) が意味する太陽近傍局所密度は
  約0.42 GeV/cm^3 で、文献レンジ (0.2-0.6 GeV/cm^3) の妥当な範囲内。桁違いの誤りはない。
- C1 の数値再現: results/regionAC_lrt_v20_fullroi/regionAC_lrt_v20.json の
  bins[5] の shared_background_lrt (Bin6, 20.76 GeV) は f_halo_A=1.368, f_halo_C=1.003,
  equivalent_sigma=2.89, fun_spread_max=9.3e-08 (収束良好) であり、spec.md の記載と
  厳密に一致した。ただしトップレベルの f_halo_A_pointest / f_halo_C_pointest
  フィールド(独立フィット・背景共有なし)は全く別のモデルの結果(9パラメータを
  領域ごとに完全に独立フィットしたもの)で、低エネルギービンで f_halo が
  -253 や +27.9 など非物理的な値になっており未収束(fun_spreadは2e-6から1.8e2まで)。
  この2つのフィールド群を取り違えると誤読するので、レビュー・報告では必ず
  shared_background_lrt の方を C1 の主張として引用すること(このJSON構造自体は
  数値レビュアへの申し送り事項)。
- C1 の有意度パターン: 7-170 GeV (Bin4-10) の shared_background_lrt はいずれも
  f_halo_A が f_halo_C より大きく、比1.3-9.7倍、有意度2.2-5.7 sigmaで、spec.mdの
  「1.3-11倍」「2.2-5.7 sigma」の記述とおおむね整合。
- C2/W1 の再現性: w1-control-sweep.md の l0=0 (本物のバブル) 除外が 4.96 sigma を
  与えることは、Manager の記録(MCMC_SKIP_MCMC=1で4.96 sigma完全再現)通り。

## 判定

C1: 注記付き維持 — 数値(領域間 f_halo 非一様性、Bin6で2.89 sigma)は再現できるが、
「球対称 NFW ハロー仮説の棄却」という言い回しは撤回し、「原因未特定の空間非一様性
(ICS-halo/バブル縮退が最有力、2026-07 verdict と整合)」に書き換えること。

C2: 注記付き維持 — l0=0特異的な4.96 sigmaへの落ち込みは、NFWの明るさだけでは説明しきれない
ことを粗いFisher情報モデルで定量的に確認した(観測/予測比0.63、他オフセットは0.75-1.21)。
ただし「バブルを消すとsigmaが76%落ちる」という主張は、その大部分(オーダーとして半分以上)が
単純な統計的情報量の喪失で説明できる点、および残りの下振れがICS-halo縮退という
「バブル特有の汚染」以外の高次背景相関効果の可能性も残る点を明記して報告すること。

C3: 注記付き維持 — 比の論法(F_dwarf/F_MW=<J>_dwarf/<J>_MW)自体は粒子物理を消去する点で
数学的に正しいが、絶対規格化に使う rho_s_MW(Via Lactea II)の選択が恣意的で、
headlineの2.69 sigmaには局所DM密度の文献不確かさだけで約1.35-5.4 sigmaの系統誤差幅がある。
単一の「2.69 sigma」を主張として出さず、系統誤差バンド付きで報告すること。
