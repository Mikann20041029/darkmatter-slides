# W1 対照実験の生データ (Manager 実行、2026-09-28)

## 目的

C2 の主張「バブル矩形を尤度から外すと Bin6 が 19.11σ → 4.96σ」について、**低下が
バブル固有か、単に NFW テンプレートが明るい領域を削っただけか**を切り分ける。

## 方法

`code/mcmc_fit_all_bins.py` に既に入っている `MCMC_EXCLUDE_BUBBLE` / `MCMC_EXCLUDE_RECT_L0`
を使い、**同じ形・同じ緯度帯の矩形 (半幅 22°, 10°<|b|<55°) の中心経度だけを振って**
Bin6 (20.76 GeV) の有意度を測った。除外画素数がほぼ一定であることで等面積性を担保している。

実行スクリプト: `/home/arsei/ctrl_sweep.sh`、生ログ: `/home/arsei/ctrl_sweep.txt`
出力先: `/home/arsei/ctrl_l0_<L0>/`、`/home/arsei/ctrl_none/`

環境変数:
`MCMC_ULTRACLEAN=1 MCMC_PIXEL_DEG=0.125 MCMC_DISK_BUBBLE=1 MCMC_CELL_LIKELIHOOD=1
MCMC_SIGNFREE_HALO=1 MCMC_SKIP_MCMC=1 MCMC_BINS=6`

`MCMC_SKIP_MCMC=1` は emcee を省くだけで、significance は delta_lnL 由来のため不変
(l0=0 で既知の 4.96σ を完全再現することを確認済み)。

## Manager が気づいている読み方の注意 (レビュアが判定すべき点)

1. **l0=0 だけが突出して低い** (4.96σ vs 他 13.35-16.25σ)。等面積の別領域を削っても
   19.00 → 13-16σ にしか落ちない。**この差は「バブル固有」を支持する。**

2. **しかし完全な等価比較ではない。** NFW J は銀河中心方向 (l=0) で最も明るいので、
   l0=0 の矩形は他のどの矩形より多くの halo フラックスを含む。したがって l0=0 で
   有意度が余計に落ちるのは**本物の信号でもある程度は起きる**。
   レビュアは「その期待される低下がどの程度か」を見積もり、4.96σ がそれで説明できるか
   判定すること。各矩形に含まれる halo テンプレート積分値 (sum of `halo` template over
   the excluded pixels) を直接計算すれば定量化できるはず。

3. **f_halo (振幅) の挙動は σ と食い違う。**
   - 除外なし: f_halo = 1.479、σ = 19.00
   - l0=0: f_halo = 1.136 (振幅は **−23%** しか下がらない)、σ = 4.96 (**−74%**)
   - オフセット各種: f_halo = 1.31-1.76 (除外なしと同程度)、σ = 13-16
   つまり**バブルを外しても halo の振幅はあまり変わらず、精度だけが大きく落ちる**。
   もしバブルが偽の halo フラックスを注入していたなら、振幅がもっと大きく下がるはず。
   **この点は C2 の「汚染」解釈をむしろ弱める可能性がある。**
   一方で C1 (背景共有 LRT) は Bin6 で A/C 比 1.36 を報告しており、
   1.479 → 1.136 (比 1.30) とおおむね整合する。C1 と C2 の整合性も判定すること。

4. **f_ics の挙動**: l0=0 のときだけ f_ics が 1.025 と 1 近傍に戻り、他は 0.46-0.79。
   除外なしでは 0.605。バブル領域を外すと ICS が物理的な値に近づくという傾向がある。
   これが何を意味するか (ICS-halo 縮退がバブル領域で起きている証拠か否か) を判定すること。
