## 9. 上智・平野哲文研との接続（2026-09-14・研究計画書と面接用）

### 9.1 平野哲文研の実際の研究（科研費17H02900・arXiv 2023〜）

| 道具 | 内容 |
| --- | --- |
| 相対論的流体力学 | **格子QCDの状態方程式**を入れて膨張するQGP流体を解く |
| **流体揺らぎ** | 膨張系（Bjorken流）での熱揺らぎの因果的ダイナミクス（Fujii & Hirano, arXiv:2311.04466） |
| コア–コロナ描像 | 熱平衡QGP＋非平衡コロナ |
| 小さい衝突系 | pp衝突でのQGP生成割合 |
| 輸送係数 | ずれ粘性・緩和時間 |

### 9.2 接点（強い順）

1. **QCD状態方程式 → 初期宇宙のQCD転移（$t\sim10\,\mu$s、$T\sim150$–200 MeV）→ 原始ブラックホール → DM → γ線**
   状態方程式 $w=p/\rho$ が転移期に $1/3\to\sim0.1$ に下がり、崩壊閾値 $\delta_c$ が下がってPBH生成が太陽質量付近で増える（Byrnes+2018, Carr+）。PBHの蒸発γ線をFermi-LATが制限。**立教の原田知広先生（PBH）にも同じ筋が使える**
2. **流体揺らぎ → 初期宇宙の密度揺らぎ**。膨張するQGP流体は初期宇宙そのもの。方法論がそのまま移植できる
3. **状態方程式 → WIMP残存量**。$H\propto\sqrt{g_*(T)}\,T^2$ の $g_*$ がQCD転移で急変。GeV質量DMのfreeze-outと重なり、残存量が最大10%動く（Drees, Hajkarim & Schmitz, JCAP 2015）。Fermi解析のベンチマーク $\langle\sigma v\rangle\simeq3\times10^{-26}$ cm³/s はこの計算の答え
4. **小さい衝突系 → 銀河中心のγ線背景**（宇宙線陽子＋ガス → π⁰ → γγ）

### 9.3 研究計画書の一段落（ドラフト）

> 卒業研究では、Fermi-LATの全天ガンマ線データを用いてダークマターハローからの信号を探索した。ダークマターの残存量や候補天体の生成は、宇宙開闢後約10マイクロ秒のQCD転移期における状態方程式と熱的揺らぎに強く依存する。修士では、相対論的流体力学と格子QCD状態方程式を用いて、QCD転移期の膨張する初期宇宙プラズマにおける揺らぎのダイナミクスを記述し、原始ブラックホールの生成量およびWIMP残存量への影響を定量化することを目指す。得られた予言を、卒業研究で扱ったガンマ線観測データと突き合わせることで、素粒子・原子核物理と宇宙観測を接続する研究を行いたい。

### 9.4 面接で「重イオン衝突に興味は？」と聞かれたら

「初期宇宙のQGPを実験室で再現できる唯一の手段だと理解しています。宇宙側で制限をつけるには、加速器側でQGPの性質——特に状態方程式と輸送係数——がどこまで決まっているかを知る必要があり、そこを学びたいです」

### 9.5 中学生レベルの説明（自分で話せるように）

宇宙が生まれた直後は熱すぎて、陽子や中性子すらなく、その材料（クォークとグルーオン）がバラバラの**スープ**だった。これがQGP。宇宙が冷えてスープが固まって陽子・中性子ができた。**この「固まる瞬間」が全部の交差点。**

- **平野先生**：このスープを地上の加速器で作って（原子核を光速近くでぶつける）、スープの「温度と圧力の関係」「どう流れるか」「どう揺れるか」を調べている
- **自分**：Fermi衛星のγ線でダークマターを探している
- **繋がり①**：ダークマターの「量」は、宇宙が冷えてスープが固まる途中で決まった。その計算に「スープの温度と圧力の関係」が要る。平野先生が加速器で測っているものと同じ
- **繋がり②**：スープが固まる瞬間に宇宙のムラが潰れて小さなブラックホールができたかもしれない（原始ブラックホール）。これもダークマター候補。ゆっくり蒸発してγ線を出す。Fermiがそのγ線を見ていないことで「そんなにない」と言える。自分の仕事がそこ
- **繋がり③**：平野先生の得意技は「膨らむスープの中の揺れ」の計算。加速器のスープも初期宇宙のスープも膨らむ。同じ計算が使える

### 9.6 正直な位置づけ

青学の「X線連星側から」と同じ**作った橋**。ただし QCD-EoS×PBH、EoS×relic density は実際に論文が出ているテーマで、青学の橋より物理的に固い。入学後に実際にやるのは重イオン衝突のシミュレーションになる可能性が高いが、修論で「初期宇宙のQCD転移」を提案する余地はある。
