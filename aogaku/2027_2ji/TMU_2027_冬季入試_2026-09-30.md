# 東京都立大学 冬季入試（2027年4月入学）— 要項原本で確認（2026-09-30）

本人の新しい条件：**理論天文 or 情報系／成成明学以上／通学圏／就活で有利**

## A.【本命】システムデザイン研究科 情報科学域（冬季入試）

https://www.sd.tmu.ac.jp/assets/files/download/nyushi/2027in_zenki/2027honbun_zenki.ver2.pdf

| 項目 | 内容 |
| --- | --- |
| **出願期間** | **2026年12月3日・4日 必着**（郵送） |
| **試験日** | **2027年1月15日（金）** |
| 合格発表 | 2027年1月29日 |
| 募集人員 | 一般選抜 **若干名** |
| **試験科目** | **専門科目（9:30〜12:00）＋ 面接のみ** |
| **専門科目の出題範囲** | **微分積分／線形代数／確率・統計／データ構造とアルゴリズム** |
| **英語** | **試験日に英語の筆記試験を行わない。TOEIC または TOEFL-iBT のスコアを提出**（試験日から過去2年以内。TOEIC-IPは不可） |

| キャンパス | 日野キャンパス（東京都日野市） |

### なぜこれが本命か

1. **君が落とした科目が1つも出ない。** 量子力学・電磁気学・熱力学・解析力学——明治/上智/立教で無理だと判断した科目が**全部ない**
2. **英語は筆記なし。10/25のTOEICがそのまま使える**
3. **「データ構造とアルゴリズム」は、基本情報技術者 科目Bそのもの。** 12/27の基本情報の勉強が、**1/15の院試対策と完全に地続き**
4. 微分積分・線形代数・確率統計は、物理出身なら戦える土俵
5. **情報系の大学院に進めば、就活の学歴＋専攻の両方が変わる**

### 注意点

- **募集人員「若干名」**（夏季は63名、冬季は若干名）
- 出願まで**約2か月**（12/3-4）、試験まで**3.5か月**（1/15）
- 過去問は公開されている（「2025年度冬季入試より、試験問題及び出題の意図をwebページに公開」）
- 日野キャンパスは横浜（神大寺）から約1時間20分

### 筆記試験等免除制度もある（要項 P.5）

> 「一般選抜又は国費外国人留学生特別選抜に志願する者について、**学業成績が優秀で、志望する学域における勉学に高い意欲を持ち、なおかつ合格した場合には必ず入学することを確約できる者**に対しては、審査の上、**筆記試験等を免除する場合があります**」

神奈川大の特別選考と同じ構造。**申請書類（筆記試験等免除希望調書・成績証明書・単位数が確認できる書類）を提出して審査を受ける。**

### 物理学専攻の研究分野（2027年度 研究分野紹介より）

① 素粒子理論／**② 宇宙重力物理**／③ 原子核ハドロン物理／**④ 宇宙理論**／⑤ 複雑系物理／
⑥ 量子凝縮系理論／⑦ 強相関電子論／**⑧ 計算物質科学**／⑨ 固体統計物理／⑩ 高エネルギー物理実験／
**⑪ 宇宙物理実験**／⑫ ソフトマター／⑬ 電子物性／⑭ 超伝導物質／⑮ ナノ構造物性

**素粒子理論の紹介文に「現宇宙に存在する未知の物質であるダークマター」が明記されている。**
理論天文をやりたいなら、**宇宙理論・宇宙重力物理・宇宙物理実験**の3研究室がある。

### 注意点
- **筆記試験がある。** 科目は未確認だが、物理系の院試なら力学・電磁気・量子・熱統計が定番。
  **これは君が「無理」と判断した範囲そのものになる可能性が高い**
- 明日（10/1）募集要項が公開されるので、科目を確認してから判断する
