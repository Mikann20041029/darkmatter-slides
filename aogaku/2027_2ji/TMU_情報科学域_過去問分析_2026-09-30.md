## 形式

**専門科目のみ・150分・4分野必答**（微分積分／線形代数／確率・統計／データ構造とアルゴリズム）
問題用紙5枚、解答用紙4枚（分野ごと）、計算用紙1枚。**英語の筆記試験なし（TOEIC提出）**。別途 面接。

## 2026年度 冬季入試の実物

### 問題1 微分積分
- (a) f(x)=x^(1/2) が x=0 で微分可能か、理由を示して判断
- (b) arccos x を x³ の項までマクローリン展開
- (c) f(x,y)=sin(x−y)+cos(x+y) の停留点を全て求め、極大か極小か判定
- (d) ∫₀ᵃ (a²−x²)^(3/2) dx（x=a sinθ の置換可）
- [1-2] 円柱座標での3重積分 I(p)=∭z^p dxdydz と、収束する p の条件

### 問題2 線形代数
- a₁,a₂ の張る平面の方程式／法線ベクトルとの内積で a₃ が平面外にあることを示し一次独立を結論
- 指定ベクトルを {a₁,a₂,a₃} の一次結合で表す
- 連立一次方程式が一意解を持つ条件

### 問題3 確率・統計
- 同時確率密度 f(x,y)=c(x+y) の定数 c と周辺確率密度
- **ベイズの定理**（P(A|B) を求める）
- **最尤推定**：10個中2個エラー → 尤度関数 L(p)、対数尤度から最尤推定量を導出

### 問題4 データ構造とアルゴリズム
- **ダイクストラ法**：探索過程を表に記入、v1→v5 の最短路と最短路長
- **擬似コードの穴埋め**（6箇所）
- **計算量を O記法で表し、理由も示す**

## 判定：4分野中3分野は、君が既にやっていること

| 分野 | 君の状態 | 根拠 |
| --- | --- | --- |
| **微分積分** | **戦える** | 重積分・円柱座標・置換積分は卒論の解析で使っている範囲 |
| **線形代数** | **戦える** | 標準的。青学で落とした「表現行列」より易しい |
| **確率・統計** | **むしろ有利** | **最尤推定＝卒論のMCMCフィットそのもの。ベイズの定理も同様** |
| **データ構造とアルゴリズム** | **唯一の未習** | ダイクストラ法・擬似コード・O記法 ＝ **基本情報 科目B の範囲** |

**つまり、新しく覚えるのは「データ構造とアルゴリズム」の1分野だけ。**
そしてそれは **12/27の基本情報（科目B）の勉強と完全に同じ内容**。

## 「転専攻になるのでは」への答え

**なります。そして物理→情報科学は、大学院では定番のルートです。**

| 論点 | 事実 |
| --- | --- |
| 受け入れ | 都立大 情報科学域の出願資格に学部・学科の指定はない。**夏季は63名募集** |
| なぜ物理が歓迎されるか | 試験の3/4が数学（微積・線形代数・確率統計）。**情報系学部生より物理出身の方が強い領域** |
| 面接で聞かれること | 「研究に対する抱負（専門分野に関する内容を含む）」＝**なぜ物理から情報科学か**を説明する必要がある |
| 失うもの | **卒論の天文は直接は続けられない。** 研究室が変わる |
| 残るもの | 「Fermi-LAT 15年分の大規模データ処理」「MCMCによる統計的推論」「帰無分布の実測による検証」は**情報科学の文脈でそのまま語れる** |
| 就活への効果 | **情報系の院卒になる。** 就職課が言った「情報系と戦うことになる」という不利が、そのまま解消される |
