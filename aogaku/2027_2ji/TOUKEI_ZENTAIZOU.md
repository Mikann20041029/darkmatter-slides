# 統計力学の全体像 — 2026-09-12（本人の把握と照合して修正）

## 本人の把握（原文の要約）

- スタート地点が3つ：ミクロカノニカル／カノニカル／グランドカノニカル
- ミクロ：S = k log W からいろいろ出す
- カノニカル：状態密度 D か分配関数 Z を偏微分して出す。温度で極限を出すことが多い
- グランド：大分配関数を微分して出す
- 別のスタート：ボース／フェルミ。結局エントロピーや状態密度に行き着くので同じようなもの

## 修正点（5つ）

1. **熱力学の層が抜けている** ← 青学本番で落とした場所。W も Z も使わない世界
2. 各アンサンブルで「何を微分するか」の名前（ポテンシャル）がない
3. 状態密度 D(ε) はカノニカル専用ではない。**どのアンサンブルでも使う道具**
4. ボース／フェルミは「別のスタート」ではなく **グランドカノニカル＋量子統計**
5. 揺らぎ・等分配・古典極限が抜けている

## 修正した全体像（5層）

### 第0層：熱力学（統計力学の外側。ミクロを一切使わない）

- 状態量：U, S, V, N, T, P, μ
- **第一法則：dU = TdS − PdV + μdN**
- ポテンシャル：F = U − TS（ヘルムホルツ）、G = F + PV（ギブス）、H = U + PV、Ω = F − μN（グランド）
- マクスウェル関係式（ポテンシャルの2階偏微分の順序交換）
- 準静的過程：等温（T固定）、断熱（S固定 = 可逆断熱）、等圧、等積
- カルノーサイクル、効率 1 − T_low/T_high
- **青学本番の問題**：dU = TdS − PdV を積分して S(T,V) を出す → 等温で ΔS = nR ln(V2/V1)、断熱で ΔS = 0 と T V^(γ−1) = 一定

### 第1層：3つのアンサンブル ＝「何を固定するか」と「対応するポテンシャル」

| アンサンブル | 固定するもの | 出発点 | ポテンシャル | そこから出るもの |
| --- | --- | --- | --- | --- |
| ミクロカノニカル | E, V, N | 状態数 W(E,V,N) | **S = k ln W** | 1/T = ∂S/∂E、P/T = ∂S/∂V、μ/T = −∂S/∂N |
| カノニカル | T, V, N | Z = Σ exp(−βE) | **F = −kT ln Z** | U = −∂lnZ/∂β、S = −∂F/∂T、P = −∂F/∂V、C = ∂U/∂T |
| グランドカノニカル | T, V, μ | Ξ = Σ exp(−β(E − μN)) | **Ω = −kT ln Ξ = −PV** | N = −∂Ω/∂μ、S = −∂Ω/∂T、P = −Ω/V |

**「偏微分していく」の正体 ＝ そのアンサンブルのポテンシャルを、固定していない変数で微分する。**
3つは「別のスタート」ではなく、同じ熱力学（第0層）に3方向から接続する。大きな系では結果は一致する。

### 第2層：粒子の統計（アンサンブルとは独立な軸）

| 統計 | 占有数 | どこで使う |
| --- | --- | --- |
| 古典（ボルツマン） | 制限なし、区別できない粒子は N! で割る | 理想気体、高温極限 |
| フェルミ | 0 か 1（パウリ） | 電子、金属、白色矮星 |
| ボース | 0〜∞ | 光子（μ=0）、フォノン、BEC |

**ボース／フェルミはグランドカノニカルの中で出てくる**：各1粒子状態を「粒子数が変動する小さな系」とみて Ξ を書くと
- フェルミ：⟨n⟩ = 1 / (exp(β(ε−μ)) + 1)
- ボース：⟨n⟩ = 1 / (exp(β(ε−μ)) − 1)
- 光子は μ = 0 で ⟨n⟩ = 1 / (exp(βħω) − 1)（プランク分布）← 第2-6回でやった

### 第3層：道具（どの層でも使う）

- **状態密度 D(ε)**：Σ_states → ∫ D(ε) dε。3次元自由粒子で D ∝ √ε、光子で D ∝ ω²。**カノニカル専用ではない**
- **高温／低温極限**：高温 → 等分配（1自由度あたり kT/2）、古典に戻る。低温 → 基底状態＋指数的に小さい励起（e^(−Δ/kT)）。**採点者が「物理を理解しているか」を見る場所**
- **揺らぎ**：カノニカルで ⟨(ΔE)²⟩ = kT² C_V、グランドで ⟨(ΔN)²⟩ = kT ∂N/∂μ ← **都立2026冬 問1-3**（χ を ⟨N⟩ と ⟨N²⟩ で表せ）
- スターリングの公式 ln N! ≃ N ln N − N（ミクロカノニカルで必ず使う）

### 第4層：相互作用系（優先度低）

- イジング模型、平均場近似、**転送行列**（立教2025春 問4）
- 格子気体（第2-3回でやった）
