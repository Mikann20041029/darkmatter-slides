#### ① 板書（暗記シート）

**検出器の原理（各1〜2行で言えるように）**

| 検出器 | 何を何に変えるか | 一言 |
| --- | --- | --- |
| **光電子増倍管（PMT）** | 光→光電面で光電子→ダイノードで二次電子を段階的に増倍（$10^6$ 倍） | 微弱光・シンチレータの読み出し。高電圧が要る |
| **フォトダイオード** | 光→半導体の pn 接合で電子・正孔対→電流 | 増倍なし、線形性が良い。逆バイアスで使う |
| **半導体検出器（Si・Ge）** | 放射線→電子・正孔対（Si は 3.6 eV で1対）→電荷を集める | エネルギー分解能が最良。Ge は冷却が要る |
| **シンチレータ** | 放射線→蛍光（可視光）→PMTで読む | NaI(Tl)、プラスチック。高い検出効率、分解能は半導体より悪い |
| **MCP（マイクロチャンネルプレート）** | 電子・光子→細い管の壁で二次電子増倍 | 位置分解能と高速応答。紫外線・X線・電子 |
| **CCD** | 光→画素ごとに電荷を蓄積→転送して読み出し | 画像。可視・X線。天文でおなじみ |
| **GM計数管** | 放射線→ガスの電離→電子なだれ→パルス | 数を数えるだけ（エネルギーは分からない）。不感時間あり |
| **比例計数管** | ガス電離→比例増幅 | パルス高がエネルギーに比例 |

**エネルギー分解能の目安**：Si（3.6 eV/対）で 5.9 keV のX線 → 約1600対 → 統計的ゆらぎ $\sqrt{1600} = 40$ → 分解能 $\sim40/1600 = 2.5\%$（ファノ因子で実際はもっと良い）。**「1対作るエネルギー $w$ で割ってペア数を出し、$\sqrt N$ を取る」が計算の型。**

**実験設計問題の答え方（テンプレート）**

1. 何を測るか（観測量）→ どの検出器か（表から選ぶ）
2. 図：線源／試料 → 検出器 → 増幅器 → 計数（ブロック図でよい）
3. 必要精度から必要カウント数：相対精度 $\epsilon$ → $N = 1/\epsilon^2$（10% なら 100 カウント、1% なら $10^4$）
4. カウント率 × 時間 ＝ $N$ から測定時間
5. バックグラウンドを別に測って差し引く、と一言

**半減期・片対数グラフ**：$N(t) = N_0e^{-\lambda t} = N_02^{-t/T_{1/2}}$、$T_{1/2} = \ln2/\lambda$。片対数で直線、傾きから $\lambda$。誤差棒は $\pm\sqrt N$。

**核・相対論の数値（出たことがある）**：$E = mc^2$（1 u ≈ 931 MeV）、核融合の Q 値＝質量欠損×$c^2$、$\alpha$ 崩壊の運動エネルギー配分（運動量保存で軽い方が多く持つ）、ミューオン寿命 2.2 μs と時間の遅れ $\gamma = 1/\sqrt{1-v^2/c^2}$。

**演算増幅器**：反転増幅 $V_{\rm out} = -\dfrac{R_f}{R_{\rm in}}V_{\rm in}$（仮想接地：両入力の電位が等しい、入力に電流は流れ込まない）。フォトダイオードの電流 $I$ を $R_f$ で電圧に：$V_{\rm out} = -R_fI$。

#### ② 過去問

**(A)【自作・立教2019春 大問6の型（原本は文字化けで読めない）】**：次の検出器の動作原理を簡潔に説明せよ。(a) 光電子増倍管　(b) 半導体検出器　(c) シンチレーション検出器。また、5.9 keV のX線を Si 検出器で検出したとき、生成される電子・正孔対の数とその統計的ゆらぎによるエネルギー分解能を見積もれ（1対 3.6 eV）。

**(B)【自作・立教2018春 大問6の実験設計の型】**：$\alpha$ 線のエネルギースペクトルを相対精度 10% で測る装置を考案し、図示して説明せよ。必要な計数とその根拠も述べよ。

#### ③ 解説

**(A)** (a)〜(c) は板書の表の1行目〜4行目をそのまま書く。
数値：$5900/3.6\simeq1640$ 対。ゆらぎ $\sqrt{1640}\simeq40$。分解能 $\Delta E/E\simeq40/1640\simeq2.4\%$、$\Delta E\simeq140$ eV。（実際のSi検出器はファノ因子 0.1 程度でこれより良い、と添えると加点）

**(B)** 解答例：

- 線源と Si 半導体検出器（$\alpha$ は数 MeV で飛程が短いので**真空容器内**に置き、空気で止まらないようにする）
- 検出器 → 前置増幅器 → 波高分析器（MCA）でパルス高の分布＝エネルギースペクトル
- 相対精度 10% → ピークに $N = 1/0.1^2 = 100$ カウント以上。線源の強度と立体角から計数率 $r$ を見積もり、$t = 100/r$
- 較正：既知エネルギーの $\alpha$ 線源（$^{241}$Am 5.49 MeV）でチャンネル→エネルギーを決める
- バックグラウンドを線源なしで同じ時間測って差し引く

> **落とし穴**：①検出器の説明で「放射線を検出する」としか書かない（何が何に変わるかを書く）。②実験設計で精度の根拠（$1/\sqrt N$）を書かない。③$\alpha$ 線を空気中で測る図を描く。

#### ④ 練習問題

**練習G5-A**：GM計数管と比例計数管の違いを2行で。

**練習G5-B**：反転増幅回路で $R_{\rm in} = 10$ kΩ、$R_f = 100$ kΩ、$V_{\rm in} = 0.1$ V のとき $V_{\rm out}$。フォトダイオードの光電流 1 μA を 1 V にするには $R_f$ はいくら。

**練習G5-C**：半減期 30 分の核種を $t = 0$ で 1000 カウント/分。60 分後と 90 分後の計数率と、それぞれの統計誤差（1分測定）。

**略解**
G5-A：GM は電離が電子なだれで飽和し、パルス高が一定＝数だけ数える。比例計数管はパルス高が入射エネルギーに比例＝エネルギーも分かる。
G5-B：$V_{\rm out} = -10\times0.1 = -1$ V。$R_f = 1\,{\rm V}/1\,\mu{\rm A} = 1$ MΩ。
G5-C：60分後 $1000/4 = 250$（$\pm16$）、90分後 $125$（$\pm11$）。
