#### ① 板書

**偶然誤差と系統誤差**
- 偶然誤差：測るたびにばらつく。何度も測って平均すれば減る（$\propto 1/\sqrt N$）
- 系統誤差：常に同じ向きにずれる。平均しても減らない（目盛のずれ、熱膨張、視差）

**最良推定値と誤差**（正規分布を仮定）
- $N$ 回測定 $x_1, \ldots, x_N$：最良推定値 $\bar x = \dfrac1N\sum x_i$
- 標本標準偏差 $s = \sqrt{\dfrac{1}{N-1}\sum(x_i - \bar x)^2}$（1回の測定のばらつき）
- **平均値の誤差** $\sigma_{\bar x} = \dfrac{s}{\sqrt N}$（これを「$\pm$」に書く）

**誤差伝播**：$Z = f(A, B, \ldots)$、独立な誤差 $\Delta A, \Delta B$
$$(\Delta Z)^2 = \left(\frac{\partial f}{\partial A}\right)^2(\Delta A)^2 + \left(\frac{\partial f}{\partial B}\right)^2(\Delta B)^2 + \cdots$$
- 和・差 $Z = A\pm B$：$\Delta Z = \sqrt{\Delta A^2 + \Delta B^2}$
- 積・商 $Z = A^pB^q$：$\dfrac{\Delta Z}{Z} = \sqrt{p^2\left(\dfrac{\Delta A}{A}\right)^2 + q^2\left(\dfrac{\Delta B}{B}\right)^2}$
- $Z = e^{rA}$：$\dfrac{\Delta Z}{Z} = r\Delta A$
- $Z = \ln A$：$\Delta Z = \dfrac{\Delta A}{A}$

**計数統計（ポアソン）**：$N$ カウントの統計誤差は $\sqrt N$。
- 計数率 $= N/t$、誤差 $\sqrt N/t$、相対誤差 $1/\sqrt N$
- **バックグラウンド差し引き**：正味 $= N_g - N_b$、誤差 $\sqrt{N_g + N_b}$（差でも誤差は2乗和）
- 相対精度 $\epsilon$ で測るのに必要なカウント数 $N = 1/\epsilon^2$

**(C) 立教 2016年春 大問5**

(b) (a) において $\sigma_a = \sigma_b$ の場合、同じ面積でも縦横の辺の長さの比により誤差が異なることを示し、誤差が最も小さくなる時の二辺の比を求めよ。

**(D) 立教 2018年夏 大問6**
放射線検出器で線源を10分測定したところ900カウント。バックグラウンドを10分測定したところ100カウント。
(a) 線源による正味の計数率とその誤差。
(b) さらに100分の測定時間が使えるとき、真の計数率をできるだけ精度よく求めるには、線源とバックグラウンドの測定にそれぞれ何分ずつ配分すればよいか。

#### ③ 解説

**(A)**
(a) i. $\ln Z = \ln p + 2\ln A + \ln B - \ln q - 3\ln C$。$\dfrac{\Delta Z}{Z} = \sqrt{4\left(\dfrac{\Delta A}{A}\right)^2 + \left(\dfrac{\Delta B}{B}\right)^2 + 9\left(\dfrac{\Delta C}{C}\right)^2}$。
ii. $\dfrac{\partial Z}{\partial A} = rZ$ → $\dfrac{\Delta Z}{Z} = r\Delta A$。
iii. $\Delta Z = \sqrt{(\ln B)^2\Delta A^2 + (A/B)^2\Delta B^2}$ → $\dfrac{\Delta Z}{Z} = \sqrt{\left(\dfrac{\Delta A}{A}\right)^2 + \left(\dfrac{\Delta B}{B\ln B}\right)^2}$。
(b) $\dfrac{1}{\sqrt N} \le 0.01$ → $N \ge 10^4$。計数率 144/s なので $t = 10^4/144 \simeq 69.4$ 秒 → **約70秒**。

**(B)** $\bar x = \dfrac{10.2 + 9.7 + 10.6 + 9.4 + 9.6 + 10.5 + 10.4 + 9.3 + 10.3}{9} = \dfrac{90.0}{9} = 10.0$。
偏差の2乗和：$0.04 + 0.09 + 0.36 + 0.36 + 0.16 + 0.25 + 0.16 + 0.49 + 0.09 = 2.00$。$s = \sqrt{2.00/8} = 0.50$。
推定誤差 $\sigma_{\bar x} = 0.50/\sqrt9 = 0.17$。**$10.0 \pm 0.2$**。

**(C)**
(a) $S = ab$：$\Delta S = \sqrt{b^2\sigma_a^2 + a^2\sigma_b^2}$。
(b) $\sigma_a = \sigma_b = \sigma$ で $\Delta S = \sigma\sqrt{a^2 + b^2}$。面積 $S = ab$ 一定のとき $a^2 + b^2 \ge 2ab = 2S$、等号は $a = b$。**正方形で誤差最小**。
(c) $144 \pm 12$ カウント／2分 → $72 \pm 6$ カウント／分。

**(D)**
(a) 正味 $= 900 - 100 = 800$ カウント／10分。誤差 $\sqrt{900 + 100} = \sqrt{1000} \simeq 31.6$。計数率 $80 \pm 3.2$ /分。
(b) 線源測定時間 $t_s$、BG測定時間 $t_b$、$t_s + t_b = 100$。計数率 $r_s = 90$/分（グロス）、$r_b = 10$/分。正味計数率の分散 $= \dfrac{r_s}{t_s} + \dfrac{r_b}{t_b}$。これを最小化：$\dfrac{t_s}{t_b} = \sqrt{\dfrac{r_s}{r_b}} = 3$ → $t_s = 75$ 分、$t_b = 25$ 分。

#### ④ 確認問題

**確認1-A**（立教2016夏 大問6）：底面が一辺 $(1.2\pm0.3)$ cm の正方形、高さ $(50\pm5)$ mm、質量 $(14.4\pm1.2)$ g の直方体。誤差付きの密度を kg/m³ で求めよ。

**確認1-B**（立教2022夏 大問6）：金属棒の長さを物差しで測る。次の誤差要因はそれぞれ偶然誤差か系統誤差か、理由をつけて述べよ。A. 目盛読み取りの角度による視差　B. 金属棒の熱膨張　C. 物差しの目盛のずれ　D. 最小目盛の1/10まで目分量で読む

**確認1-C**（立教2024夏 大問6）：加速度計の不確かさ $\sigma_a = 0.1$ mm/s²、毎秒10回測定。2地点の重力加速度の差を 0.01 mm/s² 以下の不確かさで測るには各地点で最低何秒測定が必要か。

**略解**
1-A：$V = (1.2)^2\times5.0 = 7.2$ cm³、相対誤差 $\sqrt{4(0.25)^2 + (0.1)^2} = 0.51$。$\rho = 14.4/7.2 = 2.0$ g/cm³ $= 2000$ kg/m³。相対誤差 $\sqrt{0.51^2 + (1.2/14.4)^2} = 0.52$。$\rho = (2.0\pm1.0)\times10^3$ kg/m³。
1-B：A 偶然（毎回変わる）、B 系統（温度で一方向）、C 系統、D 偶然。
1-C：差の不確かさ $\sqrt{2}\sigma_a/\sqrt{n} \le 0.01$ → $n \ge 2\times(0.1/0.01)^2 = 200$ 回 → 各20秒。

**追加【立教 2018年春 大問6 (b)(c)・原文】**
(b) 測定値 $A, B, C$ はそれぞれ偶然誤差 $\Delta A, \Delta B, \Delta C$ を持つ。$X$ が以下の式で表されるとき、$X$ の偶然誤差 $\Delta X$ を求めよ。$X = \dfrac{A^2B}{C^3}$
(c) ある放射線源から放出される放射線を1分間計数したところ523個であった。放射線源を取り除いて4分間バックグラウンドを計数したところ96個であった。正味の放射線の計数率とその誤差を求めよ。ただし、時間計測の誤差は考慮しなくてよい。

**略解**：(b) $\ln X = 2\ln A + \ln B - 3\ln C$ → $\Delta X = X\sqrt{4\left(\dfrac{\Delta A}{A}\right)^2 + \left(\dfrac{\Delta B}{B}\right)^2 + 9\left(\dfrac{\Delta C}{C}\right)^2}$。(c) グロス $523\pm\sqrt{523} = 523\pm22.9$ /分。BG $96/4 = 24.0$ /分、誤差 $\sqrt{96}/4 = 2.45$ /分。正味 $523 - 24 = 499$ /分、誤差 $\sqrt{22.9^2 + 2.45^2} = 23.0$ → **$499\pm23$ 個/分**。
