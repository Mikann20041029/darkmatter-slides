## 1.【訂正】基本情報 科目B と 都立大 問題4 の一致度

### IPA公式の科目B 出題範囲（一次資料）
出典：IPA「基本情報技術者試験 科目Bのサンプル問題」（https://www.ipa.go.jp/shiken/syllabus/ps6vr7000000oett-att/fe_kamoku_b_sample.pdf）

> １ プログラミング全般に関すること
> ２ プログラムの処理の基本要素に関すること
> 　型，変数，配列，代入，算術演算，比較演算，論理演算，選択処理，繰返し処理，手続・関数の呼出し など
> ３ **データ構造及びアルゴリズムに関すること**
> 　再帰，スタック，キュー，木構造，**グラフ**，連結リスト，整列，文字列処理 など
> ４ プログラミングの諸分野への適用に関すること（数理・データサイエンス・AI など）
> ５ 情報セキュリティの確保に関すること

形式：**多肢選択（解答群から選ぶ）**。20問100分。アルゴリズム8割・セキュリティ2割。

### 都立大 問題4 との照合

| 項目 | 基本情報 科目B | 都立大 問題4 | 一致 |
| --- | --- | --- | --- |
| グラフ | **出題範囲に明記** | ダイクストラ法 | **○** |
| 擬似コードを読む | **擬似言語で出題** | 擬似コード穴埋め | **○** |
| 計算量（O記法） | 科目Aの範囲 | 「O記法で表し、**理由も示せ**」 | △ |
| **ダイクストラ法** | **シラバスに名指しなし**（「グラフ」に含まれるだけ） | 中心テーマ | **✕** |
| **解答形式** | **多肢選択** | **記述（表に記入・理由を書く）** | **✕** |
| レベル | 配列・繰返し・関数呼出しが中心 | アルゴリズムの実装理解 | **✕** |

### 正確な言い方

**「完全に地続き」は誤り。** 正しくは：
- **基本情報をやれば「擬似コードを読む力」と「グラフ・計算量の基礎」は入る**
- **だが基本情報だけでは都立大の問題4は解けない。** アルゴリズムの教科書を1冊、別途やる必要がある
- 一致率を数字で言うなら **3〜4割**。土台は共通だが、上積みが要る

## 2. 電気通信大学 情報理工学研究科 情報学専攻（実物）

出典：https://www.uec.ac.jp/education/graduate/admission/kakomon.html
取得済み：`aogaku/2027_2ji/kakomon/uec/`（2025年8月・2023年8月の必須問題／選択問題／解答例）

### 形式
- **必須問題 50分**：「線形代数」＋「微分積分」の2問、**両方解答**
- **選択問題 130分**：**4科目中3科目を選択**
- 解答は英語でもよい

### 2025年8月 必須問題（実物）
- 4次正方行列 A の Au／**固有値をすべて求めよ**／各固有値の**固有空間**のうち次元が3のものについて、指定ベクトルが**基底**となるよう α,β,γ を定めよ

### 2025年8月 選択問題（実物）
| 科目 | 内容 |
| --- | --- |
| **1. アルゴリズムとデータ構造** | **C言語のコードを読んで穴埋め**。最小値ヒープの実装（min_sift_up / min_sift_down / min_push / min_pop）、整数列を push したときのヒープ配列 |
| **2. 確率・オペレーションズリサーチ** | **線形計画問題の定式化／スラック変数／シンプレックス法**（表を4回更新まで埋める） |
| **3. 離散数学** | **述語論理**（∀∃と論理結合子の穴埋め）、**集合**（|A∩B∩C| の最小値）、**石取りゲームと数学的帰納法** |
| 4. （未確認） | 16ページ中の残り |

### 評価
**アルゴリズムは基本情報より明確に上。** 擬似言語ではなく**実際のC言語**で、ヒープの実装を理解している必要がある。
ただし **4科目中3科目選択なので、アルゴリズムを1つ捨てられる可能性がある。**

## 3. 都立大 vs 電通大（実物ベース）

| | **東京都立大 情報科学域（冬季）** | **電通大 情報学専攻** |
| --- | --- | --- |
| 形式 | **4分野すべて必答**（150分） | 必須50分＋選択130分（**4科目中3科目**） |
| 数学の比率 | **3/4（微積・線形・確率統計）** | 必須が数学2科目＋選択にも数学系 |
| アルゴリズム | **擬似コード**（ダイクストラ法） | **C言語のコード**（ヒープ実装）※避けられる可能性 |
| 英語 | **筆記なし。TOEIC提出** | TOEIC/TOEFLのスコアシート提出 |
| 冬季入試 | **あり（2027/1/15）** | **未確認（要調査）** |
| 物理出身の有利さ | **高い（数学3/4）** | 中（必須は数学だが選択で情報系が要る） |

**現時点の判定：都立大の方が物理出身に有利。** 数学の比率が高く、アルゴリズムが擬似コードで、英語が筆記なし。

## 5. 現時点での結論

1. **基本情報＝都立大の対策、ではない。** 一致は3〜4割。土台にはなるが、アルゴリズムの教科書が別途要る
2. **都立大の問題は、明治の物理より明らかに君の土俵。** これは変わらない（数学3/4、量子・電磁気・熱力学ゼロ）
3. **電通大は都立大より情報系の比重が高い。** ただし科目選択で回避の余地あり
4. **判定は、都立大2026年冬季を150分で解いて決める。** 他大学の過去問を集める前に、まずこれ
