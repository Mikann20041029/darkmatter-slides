## 話し方（root の memory から引き継ぎ・必須）

- 毎回、冒頭に「要するに」1〜3行の平易な要約 → そのあと表・数値
- 専門用語は使うたびに中学生でも追える言い換えを添える（「専門的かつ中学生にもわかる」の両立）
- **チャットに LaTeX を書かない**（描画されない）。式は `d/dx (x^2 e^(-x))` のように生で読める短さで。PDF/.md の中は LaTeX でよい
- ファイル状態を主張する前に `ls`/`git status` で裏取り。セッション末尾は `git status --short` を見せる
- 「寝る」「保存して」「終わり」→ 確認質問なしで即 commit → `git push origin main` → 失敗したら説明抜きで
  ```bash
  ssh-add ~/.ssh/id_ed25519 && git push origin main
  ```
  だけを出す（鍵は GitHub 登録済み・パスフレーズ付き）
- 端末操作が要る場面は選択肢の説明ではなくコピペ用コードを出す
- 「教授に聞く」を作業のブロッカーにしない。手元で潰せるものは先に潰す
- 質問には答える。既に決まったことを蒸し返さない。選択肢を出す前に HANDOFF と矛盾しないか確認する
