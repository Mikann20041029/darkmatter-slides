## 2024 年度 Ⅰ期 (7.15)

**問 1**

[Ⅰ]
(1) x² + 2y² = 2 を満たす (x, y) ∈ ℝ² に対して、f(x, y) = x − y の最大値と最小値をラグランジュの未定乗数法を用いて求めよ。
(2) n = 0, 1, 2 に対して ∫_{−∞}^{∞} xⁿ e^{−x²} dx を求めよ。

[Ⅱ] ℝ 上の実数値関数 f(x) が 3 回微分可能で、f(x) の 3 階導関数が連続かつ有界であるとする。このとき正数 C と h₀ が存在して、|h| < h₀ を満たす任意の実数 h に対して
|f′(x) − (1/(2h)) (f(x+h) − f(x−h))| ≤ C h²
が成り立つことを示せ。

**問 2**
(1) 実対称行列の固有値は実数に限ることを示せ。
(2) 行列 A = [[1, 0, 1], [0, 2, 0], [1, 0, 1]] の固有値、固有ベクトルをそれぞれ求めよ。
(3) (2) で定めた行列 A に対して、n を自然数とし、Aⁿ を求めよ。

## 2024 年度 Ⅱ期 (1.20)

**問 1**

[Ⅰ] 集合 Ω = {(x, y) ∈ ℝ² | 0 < x² + y² < 1, 0 < y < x}
(1) 極座標 (r, θ) を用いて集合 Ω を表示せよ。ただし 0 ≤ θ ≤ 2π。
(2) ∬_Ω log(x² + y²) dx dy を求めよ。

[Ⅱ] xy 平面で定義された関数 f(x, y) = xy(1 − 2x − y)
(1) f(x, y) の偏導関数 ∂f/∂x, ∂f/∂y とヘッセ行列を求めよ。
(2) f(x, y) の極値をすべて求めよ。さらに極値が極大値であるか極小値であるか判定せよ。
(3) 領域 D = {(x, y) ∈ ℝ² | x ≥ 0, y ≥ 0} における関数 f(x, y) の最大値を求めよ。

**問 2**

[Ⅰ] 次の 3×3 行列 A が正則となる条件を求めよ。
A = [[1, x₁, x₁²], [1, x₂, x₂²], [1, x₃, x₃²]]

[Ⅱ] n 次元ベクトル a, b ≠ 0 に対して 2×2 行列
C = [[|a|², a·b], [a·b, |b|²]]
を考える。a·b は a と b の内積である。
(1) C の固有値はすべて 0 以上の実数であることを示せ。
(2) C が 0 を固有値にもつとき、a, b はどのような性質を満たすか述べよ。

## 2025 年度 Ⅰ期 (7.20)

**問 1**
(1) D = {(x, y) ∈ ℝ² | x² + y² ≤ 1} とするとき、重積分 ∬_D (5x² + y²) dx dy を求めよ。
  (写しの「5」は 3 にも読める。5 なら答えは 3π/2)
(2) 関数 f(x, y, z) = x、g(x, y, z) = x² + y² + z² − 1、h(x, y, z) = −2x − 3y + z を定める。
  g(x, y, z) = 0、h(x, y, z) = 0 の条件下での f(x, y, z) の最小値を求めよ。
  (写しの h の最後の項は「2」にも読めるが、3 変数の制約なので z と読んだ)

**問 2** 行列 A = [[0.1, 0.5, 0.4], [0.3, 0.3, 0.4], [0.6, 0.2, 0.2]] と定める。
(1) A の固有値と対応する固有ベクトルをすべて求めよ。
(2) P⁻¹AP がジョルダン標準形となるような 3×3 正則行列 P を求めよ。
(3) n を正の整数とするとき、lim_{n→∞} Aⁿ を求めよ。
  (確認: 各列の和が 1 の確率行列。固有値は 1 と −1/5 (重複 2、ジョルダン細胞あり) なので写しは正しい)

## 2025 年度 Ⅱ期 (2.1)

**問 1**

[Ⅰ] a > 0 とし、区間 I = [0, 1] 上で定義された正値連続関数 u(t), f(t) が I 上で
u(t) < f(t) + a ∫₀ᵗ u(s) ds
をみたすとする。
(1) V(t) = e^{−at} ∫₀ᵗ u(s) ds を t について微分せよ。
(2) I 上で u(t) ≤ f(t) + a ∫₀ᵗ e^{a(t−s)} f(s) ds が成り立つことを示せ。 (グロンウォールの不等式)

[Ⅱ] 0 < a < 1 をみたす実数 a に対して、ℝ² 上の関数 f_a(x, y) = axy を定義する。
  (写真では右端が切れていて「= a x y」までしか見えない。続きがあれば要確認)
領域 Ω_a = {(x, y) ∈ ℝ² | a < x < 1, 0 < y < 1 − x} 上での重積分 F(a) = ∬_{Ω_a} f_a(x, y) dx dy を考える。
(1) F(a) を a の式で表せ。
(2) F′(a) を a の式で表せ。
(3) 0 < a < 1 における F(a) の最大値を求めよ。

**問 2** 行列 A = [[1, 2, 3], [2, 1, 2], [3, 2, 1]] に対して二次形式 xᵀAx を考える。
ここで x, y, z ∈ ℝ、x = (x, y, z)ᵀ とする。
(1) A の固有値と対応する固有ベクトルをすべて求めよ。
(2) |x| = 1 における xᵀAx の最大値、最小値を求めよ。
  (確認: 固有値は −2 と (5 ± √41)/2)

## 2026 年度 Ⅰ期 (2025.7.19) — 公式

**問 1**

[Ⅰ]
(1) 逐次積分 ∫₀¹ ( ∫_{3y}^{3} e^{x²} dx ) dy の値を求めよ。
(2) D = {(x, y) ∈ ℝ² | x ≥ 0, y ≥ 0} とするとき、広義積分 ∬_D e^{−2x²−3y²} dx dy の値を求めよ。

[Ⅱ] 原点中心で半径が 1 の円を S = {(x, y) ∈ ℝ² | x² + y² = 1} とする。S の上に 4 点とも頂点を持つ長方形の面積の最大値を、ラグランジュの未定乗数法を用いて求めよ。

**問 2** 0 でない実数 a, b に対して、3 次正方行列 A = [[1, a, b], [a, a², ab], [b, ab, b²]] と定める。
(1) A の固有値を λ₁ ≥ λ₂ ≥ λ₃ とする。λ₁, λ₂, λ₃ をそれぞれ求めよ。
(2) k = 1, 2, 3 に対して、λ_k に対応する A の固有ベクトルを p_k とする。p₁, p₂, p₃ を線形独立になるように求めよ。
(3) (1 + a² + b²)A² = Aʲ と表せる最小の正の整数 j を求めよ。
(4) n を正の整数とするとき、Aⁿ の一般項を求めよ。

**公式解答例**: 問1 [Ⅰ](1) (e⁹ − 1)/6、(2) π/(4√6)、[Ⅱ] 2。問2 (1) λ₁ = 1 + a² + b²、λ₂ = λ₃ = 0。(2) p₁ = (1, a, b)、p₂ = (−a, 1, 0)、p₃ = (−b, 0, 1)。(3) 3。(4) Aⁿ = (1 + a² + b²)ⁿ⁻¹ A

## 2026 年度 Ⅱ期 (2026.1.31) — 公式

**問 1**

[Ⅰ]
(1) D = {(x, y) ∈ ℝ² | x² + y² ≤ √π, 0 < x ≤ y} とするとき、重積分 ∬_D sin(x² + y²) dx dy の値を求めよ。
(2) 放物面 {x² + y² = 9 − z} と平面 {z = 0} によって囲まれた領域を R とするとき、∭_R (x² + y² + z²) dx dy dz の値を求めよ。
(3) x = sin t、y = cos t、z = x² + 3xy + 5y² とするとき、dz/dt を求めよ。

[Ⅱ]
(1) S = S₁ ∪ S₂ ∪ S₃ とする。ただし
S₁ = {(x, y, z) | 0 ≤ z ≤ 1 + x, x² + y² = 1}、
S₂ = {(x, y, z) | z = 0, x² + y² ≤ 1}、
S₃ = {(x, y, z) | z = 1 + x, x² + y² ≤ 1}。
このとき面積分 ∬_S z dS の値を求めよ。

**問 2**

[Ⅰ] 回転行列 R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]] (0 ≤ θ < 2π)
(1) 点 x = (1, 2)ᵀ を考える。θ = π/4 の回転行列を A とする。Ax を求めよ。
(2) 角度 θ の回転行列を A とする。任意の実ベクトル x = (x₁, x₂)ᵀ に対して ‖x‖ = ‖Ax‖ を示せ。

[Ⅱ] A = [[3, −1, −1], [−12, 0, 5], [4, −2, −1]]
(1) A の固有値をすべて求め、それぞれに対応する固有ベクトルを求めよ。
(2) A⁵、A⁻¹ および A + 2I の固有値を求めよ。

**公式解答例**: 問1 [Ⅰ](1) (π/8)(1 − cos√π)、(2) 2673π/4、(3) 3cos 2t − 4sin 2t。[Ⅱ](1) (3/2 + √2)π。問2 [Ⅰ](1) (−√2/2, 3√2/2)、(2) 証明略。[Ⅱ](1) 固有値 2, 1, −1、固有ベクトル (1, −1, 2), (−3, 1, −7), (1, 2, 2)。(2) A⁵: 32, 1, −1、A⁻¹: 1/2, 1, −1、A + 2I: 4, 3, 1
