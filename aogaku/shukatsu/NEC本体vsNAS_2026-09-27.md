# NEC本体の宇宙部門 vs NEC航空宇宙システム — 決め方（2026-09-27）

本人：「給料とやりたいことを考えたら NEC本体の宇宙部門かもだが、神奈川院からはかなり厳しい現実。
でも修士卒で700万は安いと思ってしまう。それでも NAS の仕事内容がかなりかっこいいと思ってしまった」

## 0. まず訂正：「NEC本体は神奈川院から厳しい」は、データで確認できていない

**NEC本体の採用実績校は、マイナビに「全国の国公立及び私立大学」としか書かれていない。＝非公開。**
つまり神奈川大が通るとも通らないとも、**誰も言えない**。「厳しい」は君の推測であって、事実ではない。

分かっているのはこれだけ：

| 項目 | NEC本体 |
| --- | --- |
| 採用人数 | **2023年 590名 → 2024年 680名 → 2025年 800名**（拡大中） |
| 従業員（単独） | 22,271名 |
| 売上（単独） | 1兆9,812億円 |
| 採用実績校 | **非公開** |
| 有報 平均年収 | 994万／43.1歳 → 35歳推定 771万 |
| 修士初任給 | 314,400円＋家賃補助 最大4万/月（1年目） |

**年800名採る会社は、学歴の幅が広い。** 実績校を公開していないのは「絞っていない」ことの裏返しでもある
（絞っている会社ほど、上位校だけを誇らしく並べる。例：日鉄ソリューションズは旧帝と早慶上理のみを列挙）。

## 1. 「修士で700万は安い」への事実確認

令和6年 賃金構造基本統計調査（厚労省）より、**大学院卒・男性・35〜39歳の所定内給与は458,500円/月**。
年収換算 **740〜780万**（賞与込み・残業別）。

→ **700万台は「院卒の平均並み」。安くはないが、君の基準（35歳900万）には届かない。**
安いと感じるのは、君が基準を平均より高く置いたから。それ自体は間違いではない。

## 2. NAS の年収を、もう少しまともに推定する

NAS は非上場で有報が無い。前に「NEC本体の下」と書いたが根拠が弱かったので、**1人あたり売上**で見直す。

ただし1人あたり売上だけでは決まらない（電通総研は3,459万で1,125万、日本アビオニクスは3,284万で712万＝粗利率と年齢構成で倍近く違う）。
**正直に言うと、NAS の35歳年収は 650〜780万 のどこか、としか言えない。前に書いた「700万台」は、やや楽観寄りだった。**

補足：**NAS の修士初任給320,800円は、親会社 NEC本体（314,400円）より高い。**
初任給が親より高い子会社は珍しく、「安く使われる子会社」ではない傍証にはなる。

## 3. 本当の違いは、年収ではなく「宇宙に行ける確率」

| | **NEC本体** | **NEC航空宇宙システム** |
| --- | --- | --- |
| 従業員 | 22,271名 | **859名** |
| 事業 | IT・通信・社会インフラ・**その一部が宇宙** | **全部が防衛・航空・宇宙** |
| 宇宙に配属される確率 | **選べない。22,271名のうち宇宙はごく一部** | **100%** |
| 仕事の中身 | 配属次第 | 衛星の運用・**軌道設計**・搭載ソフト・衛星管制／局制御・**リモートセンシング** |
| 採用 | 800名/年 | 55名/年（26→55名に倍増中） |
| 35歳推定年収 | **771万** | 650〜780万（推定） |
| 神奈川大の実績 | **非公開** | **★院にあり** |
| 勤務地 | 全国 | **府中・川崎**（関東確定） |
| 年間休日 | 126日 | 125日 |
| 有給取得 | 13.6日 | **17.1日** |
| フレックス | スーパーフレックス | **コアタイムなし** |

### ここが決定的

**NEC本体に入っても、宇宙に行ける保証はない。** 22,271名の会社で、宇宙は事業の一部。
配属で通信インフラや官公庁システムに行く可能性の方がはるかに高い。

**一方 NAS は、入れば全員が防衛・航空・宇宙。** そして君の卒論（衛星データの解析）がそのまま通じるのは、
「衛星管制／局制御システム」「衛星リモートセンシング」を事業として持っている NAS の方。

**年収の期待値の差は、35歳時点でせいぜい 0〜120万。**
その差で「宇宙に行けるかどうか」を賭けるかどうか、という選択になる。

## 4. 「かっこいいと思ってしまった」は、判断材料として正当

君は「①お金 ②学歴・成功体験 ③研究内容」の順だと言った。
**だが①で見ても、NEC本体とNASの差は決定的ではない（771万 vs 650〜780万）。**
そして②の「成功体験」は、**やりたい仕事で成果を出したときに一番出る**。

**35歳900万を本気で取りにいくなら、答えは NEC本体ではなく電通総研（962万）。**
NEC本体は「宇宙かもしれないし、違うかもしれない会社」で、金額でも電通総研に190万負けている。
**つまり NEC本体は、両取りに見えて、実はどっちも中途半端になりうるポジション。**

## 5. 結論：両方出せばいい。順番だけ決めておく

NECグループは**別法人なので、本体とNASの両方に応募できる**（併願を禁止していない）。

| 枠 | 会社 | 役割 |
| --- | --- | --- |
| 金を取りにいく枠 | **電通総研**（35歳962万・★院・学部にも実績・応用物理系を名指し） | 第一志望。休みは少ない |
| 宇宙を確実に取る枠 | **NEC航空宇宙システム**（宇宙100%・★院・府中/川崎・有給17.1日） | 第二志望。ただし満足度は最上位 |
| 賭け枠 | **NEC本体**（800名採用・実績校非公開・35歳771万） | 両方出す。宇宙配属は運 |

**決めるのは2028年の初夏で、今ではない。** 今決める必要があるのは、12/27の基本情報と10/25のTOEICだけ。
**「かっこいいと思ってしまった」は、M1のインターンで実物を見てから検証すればいい。**
NAS は 12〜1月に1day（締切2027/1/31）、NEC本体はサマーインターン（2027年夏）がある。
**両方行ってから決めても、間に合う。**
