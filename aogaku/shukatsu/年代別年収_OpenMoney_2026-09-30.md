## 3. NEC（日本電気）単体の詳細

| 項目 | 値 |
| --- | --- |
| 回答者の平均年収 | **749万**／平均年齢32.1歳／**中央値712万** |
| 回答者数 | 1,314人 |
| 年収範囲 | 300万〜2,262万（22〜59歳） |
| 推移 | 2023年 690万(31.7歳)／2024年 769万(32.8)／2025年 812万(33.0)／2026年 789万(32.0) |
| **業界平均との差** | SIer・ソフトウェア開発・システム運用業界 776万に対し **−27万** |
| **業界内年収ランキング** | **3,192社中 127位** |
| 社員評価 | 3.23（654人） |

**NECは業界平均をわずかに下回る。ただし3,192社中127位＝上位4%。** 「負け組」ではないが「IT業界の中では突出していない」。
NECが高く見えたのは有報の平均年収994万（43.1歳）を見ていたためで、**30代では855万、全体の中央値は712万。**
