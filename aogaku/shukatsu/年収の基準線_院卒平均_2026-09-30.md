# 年収の基準線を「理系院卒平均」に置き換える（2026-09-30）

## 0. 結論（先に）

**新しい最低ライン：30代前半で703万、35〜39歳で826万、40〜44歳で961万。**
これは**厚生労働省の一次データ**で、**男性・大学院卒の実際の年収**。これを超えない会社は候補から外す。

---

## 1. 本人提供の資料が示していたこと（国税庁「民間給与実態統計調査」令和5年）

| 指摘 | 中身 |
| --- | --- |
| 全国平均年収460万は当てにならない | **主婦・高齢者・学生のパート／バイトを含んだ数値** |
| 非正規雇用2,124万人の内訳 | **主婦43.4%＋60歳以上20.8%＋学生9.6% ＝ 73.8%が主婦・シニア・学生** |
| 男性の年齢別（全学歴・雇用形態の総計） | 25〜29歳 429万／30〜34歳 492万／35〜39歳 556万／40〜44歳 612万／45〜49歳 653万／50〜54歳 689万／55〜59歳 712万 |
| 資料の主張 | **40代男性の大卒平均は約850万** |

**「日本の平均年収460万」は、パート・学生・シニアを混ぜた数字。壮年期の正社員男性はもっと高い。**

### ここから分かること

1. **院卒プレミアムは年齢とともに開く。** 20代前半はゼロ、30代前半で+134万、40代前半で**+236万**
2. 資料の「40代男性の大卒平均850万」は、厚労省ベースだと**大学卒40〜44歳が725万、45〜49歳が813万**。850万はやや高めの見積り（国税庁と厚労省で定義が違うため）
3. **大学院卒の40〜44歳は961万。** 大卒より236万高い
4. **君が「院卒平均を超える」と言うなら、基準はこうなる**

| 年齢 | **超えるべきライン（男・院卒平均）** |

| 30〜34歳 | **703万** |
| **35〜39歳** | **826万** |
| 40〜44歳 | **961万** |

## 5. 覚えておくこと

- **「日本の平均年収460万」は主婦・学生・シニアのパートを含む数字。比較対象にしてはいけない**
- **君の比較対象は「男性・大学院卒・同年齢」＝30代703万、35〜39歳826万、40代961万**
- **オリックスの友人（法政・学部卒・全国転勤）と比べるときも、正しい相手は「大学卒・男性」の661〜725万**
- 院卒プレミアムは20代ではゼロ。**30代から開いて、40代で+236万になる。** 修士の2年が効いてくるのは30代以降
