# 条件に追加：「35歳で年収900万」— 実測と、満たす会社 / 満たさない会社

本人（2026-09-27）：「同じ高校の子に勝ちたいのは条件に入れてもいいくらい。35で平均900万ならありがたい。
オリックスのその子は30で1000万行くでしょ？ NEC航空宇宙はそれ満たしてないでしょ」

## 0. 結論（先に）

1. **「30歳で1000万」は、オリックスでも一般的ではない。** 有報の平均976万は**44.2歳**時点の数字
2. **「35歳で900万」は、大学院卒の全国平均（推定740〜780万）を15〜20%上回る水準。** 届く会社は限られる
3. **NEC航空宇宙（NAS）は、おそらく満たさない。** 非公表だが、親会社のNEC本体が963万/42.6歳。子会社はその下
4. **この条件を入れると、宇宙業界はほぼ全部落ちる。** ここが本当のトレードオフ

### ここから計算できること

**大学院卒・男性・35〜39歳の所定内給与 458,500円/月**（これは確定値）
→ 年収換算：458,500 × 12 ＝ 550万 ＋ 年間賞与（大企業の相場 4〜5か月 ≒ 190〜230万）
→ **推定 約740〜780万**（残業代は別）

**つまり「35歳で900万」は、大学院卒の平均より 15〜20% 上**。
「ありがたい」どころか、**上位2〜3割に入らないと届かない水準**。

**「30歳で1000万」は、大学院卒 30〜34歳の平均 397,100円/月（年収推定 約640〜670万）の1.5倍**。
オリックスでも一般的とは言えない。参考：東京センチュリー（有報901万）の社員口コミに
「新卒9年目・30歳・担当課長・年収700万円」という実例がある。

## 4. だから決めること（本人の判断）

| 案 | 第一志望群 | 得るもの | 失うもの |
| --- | --- | --- | --- |
| **A：金額を取る** | **NRI**／アクセンチュア／富士通ジョブ型／NEC本体 | 35歳900万に届く可能性。友人に勝てる土俵 | 宇宙は趣味になる |

**私の推奨は C → A の順。**
NEC本体は「宇宙システム（はやぶさ2・衛星）」を自社事業として持っていて、平均963万でオリックスと互角。
宇宙を完全には捨てずに金額で並べる、唯一の選択肢がここ。
ただし**配属は選べない**ので、「宇宙をやりたい」が最優先なら NAS が確実。

## 追記：NRI の「採用実績校に神奈川大学」の出典と、その重みの訂正（2026-09-27）

本人：「NRIが神奈川大学にあるのがマジで違和感。URL出して。神奈川大程度からそれ出たらニュースもん」

### 出典（実物）

**https://job.mynavi.jp/27/pc/search/corp961/outline.html**
（マイナビ2027 株式会社野村総合研究所 → 会社概要 → **採用実績（学校）**）

そのページの「採用実績（学校）」欄 ＜大学院＞ の並びに、確かに「神奈川大学」がある。
前後はこう：**…富山大学、金沢大学、神奈川大学、工学院大学、北九州市立大学…**

### ただし、重みを正しく測るとこうなる

| 項目 | 実測値 |
| --- | --- |
| ＜大学院＞に載っている学校数 | **89校** |
| その中で神奈川大学の位置 | **78番目**（末尾の方） |
| ＜大学＞（学部）のリスト | **神奈川大学は載っていない** |
| NRI の新卒採用人数 | **2025年 503名／2024年 504名／2023年 466名** |
| 年度・人数・職種の内訳 | **表示なし**（何年に何人、どの職種かは分からない） |

**読み方：**
- 年約500名 × 数年＝累計1,500〜2,500名の中に、神奈川大の院卒が**おそらく1〜数名**
- しかもリストの78/89番目＝**上位校が先に並ぶ順序の、末尾**
- NRI は経営コンサル職・システム職など職種が複数あり、**理系とは限らない**
- **学部では実績がなく、院だけにある**

### 訂正

前の記述で NRI を「門は閉じていない」「◎」と書いたが、**実務的には宝くじ枠**と書くべきだった。
「受けてはいけない」ではなく、**「NRIを当てにした計画を立ててはいけない」**が正しい。

**扱いの整理：**
- NRI：記念受験として1社出す。通ったら人生が変わるが、**計画の土台にはしない**
- 計画の土台にするのは **NEC本体（963万/42.6歳・採用301名〜）** と **NAS（★院に神奈川大・採用55名）**
- 「35歳900万」を本気で狙うなら、NRI より **アクセンチュア（採用301名〜・院に日大/都市大/電機大/芝浦/法政/明治あり）** や
  **富士通ジョブ型** の方が、母数が大きく現実的
