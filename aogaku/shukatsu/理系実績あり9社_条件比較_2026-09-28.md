# 神奈川大の理系学科から実績がある9社 — 条件の全比較（2026-09-28）

きっかけ：神奈川大学の「学部・学科別主な就職先一覧（2025年度）」で電通総研を検索したところ、
**法学部 法律学科の1件のみ**で、理学部・工学部・大学院には無かった。
→ 会社側の「採用実績校」ではなく、**大学側の学科別リスト**を正として、志望群を組み直した。

## 0. NECプラットフォームズは「NECの総合研究所」ではない

| | 実態 |
| --- | --- |
| 事業 | **ICTシステム機器の開発・製造・販売・設置・保守**。Wi-Fiホームルータ、企業向けサーバ、業務用端末（POS等）、**衛星通信システム開発**、**光海底ケーブルシステム** |
| 位置づけ | NECの**ハードウェアものづくり子会社**。研究機関ではない |
| 規模 | 売上 **3,126億円**（単独）／従業員 **6,380名**（単独） |
| 特徴 | **平均勤続24.4年**。今回調べた中で最長クラス＝離職が非常に少ない |

**NECの研究組織は「NEC中央研究所」**で、これは本体（日本電気株式会社）の中にある。新卒配属は博士中心。
「総合研究所」を子会社として持つのは、**金融・商社系（NRI＝野村、日本総研＝三井住友、大和総研＝大和、三菱総研＝三菱）**の形で、
**電機メーカーはその形を取らない**（研究所を本体内に置く）。

## 3. 条件で並べ直すとこうなる

### 条件をほぼ全部満たす（上位3社）

| 順 | 会社 | 満たす | 落ちる |
| --- | --- | --- | --- |
| **1** | **NECプラットフォームズ** | 修士314,400／**年休126**／**残業15.7h**／家賃補助／**スーパーフレックス**／賞与年2回／**勤続24.4年**／**★院** | 勤務地に東北（宮城・山形・福島）が入る |
| **2** | **NEC航空宇宙システム** | **修士320,800（最高）**／年休125／家賃補助4万／**コアタイムなし**／賞与年2回／**勤続20年**／**★院**／**宇宙◎** | 残業25.0h・**札幌/仙台/福岡配属の可能性** |
| **3** | **日本アビオニクス** | **横浜市内のみ（通勤最短）**／年休126／**有給19.0日**／家賃補助手当／賞与年2回／**宇宙◎（JAXA認定）**／○学部 | 修士285,000・**35歳497万** |

### 条件を1つ落とす

- **三菱電機D&S**：**家賃補助の記載がない**＋賞与が4月・10月＋兵庫配属あり。ただし**理学部 数理・物理学科からの実績あり＋★院**で、**君の学科から最も近い実績**
- **日本航空電子**：**残業14.1h・年休126**と労働環境は最良クラス。ただし**35歳594万**、神奈川大の実績なし
- **三菱電機ソフトウエア**：**年休120**で条件割れ

### 金額は高いが条件が割れる

- **電源開発**：**35歳961万**。ただし**全国転勤（発電所）・年休122**
- **東京電力HD**：修士317,200・巨大企業。ただし**年俸制（賞与年2回ではない）**・35歳650万
- **三菱電機（本体）**：35歳765万・有給19.3日。ただし**全国転勤**・神奈川大の院実績なし

## 4. 結論

**条件で選ぶなら NECプラットフォームズ。仕事で選ぶなら NEC航空宇宙。通勤で選ぶなら 日本アビオニクス。金で選ぶなら 電源開発。**

そして**この9社は全部、神奈川大の理系学科または大学院から実際に採用実績がある**。
電通総研のように「会社側リストにはあるが理系実績が確認できない」会社とは、確度が違う。
