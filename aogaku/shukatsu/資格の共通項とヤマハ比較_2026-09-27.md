# ① 志望企業の「推奨資格」の共通項 ② ヤマハとの比較 — 2026-09-27

## ①-0 結論：共通項は2つだけだった

志望群20社の「自己啓発支援制度／資格取得支援」欄を1社ずつ読んだ結果、**業種を問わず全社に出てくるのはこの2つ**。

1. **情報処理技術者試験（基本情報 → 応用情報 → 高度）**
2. **TOEIC（語学）**

**君が今やろうとしている「基本情報（12/27）→ TOEIC → 応用情報 → LPIC」は、共通項のど真ん中。**
「EF（基本情報）は本当に意味があるのか」への答えは、**ある**。しかも狙う会社を変えても無駄にならない。

## ①-2 ここから読めること

### (1) 情報処理技術者試験は「業界の共通語」
NAS・富士通・日鉄ソリューションズが名指し。他社も「会社が認めた資格」の中身は実質これ。
**基本情報 → 応用情報 は、どの会社に行っても評価される。ここは迷わなくていい。**

### (2) TOEICは全社にある
NAS（IPテスト支援）・富士通・JAXA（語学助成）・三菱電機D&S（英語能力検定制度）・三菱総研（語学研修）・電源開発（語学補助）。
**資格の中で最も汎用性が高いのは、実は TOEIC。** 10/25 に全振りしている判断は正しい。

### (3) ベンダー資格（LPIC・ORACLE・AWS）は「IT寄りの会社」で追加点
NAS が LPIC・ORACLE、富士通が AWS を名指し。
**LPIC は NAS に行くなら効くが、メーカー系（多摩川精機・三菱電機・電源開発）では効かない。**
→ M1 で取るなら **応用情報が先、LPIC は後**。前に言った順番のままで正しい。

### (4) メーカー／インフラは「現場系」が混ざる
三菱電機＝電気工事士、電源開発＝発電所の技能検定。
**物理出身の君には、情報系よりこちらが取りやすい可能性がある**（電験三種など）。ただし NAS では効かない。

### (5) NRI だけ毛色が全く違う
推奨資格が**証券アナリスト・証券外務員・FP・簿記**。つまり **NRI は「金融の会社」**。
前に「宝くじ枠」と書いたが、**そもそも求めている人材像が君と違う**。記念受験の位置づけで正しい。

## ②-1 額面では君の候補が上。ただし差は思ったより小さい

- **35歳推定：電通総研 962万 ＞ オリックス 784万 ＞ ヤマハ発動機 655万 ＞ ヤマハ 612万**
- NAS は非公表だが、NEC本体（771万）より下・日本航空電子（594万）より上のどこか
- **つまり NAS とヤマハ発動機は、ほぼ同じ帯の可能性がある**

## ②-2 ただし「生活費」を入れると逆転しうる

| | 浜松・磐田 | 横浜・東京 |
| --- | --- | --- |
| 1K の家賃相場 | 4〜5万 | 7〜9万 |
| 実家から通えるか | **通える（＝家賃0）** | 通えない |

**実家通いなら、年間で 80〜110万の差が出る。** 額面655万のヤマハ発動機（実家）と、額面700万台のNAS（横浜で家賃7万）は、
**手元に残る金でほぼ並ぶか、ヤマハ発動機が勝つこともある。**

## ②-3 条件で見るとヤマハ発動機は強い

- **残業13.6時間**は、君の候補群（NAS 25.0h／電通総研 28.9h）より明確に少ない
- **コアレスフレックス**（コアタイムなし）も NAS と同等
- 穴は**年間休日121日**（君の条件125日に届かない）と、**勤務地が静岡＝「関東内」に反する**こと
- **採用実績校に神奈川大学もある**

## ②-4 結論

**「どっちがいいか」は、君が何を最優先にするかで割れる。**

| 優先するもの | 勝つ方 |
| --- | --- |
| **額面の年収** | 君の候補（電通総研962万／NEC本体771万） |
| **手元に残る金（実家通い前提）** | **ヤマハ発動機**（実家なら家賃0） |
| **残業の少なさ** | **ヤマハ発動機（13.6h）** |
| 年間休日 | 君の候補（NAS 125日 vs 121日） |
| 関東で働く | 君の候補 |
| やりたい仕事（宇宙） | 君の候補 |

**君は「①将来のお金 ②学歴・成功体験 ③研究内容」の順だと言った。**
①だけなら電通総研。①と②なら電通総研。**ヤマハ発動機に負けているのは「生活のしやすさ」であって、年収ではない。**

そして重要なのは、**その友人と君は、同じ土俵に立っていない**こと。
静岡に戻るのは「家賃0・通勤10分・地元」という選択で、君が選んだ「関東・宇宙・大手」とは目的が違う。
**比べるなら、額面ではなく「30年後にどういう生活をしていたいか」で比べるべき。**
