### (3) の正しい計算
$a=0$ なら $A = B$、固有値 $2, -1, -1$。最小多項式 $(A-2I)(A+I) = A^2 - A - 2I = 0$ → **$A^2 = A + 2I$**。
- $A^3 = A\cdot A^2 = A^2 + 2A = 3A + 2I$
- $A^5 = A^2\cdot A^3 = (A+2I)(3A+2I) = 3A^2 + 8A + 4I = 3(A+2I) + 8A + 4I = 11A + 10I$
- 合計：$(11A+10I) + 3(3A+2I) - 2(A+2I) + 3A + I = (11+9-2+3)A + (10+6-4+1)I = \mathbf{21A + 13I}$

$$21A + 13I = \begin{pmatrix}13&21&-21\\21&13&-21\\-21&-21&13\end{pmatrix}$$

**検算**（これをやれば符号ミスは自分で見つかる）：固有値を代入する。$\lambda=2$：$32+24-8+6+1 = 55$、$21\cdot2+13 = 55$ ✓。$\lambda=-1$：$-1-3-2-3+1 = -8$、$-21+13 = -8$ ✓。

## 弱点コード
- **B（検算しない）**：(3) は固有値代入で10秒で見つかるミス。多項式の計算は「固有値を入れて左右一致」を必ず最後に1行書く。
- (1)(2) は手順・答えともに正しい。最初の単元でここまで書けているのは、上智問1の型としては合格ライン。
