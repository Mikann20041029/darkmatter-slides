# 矮小銀河の J ファクターに誤差 (約 3 倍) を入れた検定 (2026-10-02、クラウド)

## 結論

1. **9/28 の矮小銀河の予測 (C3) に、使えない天体が 2 つ混ざっていた。** SMC・LMC は標的の中心が拡張源マスクで消え、
   ハローの形が 1〜2% しか残っていない (`usable: false`)。SMC 1 天体が合算予測 2.69σ のうち 2.06σ 分を占めていた。
   使える 43 天体では、DM なら期待される信号は **1.73σ** (局所密度 0.42 GeV/cm³)、密度 0.3〜0.6 GeV/cm³ で **0.85〜3.38σ** (旧 1.35〜5.4σ)
2. **Bertólez-Martínez+ (2026) の J の誤差 (Δlog₁₀J = 0.5、約 3 倍) を入れると**、期待は 1.73σ → 中央値 2.4σ・68% で **1.3〜5.0σ** に広がる。
   実測 (同じ重みでまとめた値) は 0.39σ。ずれは 1.3σ → 1.5σ、空の領域の較正 (1.362) を入れると 1.0σ → 1.2σ
3. ⇒ どの仮定でもずれは較正後 2.2σ 以下。**暗黒物質と矛盾はしないが、確認もできない。** J の誤差を入れると期待の幅が大きく広がり、「判定できない」がより強くなる

## 根拠 (確認済み)

### 使えない天体の混入

- `results/mcmc_allbins_gasICS_v20_constructsplit/other_celestial_body/smc_spectrum.json` の `meta`:
  `halo_frac_valid` 0.0103、`usable: false` (LMC は 0.021、false)。理由は `code/apply_v20_method_targets.py:240-246`
  (LMC/SMC は 4FGL の拡張源。長半径の 2 倍でマスクすると ROI の中心が消える)
- `code/dwarf_consistency_check.py:118-123` は `category == "dwarf"` だけを見て `usable` を見ていない
- 修正案: `cloud_reports/2026-10-02_dwarf_consistency_usable.patch` (`usable` が false の天体を飛ばす 5 行)

### 比べ方の注意 (確認済み)

- C3 は「予測 = √Σpred_i² (最適な重み)」と「実測 = Σmeas_i/√N (重みなし)」を比べていた。まとめ方が違う
- 本レポートでは同じ重み w_i = pred_i で両方をまとめた: T = Σ w_i·meas_i / √Σw_i²。DM が無ければ T ~ N(0, 1)、あれば平均 √Σpred_i²
- 45 天体 (SMC・LMC 込み) だと T = −0.86 で、見かけ上 3.5σ (較正後 2.6σ) の緊張が出る。これは SMC (予測 2.06σ、実測 −1.45σ) の 1 天体が作るもので、
  SMC の測定自体が使えないので意味がない

### J の誤差の入れ方

- 各天体の本当の J = 推定値 × 10^δ_i、δ_i ~ N(0, 0.5²) (独立)。予測は J に比例するので pred_i × 10^δ_i
- 天の川側の局所密度 ρ☉ の仮定: 予測は ρ☉ の −2 乗に比例 (天の川の J が ρ_s² に比例し、天の川の実測フラックスは固定のため)。
  0.3 / 0.42 / 0.6 GeV/cm³ で計算。**注意**: 9/28 の物理レビューは「0.3 で 1.35σ、0.6 で 5.4σ」と書いたが向きが逆 (0.3 で大きく、0.6 で小さい)。幅は対称なので結論は不変
- 20 万回のモンテカルロ。p 値は「DM ありで実測 T 以下になる確率」を δ について平均したもの
- スクリプト: `cloud_reports/2026-10-02_dwarf_J_uncertainty.py`、結果: `…_result.json`、図: `slides/figs/fig_dwarf_J_uncertainty.png`
- 環境: クラウド、Python 3.12.11、numpy 2.5.1。入力は既存の JSON だけ (フィットはしていない)

| 43 天体、20 GeV | 局所密度 | 期待 (中央値、68%) | 実測 T | ずれ (σ=1) | ずれ (σ=1.362) |
|---|---|---|---|---|---|
| J の誤差なし | 0.42 | 1.73 | 0.39 | 1.34σ | 0.98σ |
| **J の誤差あり** | 0.42 | **2.42 (1.32–4.96)** | 0.39 | 1.45σ | **1.22σ** |
| J の誤差なし | 0.30 | 3.38 | 0.39 | 3.00σ | 2.20σ |
| J の誤差あり | 0.30 | 4.74 (2.58–9.72) | 0.39 | 2.26σ | 1.94σ |
| J の誤差なし | 0.60 | 0.85 | 0.39 | 0.46σ | 0.34σ |
| J の誤差あり | 0.60 | 1.19 (0.64–2.43) | 0.39 | 0.79σ | 0.64σ |

- J の誤差は「期待の中央値」を少し上げる (対数正規の上に長いすそが、合計を上に引っ張る)。同時に幅を大きく広げる。
  論文 Section V の「上振れした J が全体を支配する」と同じ現象
- 密度 0.3 で誤差なしのときだけずれが 3.0σ (較正後 2.2σ) になるが、J の誤差を入れると 2.3σ (1.9σ) に下がる
