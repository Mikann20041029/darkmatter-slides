# 最良値の求め方を Totani (2025) と同じ (MCMC) に直して全部計算し直した (2026-10-02、クラウド)

## 結論

1. `code/mcmc_fit_all_bins.py` を Totani §2.2・§2.3 どおりに直した (patch: `cloud_reports/2026-10-02_totani_bestfit.patch`)。
   最良値 = Totani の初期値から emcee (32 歩行者 × 6000 歩) で踏んだ点のうち ln L 最大の点。ハローなしも同じく MCMC。
   有意度 = 両者の最大 ln L の差。誤差 = チェーンの 16–84%。旧方式は `MCMC_TOTANI_BESTFIT=0` で残してある
2. **クラウド (x86_64) で 13 ビン全部を計算: Bin6 (20.8 GeV) 19.45σ。** MCMC は尤度の頂上に届いている
   (勾配法で求めた頂上との差は ln L で 0.6 以下、有意度で 0.28σ 以下。確認用で、結果には使っていない)
3. 結論は何も変わらない: バブル除外 4.97σ、経度ずらし 14.6–16.4σ、ICS 3 分割 18.42σ、矮小銀河の期待 1.77σ (J の誤差込み 68% 1.35–5.07σ)、ずれ 1.30σ (較正後)
