# Totani と同じやり方 (MCMC で最尤値) でも有意度は変わらない (2026-10-02、クラウド)

## 結論

Bin6 (20.8 GeV) を同じ型紙・同じ 10° セル尤度・同じ制約で、2 通りの最尤値の求め方で計算した (クラウド環境 x86_64):

| やり方 | ln L (ハローあり) | ln L (なし) | 有意度 |
|---|---|---|---|
| 本研究: 勾配法 (L-BFGS-B) で最尤値、MCMC は誤差だけ | 239284.5031 | 239099.8948 | **19.215σ** |
| Totani 流: Totani の初期値から emcee、チェーン中の最大 ln L | 239284.3063 | 239099.8226 | **19.209σ** |

差は 0.006σ。ハローの倍率も 1.478 (勾配法) / 1.457 (チェーン中の最大点) / 1.466 (チェーンの中央値) でほぼ同じ。
求めている量 (尤度の最大値) が同じなので、方法の違いは結果を変えない。勾配法のほうが ln L がわずかに高い (= 頂上により近い)。

## 根拠

- Totani (2025) §2.2: "the best-fit values and statistical errors of the fitting parameters f_l are obtained by maximizing the likelihood function using the MCMC method"。§2.3 の初期値 (点源・GALPROP = 1、等方 = E²dN/dE 1e-4、他 = 0) を使った
- スクリプト: `cloud_reports/2026-10-02_totani_style_mcmc_check.py` (emcee 32 歩行者 × 6000 歩、seed 42)
- 環境: クラウド (x86_64)、Python 3.12.11。本人 PC の 19.00σ とは環境の差がある。A と B は同じ環境・同じ型紙で比べている
