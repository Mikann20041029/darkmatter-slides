## 今日覚えること（1個だけ）

**f文字列**: 変数を文字の中に埋め込む方法

```python
name = "Draco"
distance = 76

# f"..." の中に {変数名} と書くだけ
print(f"{name}の距離は{distance} kpcです")
# → Draco の距離は 76 kpc です
```

`f` を先頭につけて、変数を `{}` で囲む。それだけ。
