# + 「銀河の幅」と「DMハロー (2×ビリアル半径)」のスケール比較
# 想定質問: 「±60°ってどれくらいの距離？」「銀河本体に比べてDMハローはどれくらい大きいの？」
# 関連コード: code/plot_roi_physics.py:21-25,102-106 (同じ d=D_sun*tan(b) 換算を使用)
# パラメータ出典: RS, RHO_S, D_SUN, R_VIR は Totani (2025) §2.3 採用値と完全一致

## 1. 角度 → 物理スケールの変換方法 [近似・解釈]

ROI は天球面上の角度 (銀経 l, 銀緯 b) で定義されている。これを物理的な距離に
変換するには「どこまでの距離の構造を見ているか」という仮定が必要であり、
一意には決まらない。本資料では `plot_roi_physics.py:102-106` と同じ近似を採用する:

  「銀河中心 (GC, 距離 D_sun = 8 kpc) を通り視線に垂直な面」を基準とし、
  角度 θ（l または b）だけ GC 方向からずれた視線が、その面を横切る位置までの
  GC からの投影距離を d とすると

      d = D_sun × tan(θ)                                    … (近似式)

  [近似の限界]: 実際には NFW シグナルは特定の距離の「面」にあるわけではなく、
  視線全体に広がって分布する（J-factor は視線積分量）。この式は「GC 距離にある
  構造を見ている」と仮定した場合の目安であり、感覚をつかむための概算である。

## 2. ROI 境界角度の物理スケール換算

  | 角度 θ | d = D_sun・tan(θ) | 意味 |
  |---|---|---|
  | b = 10°（ROI 内側境界、銀河面除外ライン） | 8.0 × tan(10°) ≈ **1.41 kpc ≈ 1,400 pc** | 銀河面から ~1.4 kpc 上下の構造を見ている |
  | b = 60°（ROI 外側境界） | 8.0 × tan(60°) ≈ **13.9 kpc ≈ 13,900 pc** | 銀河面から ~14 kpc 上下まで（銀河円盤の厚みを大きく超える）|
  | l = 60°（ROI 経度境界、b と同じ近似式を適用） | 8.0 × tan(60°) ≈ **13.9 kpc ≈ 13,900 pc** | GC 方向から左右に ~14 kpc 離れた構造まで |
  | 参考: rs = 21 kpc に対応する角度 | arctan(21/8) ≈ 69.1° | ROI 外側境界 (60°) は「NFW スケール半径に相当する角度」のすぐ内側にある |

  [解釈] つまり ROI (|b| = 10°〜60°) は、GC からおよそ 1.4 kpc 〜 14 kpc の
  高さに相当する範囲を切り出しており、この上限 (~14 kpc) は天の川銀河円盤の
  半径スケール (後述、~15 kpc) に近い。「銀河円盤と同程度の物理スケールを
  見渡している」という直感的説明が可能。

## 3. 銀河の幅 vs DM ハロー (2×ビリアル半径) の比較

  - **DM ハローの直径**: 2 × r_vir = 2 × 402 kpc = **804 kpc**
    （r_vir = 402 kpc は本解析・Totani (2025) 共通の Via Lactea II 採用値、
    `plot_roi_physics.py:25`, 比較表⑥で完全一致を確認済み）
  - **天の川銀河（恒星円盤）の直径**: 文献でよく引用される代表値は
    **約 30 kpc**（[要出典・代表値] 銀河円盤の直径として教科書的に広く使われる
    数値。観測によっては拡張円盤を含めて ~50 kpc とする報告もあり、
    幅があることに注意）
  - **比** 2×r_vir / (銀河円盤直径) :
      - 円盤 30 kpc を仮定 → 804 / 30 ≈ **27 倍**
      - 円盤 50 kpc を仮定 → 804 / 50 ≈ **16 倍**

  [解釈・結論] 採用する円盤直径の値に依存するが、いずれにせよ
  **DM ハローは目に見える銀河円盤の十数〜数十倍の広がりを持つ**。
  「私たちが観測している星の集まり（円盤）は、はるかに巨大な暗黒物質ハローの
  ごく中心部分に過ぎない」という構図を、数値で裏付けることができる。

## 4. 結論（スライド用一文）

「ROI の外側境界 |b|=60° は、銀河中心からおよそ 14 kpc の高さに相当し
（d = D_sun・tan(60°)）、これは銀河円盤の半径スケールに匹敵する。
一方で DM ハローの直径 (2×r_vir = 804 kpc) は銀河円盤直径 (~30 kpc) の
約 27 倍であり、観測している領域は広大なハローのごく一部に過ぎない。」
