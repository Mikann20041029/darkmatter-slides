# 感度分析: Bin6 (20.76 GeV) の NFW S/N が主要パラメータ ±20% でどう変わるか
# 関連コード: code/all_bins_nfw_fit.py、再現スクリプト: /tmp/sensitivity_bin6.py
# 結果: data/figure-sensitivity/bin6_sensitivity.json
# 実行環境: コミット 5d2f3ca 時点、Bin6 (E=20.76 GeV, 56,533 イベント)、N_LOS=500

## 結論（スライド用）

1. **baseline の S/N = +0.232σ は f91845c で確認した修正後の値（+0.24σ）と一致**し、
   再現性が確認された（コミット 5d2f3ca、N_LOS=500、同一スクリプト構造）

2. **最も敏感なパラメータはフェルミバブルの境界定義**:
   緯度範囲 (|b| ∈ [15°,50°]) を ±20% 変えるだけで S/N は **-4.5σ 〜 +5.85σ** という
   符号も大きさも全く異なる結果に変わる（Δ振れ幅 ≈ 10.4σ）。
   経度境界 (|l|<22°) でも ±1.5σ 程度動く。
   → 「20 GeV ハロー超過」の有意度は、**ハードコードされた背景差引境界の
   恣意的な選び方に強く依存**しており、単一ビンの σ 値だけでは結論を語れない
   ことを定量的に示す好材料となる

3. **NFW スケール半径 r_s も無視できない感度を持つ**:
   ±20% (16.8〜25.2 kpc) で S/N は -0.92σ 〜 +1.75σ に変動する。
   これは Totani 自身も §4.3.3 で指摘する「MW ハロー密度プロファイルの
   不確かさ」が解析結果に直結することの直接的な実証になる

4. **等方背景閾値の感度は相対的に小さい** (+0.03〜+0.54σ)。
   これは ROI 内で |b|>50° の領域が比較的狭く、推定平均値への影響が
   限定的であるため

## 解釈・スライドでの使い方（提案）

「我々の解析で得られた Bin6 S/N (+0.24σ) は、背景差引境界を ±20% 変えるだけで
 -4.5σ 〜 +5.85σ まで振れる。これは『単一ビンの有意度』という指標が、
 ハードコードされた領域定義に強く依存する不安定な量であることを示しており、
 σ_A 推定法依存性 (f91845c) と合わせて『単一ビン有意度の方法論依存性』を
 示す二重の証拠になる。Totani(2025)はこの不確かさを MCMC 全成分同時フィットで
 軽減しているが、本解析のような単純な逐次差引では、領域定義の恣意性が
 結果を支配しうることを正直に示す」

## 判断・後回し事項

- 本分析は Bin6 1ビンのみ、4パラメータ系列(各±20%)の単独変動について実施。
  パラメータ間の相関や全13ビンへの展開は計算コスト上、後回しとした
- 等方背景閾値・NFW r_s 以外（GALPROP b0 はフィットパラメータのため対象外、
  ループI境界は未実施）は判断材料が必要なら追加実行可能
  (`/tmp/sensitivity_bin6.py` の `variants` 辞書に追加するだけで拡張できる)
