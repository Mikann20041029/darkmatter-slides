## Abstract（要旨）— p.1

### 何が書いてあるか

一言で言うと：**DAMPE 衛星が Fermi-LAT 以外の装置として初めて、フェルミバブルと銀河中心 GeV 超過の両方を独立検証した。**

箇条書きで整理すると：
- 装置：DAMPE（中国の宇宙γ線望遠鏡）
- データ：102 ヶ月（2016–2024 年）
- 主結果①：フェルミバブルを **26.5σ** で検出
- 主結果②：銀河中心（GC）GeV 超過を **7.5σ** で検出
- 両者の形態とスペクトルは Fermi-LAT 先行研究と整合
- DM解釈：mχ ≈ 50 GeV、⟨σv⟩bb ≈ 10⁻²⁶ cm³/s（χχ → bb̄ チャンネル）

### 知らないといけない用語

| 用語 | 意味 |
|---|---|
| **DAMPE** | Dark Matter Particle Explorer。中国の宇宙γ線・宇宙線観測衛星（2015年12月打ち上げ） |
| **フェルミバブル（Fermi Bubbles）** | 銀河中心上下に広がる約50°の巨大γ線バブル構造（Su+2010 発見） |
| **銀河中心GeV超過 (GCE)** | GC方向の数 GeV にある既知のγ線超過。DM消滅 or ミリ秒パルサーが候補 |
| **TS値（Test Statistic）** | 検出有意度の指標。TS = -2Δln L、有意度 ≈ √TS σ（Wilks定理） |

★ **卒論との接続**: Totani (2025) が 20 GeV の MW ハロー超過を発見したのに対し、この論文は 1–3 GeV の GC 超過を検出しています。**異なるエネルギー・異なる領域の信号**であることに注意。

## §1 Introduction（序論）— p.1–2

### 段落ごとの解説

#### 第1段落：GC 領域の重要性

銀河中心（GC）は超大質量ブラックホール、DM 密度のピーク、宇宙線源が集中する「極端な場所」。高エネルギーガンマ線天文学コミュニティの主要な観測対象。

GCが DM 間接探索に重要な理由：
- DM 密度プロファイルが GC に向かって急増 → DM 消滅率 ∝ ρ² が最大
- Fermi-LAT が 1° 領域の拡散放射を発見（GC GeV 超過）
- ただし GC 付近は前景放射が複雑で系統誤差が大きい

#### 第2段落：GC GeV 超過とその解釈

GCE は Goodenough & Hooper (2009) 以降多くのグループが確認しているが、起源は未決定：

| 仮説 | 支持する根拠 |
|---|---|
| **DM 消滅** | 球対称形態、DM 密度と一致するプロファイル |
| **ミリ秒パルサー（MSP）** | MSP の空間分布が GCE と類似 |
| **宇宙線カーバチャー放射** | 宇宙線電子の bremsstrahlung + IC |

#### 第3段落：フェルミバブル

- Su & Finkbeiner (2010) が Fermi-LAT データで発見
- 銀河中心上下に約 40° 幅 × 55° 高さの2つのローブ
- スペクトル：0.1–100 GeV のハードスペクトル、カットオフ ~100 GeV
- 起源不明（過去の AGN ジェット、銀河風、星形成アウトフローなど）

#### 第4段落：DAMPE の特徴と位置づけ

DAMPE が Fermi-LAT より優れる点：
- **高エネルギー分解能**（特に 50 GeV 以上）
- **低い宇宙線汚染**（電子 15%減、陽子 50%減）
- Fermi-LAT とは完全に独立した装置 → **独立検証**として価値が高い

★ **卒論との接続**: この論文は Totani (2025) の Fermi-LAT 解析への独立した補完的検証です。ただし対象信号が異なります（GCE vs MWハロー超過）。

### §2.3 ビン×ビン尤度解析

尤度関数（ポアソン対数尤度）：

$$\ln \mathcal{L}(\boldsymbol{\Theta}) = \sum_{ij} \left[ N_{ij} \ln(\tilde{\mu}_{\mathrm{tot},ij}) - \tilde{\mu}_{\mathrm{tot},ij} \right]$$

- $N_{ij}$：観測カウント（空間ビン $i$、エネルギービン $j$）
- $\tilde{\mu}_{\mathrm{tot},ij}$：モデル予測カウント
- TS = $-2\Delta \ln \mathcal{L}$ で有意度を評価

**Totani との方法論の違い**：
- DAMPE：全成分を MCMC で同時フィット
- Totani（私たち）：逐次差し引き（sequential subtraction）

★ **卒論との接続**: 私たちの解析は DAMPE の完全な同時フィットと異なり、各成分を順番に差し引く近似的方法です。これが系統誤差の主な原因の一つ。

## §3 Fermi Bubbles（フェルミバブル）— p.5–7

### §3.1 バブルテンプレートの定義

DAMPE は Fermi-LAT の既存テンプレートを使わず、**自前のデータから独立にテンプレートを作成**しています：

1. **null model**（バブルなし）でフィット
2. 残差マップを計算：(観測 − モデル)/√モデル
3. 残差の有意度が $2\sigma_{bg}$ を超える領域をバブルとして定義
4. Su+2010 のフラットバブルテンプレートを初期値として反復改良

**これが重要な理由**：Fermi-LAT テンプレートへの依存を排除 → 独立検証として価値が高い

### Figure 1 の読み方（p.6）

Figure 1 は 2 つのパネル：

**上段左（観測強度マップ、2–500 GeV）**：
- 銀河面が黒帯（|b|<5° マスク）
- バブル内部（白線）が全体的に明るい

**上段右（null model ベストフィットマップ）**：
- バブルなしのベストフィット。バブル領域で光子不足が見える

**下段左（null model 残差有意度マップ）**：
- バブル内部（白線）に赤い正の残差 → バブルの「見え方」
- Fermi-LAT の先行境界（色分けした点線）とよく一致

**下段右（バブルあり alternative model 残差）**：
- バブルを入れると残差がほぼゼロ → バブルモデルが有効

### Figure 2 の読み方（p.6）

左：残差有意度の分布（ヒストグラム）
- 黒：ROI 全体
- 赤：バブル内
- 緑：バブル外
- バブル内は正側に大きくシフト → バブルがある証拠

右：$2\sigma_{bg}$ カット後のバブル境界マップ（白実線）
- この境界が「DAMPE が独自に決めたバブルの輪郭」

### §3.2 フェルミバブルのスペクトル解析

**Figure 3（p.6）**：バブルエッジからの距離とフラックスの関係
- エッジ（距離 = 0）でフラックスが急変 → シャープなエッジ確認
- バブル内部はフラット → フラットテンプレートの妥当性を確認

**Figure 4（p.7）**：全成分 SED（エネルギービンごと平均フラックス）
- 左：バブルを含む全成分フラックス（ROI 内平均）
- 右：バブルのみの SED（Fermi-LAT と比較）

**バブルのスペクトル最適フィット**：
$$\frac{dN}{dE} \propto E^{\Gamma_1} \exp\left(-\frac{E}{E_{\rm cut}}\right)$$

| パラメータ | 全体 | 北ローブ | 南ローブ |
|---|---|---|---|
| $\Gamma_1$ | −1.99 ± 0.06 | −1.95 ± 0.12 | −2.01 ± 0.08 |
| $E_{\rm cut}$ | 204 GeV | 174 GeV | 221 GeV |
| TS | 757.4 | 236.8 | 533.5 |
| 有意度 | **26.5σ** | 14σ | 22σ |

**Figure 5（p.7）**：南北ローブ別 SED
- 北（青）と南（橙）でスペクトルがほぼ一致 → 同一起源

### §3.3 フェルミバブルの形態

南バブルは北より統計的に明確（北半球は銀河拡散放射が強いため）。DAMPE が導いた境界は Fermi-LAT の先行研究（Su+2010, Ackermann+2014, Keshet+2017）と 6% 程度の差で一致。

★ **卒論との接続**: 私たちは 4.3 GeV 残差マップからフェルミバブルテンプレートを作成しています（Totani と同じ方法）。DAMPE は独自にデータから境界を決定しており、結果が一致することがこのアプローチの正当性を支持します。

## §4 Galactic Center Excess（銀河中心GeV超過）— p.8–13

### §4.1 ベースラインモデルでの GCE 検出

**解析領域（GCE 用 ROI）**：
- $1° \leq |b| \leq 20°$、$|\ell| \leq 20°$（40° × 40°）
- 空間ビン：0.1° × 0.1°（CAR 投影、400 × 400 ピクセル）
- エネルギービン：20 個（2–200 GeV、対数等間隔）

**GCE テンプレート（gNFW J 因子）**：

$$J(\ell, b) \equiv \int_{\rm l.o.s.} \rho_{\rm dm}^2(r(\ell, b, s)) \, ds$$

$$\rho_{\rm dm}(r) = \frac{\rho_0}{\left(r/r_s\right)^\gamma \left(1 + r/r_s\right)^{3-\gamma}}$$

- スケール半径 $r_s = 20$ kpc
- 内部密度勾配 $\gamma = 1.2$（ベースラインモデル）
- 正規化：$\rho_0$ は $\rho_{\rm dm}(R_0) = 0.4$ GeV cm⁻³、$R_0 = 8.5$ kpc

### Figure 6 の読み方（p.9）

**上段左（観測強度マップ、2–200 GeV）**：
- 銀河面マスク（|b| < 1°）で黒帯
- 点源（DAMPE カタログ）を緑バツで表示

**上段右（null model ベストフィット）**：
- GCE なしのモデル予測

**下段左（null model 残差有意度）**：
- GC 付近（中央の点線円、5° 半径）に赤い超過 → GCE の視覚的証拠

**下段右（gNFW モデル込みの残差）**：
- GCE を入れると中央の超過がほぼ消える → モデルが有効

**検出有意度**：TS = 80.1 → 有意度 **7.5σ**

### Figure 7 の読み方（p.9）

GC からの角度ごとの残差フラックス：
- 灰色点：null model の残差（GCE なし）
- 青点：gNFW テンプレート込みの残差（GCE あり）
- 超過は $r \lesssim 2°$ に集中 → GC 中心に強く集中した超過

### §4.2 形態研究

**Figure 9（p.10）**：gNFW プロファイルパラメータの尤度プロファイル

| パラメータ | 最適値 |
|---|---|
| 内部密度勾配 $\gamma$ | $1.23 \pm 0.08$ |
| 楕円率 $\varepsilon$ | $1.0^{+0.3}_{-0.2}$（球対称と整合） |
| 中心位置 $d\ell$ | $-0.1^{+0.04}_{-0.2}°$（GC 動力学中心と整合） |

$\gamma = 1.23$ > 1.0（標準 NFW）→ バリオン収縮効果（断熱収縮）の示唆

**Figure 10（p.10）**：空間モデル比較

| モデル | TS (2–200 GeV) | TS (2–20 GeV) |
|---|---|---|
| gNFW ($\gamma$ = 1.2) | **80.1** | **73.8** |
| X-shaped bulge | 78.8 | 66.4 |
| Boxy bulge (C20NP) | 77.8 | 70.8 |

→ gNFW が統計的に最良だが、バルジモデルも許容範囲

### §4.3 系統不確かさ

**Figure 11（p.12）**：GCE スペクトルへの4つの系統誤差の影響

(a) マスクの変更 → TS 変化は小さく GCE は有意に残存  
(b) バブルテンプレートの変更 → 最も変化するがそれでも 5–6.5σ  
(c) 点源モデルの変更 → ほぼ変化なし  
(d) GDE（拡散放射）モデルの変更 → 6σ 程度で GCE は持続  

→ GCE は各種系統誤差に対してロバスト

### §4.4 DM パラメータへの含意

**GCE スペクトル（Figure 8、Table 4）**：

| エネルギー [GeV] | $E^2 dN/dE$ [$10^{-6}$ GeV cm⁻² s⁻¹ sr⁻¹] | TS |
|---|---|---|
| 2.00–3.17 | 3.27 ± 0.67 | 25.3 |
| 3.17–5.02 | 2.05 ± 0.47 | 21.0 |
| 5.02–7.96 | 2.05 ± 0.44 | 24.2 |
| 12.6–20.0 | < 1.42 | 2.9 |

→ スペクトルは **1–3 GeV でピーク**、12 GeV 以上はほぼ上限値のみ

**Figure 13（p.14）**：DM 消滅スペクトルのフィット

DM 消滅 γ 線フラックス：

$$\frac{dN}{dE} = \frac{1}{4\pi} \cdot \frac{\langle\sigma v\rangle_f}{2m_\chi^2} \cdot \frac{dN_f}{dE} \times J$$

**最良フィットパラメータ（Figure 14、Table 4 より）**：

| チャンネル | $m_\chi$ [GeV] | $\langle\sigma v\rangle$ [cm³/s] |
|---|---|---|
| $\chi\chi \to b\bar{b}$ | $49^{+16}_{-12}$ | $(1.9^{+0.4}_{-0.3}) \times 10^{-26}$ |
| $\chi\chi \to \tau^+\tau^-$ | $13.0^{+1.0}_{-1.8}$ | $(6.0 \pm 0.9) \times 10^{-27}$ |

**Figure 14（p.14）**：$m_\chi - \langle\sigma v\rangle$ 制約平面
- 赤実線/破線：DAMPE の 1σ・2σ 等高線
- 黒点鎖線/破線：Fermi-LAT 先行研究（Calore+2015, Cholis+2022）と整合
- 青点線：矮小銀河観測の 95% 上限値（McDaniel+2024）

一部のパラメータ空間は矮小銀河観測で除外される。

## §5 Conclusion（結論）— p.13–14

### 主な結論

1. **フェルミバブル独立検証**：DAMPE データで 26.5σ で検出。Fermi-LAT と形態・スペクトルが整合。フェルミバブルは独立な 2 つの宇宙線望遠鏡によって確認された。

2. **GC GeV 超過独立検証**：7.5σ で検出。これも Fermi-LAT と整合。スペクトルは 1–3 GeV にピーク。

3. **DM 解釈**：GCE を bb̄ チャンネルで解釈すると mχ ≈ 49 GeV、⟨σv⟩ ≈ 1.9×10⁻²⁶ cm³/s。Fermi-LAT 先行研究と整合。

4. **将来展望**：Very Large Area Space Telescope (VLAST) により、フェルミバブルと GCE のさらなる解明が期待される。

### 何が違うか

| 項目 | DAMPE (Alemanno+2026) | Fermi-LAT (Totani+2025) |
|---|---|---|
| 検出器 | DAMPE 衛星（中国） | Fermi-LAT 衛星（NASA） |
| データ期間 | 2016–2024（8.5年） | 2008–2023（15年） |
| エネルギー範囲 | 2–200 GeV | 1.5–814 GeV |
| 解析 ROI | GCE: 40°×40° | MWハロー: |l|≤60°, |b|≤60° |
| 検出対象 | GCE（GC近傍、1–3 GeV） | MWハロー超過（20 GeV） |
| 等方背景の扱い | 露出マップ比例（自由） | |b|≥50° 平均差し引き |
| フィット方法 | MCMC 同時フィット | 逐次差し引き |
| DM 質量示唆 | mχ ≈ 49 GeV (bb̄) | mχ ≈ 500 GeV (bb̄) |

### なぜ DM 質量が全く違うのか？

これは矛盾ではなく、**異なる信号を見ている**からです：

- **DAMPE GCE**：GC 近傍（~数°）に集中した 1–3 GeV の超過。mχ ≈ 49 GeV の DM が GC 近傍の dense core で消滅。
- **Totani MW ハロー超過**：MWハロー全体（|b| > 10°）に広がった 20 GeV の超過。mχ ≈ 500 GeV の DM が MW ハロー全体で消滅。

もし両方が DM 消滅なら、**2 種類の DM が共存**しているか、**どちらかが DM ではなく天体物理的起源**である可能性があります。この未解決の矛盾は、将来の観測（VLAST、CTA など）が解明すべき課題です。

★ **卒論との接続**: 私たちの卒論は Totani (2025) の MW ハロー 20 GeV 超過を追っています。DAMPE の GCE は参考になる独立研究ですが、直接的な比較対象ではありません。「同じ DM かどうか」という問いは卒論の Discussion で触れる価値があります。
