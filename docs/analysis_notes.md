## 1. 生データについて

### 1-1. 観測装置

| 項目 | 内容 |
|---|---|
| 衛星 | GLAST（現 Fermi 衛星） |
| カメラ | LAT（Large Area Telescope） |
| データバージョン | Pass 8 Release 3（P8R3） |

### 1-2. データの取得方法

HEASARCのFTPサーバーから**週単位の全天・全エネルギーFITSファイル**を直接wgetで取得した。

```bash
cd fits/
for w in $(seq -f "%03g" 9 18); do
  wget "https://heasarc.gsfc.nasa.gov/FTP/fermi/data/lat/weekly/photon/lat_photon_weekly_w${w}_p305_v001.fits"
done
```

**取得した期間：w009〜w018（10週間）**
- 観測開始：2008年8月4日
- 観測終了：2008年10月9日

> **注意：** NASA の LATDataQuery.cgi を使えば、取得時点でエネルギー範囲・期間・天域を指定できる。  
> 今回は週単位ファイルを直接DLしたため、エネルギー範囲の絞り込みはDL後のフィルタリングで行った。  
> 観測期間（何週分DLするか）だけはDL時点で自分で決めた。

### 1-3. 生データの中身（FITSファイル）

FITSファイルは `EVENTS` という拡張HDUに全光子データが格納されている。

| 項目 | 値 |
|---|---|
| 総光子数（フィルタ前） | 5,737,716個 |
| 列数 | 23列 |
| 合計容量（10週分） | 562.6 MB |

主な列：`ENERGY`, `RA`, `DEC`, `L`, `B`, `ZENITH_ANGLE`, `TIME`, `EVENT_ID`, `RUN_ID` など23列。

## 2. データ加工：FITSからCSVへ（`make_filtered_csv.py`）

### 2-1. フィルタリング条件

生データの5,737,716個の光子に対し、Totani (2025) Section 2.1 に従って4つの条件を適用した。

| 条件 | 値 | 理由 |
|---|---|---|
| エネルギー | E ≥ 1 GeV | 低エネルギーは角度分解能が悪い |
| 天頂角 | θ < 100° | 地球大気由来のγ線を除去 |
| 銀経（ROI） | \|l\| ≤ 60° | 解析領域外を除外 |
| 銀緯（ROI） | 10° ≤ \|b\| ≤ 60° | 銀河面と端を除外 |

### 2-2. フィルタリング後の変化

| | フィルタ前 | フィルタ後 |
|---|---|---|
| 光子数 | 5,737,716個 | 38,671個 |
| 通過率 | — | **0.67%** |
| 容量 | 562.6 MB | 2.57 MB |
| 圧縮率 | — | **約219倍** |

> **補足：** 容量が大きく減った理由は2つある。  
> ① フィルタリングにより光子数が5,737,716個 → 38,671個（**0.67%のみ通過**）と激減した。  
> ② 解析に不要な列を除いて23列 → 7列に削減した。  
> ピクセルごとの平均化は**一切行っていない**。光子1個 = 1行のまま保存。データ量の減少はあくまでフィルタリングと列削減による。

## 5. 全成分の差し引き（`plot_skymap_all_subtracted.py`）

差し引く順序はTotani Section 2.3 に対応。

### Step 1：等方背景（Isotropic）

宇宙全体から一様に来るγ線。銀河から最も遠い高銀緯帯（|b| > 50°）の平均カウントを全ピクセルから引く。

```
差し引き量 = |b| > 50° 領域の平均値
```

### Step 2：銀河面拡散放射（GALPROP proxy）

銀河円盤内の宇宙線が星間ガスと衝突して出るγ線。本来はGALPROPモデルFITS（3GB）が必要だが、現状はデータから推定した指数関数プロファイルで近似している。

```
プロファイル = A × exp(−|b| / b0)   ← scipy.optimize.curve_fit でフィット
```

### Step 3：既知点源マスク（4FGL-DR2カタログ）

ブレーザー・パルサーなど**個別の既知天体**が出すγ線。

- 使用カタログ：4FGL-DR2（Fermi-LAT 12年分の公式点源カタログ）
- 収録点源数：6,659個
- ROI内でマスクした点源数：**1,274個**
- 方法：カタログの銀河座標に対応するピクセルをNaN（解析除外）にする

> σクリッピング（統計的推測）ではなく、物理的に確認された天体座標を直接使うことで、Totaniさんの手法に忠実な再現になる。

### Step 4：フェルミバブル（Fermi bubbles proxy）

銀河中心から上下に伸びる巨大なγ線構造（起源不明）。幾何テンプレート内の平均値を引く。

```
テンプレート領域：|l| < 22°、15° < |b| < 50°
```

### Step 5：ループI（Loop I proxy）

太陽系近くにある古い超新星残骸の殻が出すγ線。幾何弧テンプレートの平均値を引く。

```
テンプレート：中心(l=−31°, b=18°)から角距離40〜70°の弧、かつb > 10°
```

### 差し引き後の残差

```
残差 = 観測 − 等方背景 − 銀河拡散 − 既知点源(NaN) − バブル − ループI
     ≈ ノイズ ＋ （DMハロー信号）
```

## 6. NFWハロープロファイルフィット（`plot_nfw_halo_fit.py`）

### 6-1. NFW（Navarro-Frenk-White）とは

ダークマターが銀河ハロー内でどう分布するかを表す理論式。

```
ρ(r) = ρs / ( (r/rs) × (1 + r/rs)² )
```

| パラメータ | 値 | 意味 |
|---|---|---|
| rs | 21 kpc | スケール半径（Via Lactea II） |
| ρs | 8.1×10⁶ M☉/kpc³ | スケール密度 |
| d_sun | 8.0 kpc | 太陽–銀河中心距離 |

銀河中心に近いほど密度が高く、外に向かってなだらかに減少する球対称分布。

### 6-2. J-factorマップ

ダークマターが対消滅してγ線を出す場合、その強度は視線方向のρ²の積分（J-factor）に比例する。

```
J(l, b) = ∫ ρ²(r(s)) ds   （視線方向に数値積分）
```

計算結果：銀河中心付近が最も明るい球対称の「もや」状マップ（120×120ピクセル）。

### 6-3. フィット

各エネルギービンで以下の式のAを最小二乗法で推定する。

```
残差マップ = A × NFWテンプレート
```

| Aの状態 | 意味 |
|---|---|
| A > 0 かつ S/N高い | 残差にNFWの形の信号あり → **DM検出** |
| A ≈ 0 | シグナルなし |
| A < 0 | 背景の引きすぎ（近似誤差が支配） |

### 6-4. 10週分の結果

| ビン | エネルギー | A | σ | S/N |
|---|---|---|---|---|
| 06 | 20.76 GeV | −0.46 | 0.27 | 1.70σ |

全ビンでAが負：GALPROPが近似のため低エネルギー側で引きすぎが発生している。  
20 GeV付近のS/N = 1.70σ：ノイズに埋もれており、現時点では検出に至らない。

> **解釈：** これは想定通り。10週（398光子/Bin06）では統計が不足。  
> Totaniさんは780週（≈78倍）で13〜19σを検出。データ増量で σ が 1/√78 ≈ 1/9 に改善する見込み。
