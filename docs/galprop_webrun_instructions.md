# GALPROP WebRun 実行手順(ユーザー本人の操作が必要)

教授指摘「GALPLOPのwebrunで実装」への対応。**この作業はあなた自身のアカウントでの操作が必要**なため、私(AI)が代行できない。以下の手順通りに進めれば完了する。

## なぜ自動化できないか

`galprop.stanford.edu` の WebRun サービスはログインアカウントを持つユーザーのジョブとしてStanfordの計算クラスタ上でGALPROPを実行する仕組み。2026-07-10時点でサイトを調査したところ、`galprop.stanford.edu/forum/` (phpBBフォーラム)経由のアカウント登録・ログインが必須で、ジョブ投入もWeb UIのフォーム経由。個人アカウントの作成・利用規約への同意はあなた本人が行うべき操作であり、代行すべきでない。

## 手順

1. **アカウント登録**
   - `https://galprop.stanford.edu/` にアクセス(サイトが混雑時「Too many connections」エラーが出ることがある。時間を置いて再試行)
   - `forum/` からアカウント登録(ユーザー名・メールアドレスが必要)
   - 登録後、WebRunページ (`https://galprop.stanford.edu/webrun.php` からリンクされる `webrun/`) にログイン

2. **galdef(実行パラメータ)の設定**
   - `six_component_comparison_table.txt` に記載の通り、Totani (2025) は GALPROP モデル **`S_LZ_6R_30T_150C_2`** を使用している(§2.3, p.4引用)。この galdef ID が意味する具体的パラメータ(伝播ハローの半径 R・半高 Z、CR源の空間分布モデル等)は galdef 命名規則から逆算できるが、**確証を取らずに数値を決め打ちしない**。以下のいずれかで正確な値を確認すること:
     - Totani (2025) 論文本体(`ref/20Gev_gamma_ray.paper.2025-Nov-23.pdf`)に galdef の詳細パラメータ表があれば転記
     - GALPROPフォーラム(`forum/`)で `S_LZ_6R_30T_150C_2` を検索し、該当する galdef ファイルを探す
     - 見つからない場合、WebRunのデフォルトテンプレートから「GALPROP標準拡散モデル」に近いものを選び、その旨をスライド・論文に明記する(教授に確認を仰ぐのも一案)
   - 出力に `gll_iem_v07.fits` と同等のガンマ線スカイマップ(全天、エネルギービン付き)を含める設定にする

3. **ジョブ投入・待機**
   - WebRun UI でジョブを投入すると、Stanfordのクラスタ上でキューイングされ実行される(混雑時は数時間〜数日待つこともある)
   - 実行中はリアルタイムログがWebRunページで確認できる

4. **結果の取得**
   - 完了後、結果アーカイブ(URLで共有可能)からガンマ線スカイマップFITSをダウンロード
   - ダウンロードしたファイルを `ref/galprop_webrun_output.fits`(仮称)として本リポジトリに配置
   - 私に知らせてもらえれば、その時点で `code/galprop_comparison.py` の `FITS_PATH` をこのファイルに向けて再実行し、指数関数近似との偏差を再定量化する

5. **記録**
   - 使用した galdef パラメータ・ジョブID・完了日時を `.dev/HANDOFF.md` か `docs/analysis_notes.md` に記録しておく(再現性のため)

## 私が代わりにできること

- ジョブ投入前のgaldefパラメータの妥当性レビュー(Totani論文との整合確認)
- 結果FITSが届いた後の解析コードへの組み込み・比較図の再生成
- ローカルにコンパイル済みの `tools/galprop/galprop` バイナリでの実行(WebRunでなくローカル実行でよい場合、ISRF+ガスリングデータの入手方法さえ分かれば私が実行可能。ただしこちらも `galprop.stanford.edu` のアカウントでのデータダウンロードが必要な可能性が高く、要確認)
