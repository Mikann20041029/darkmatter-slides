# ファイル名・フォルダ名の付け方

迷ったときは、次のルールにそろえてください。

## 基本ルール

1. ファイル名には、英数字・ハイフン (`-`)・アンダースコア (`_`) を使う
2. 日本語、空白、記号はできるだけ避ける
3. 日付を入れるときは `YYYY-MM-DD` 形式にする
4. 何のファイルかわかる短い語を入れる
5. 同じ種類のファイルは、命名パターンをそろえる

## 避けたい名前

- `final`
- `final2`
- `final_latest`
- `test`
- `memo`

このような名前だけでは内容や新旧がわかりにくくなります。

## バージョン違いの扱い

バージョン違いは、可能なら GitHub で履歴管理することを推奨します。  
`final`, `final2`, `final3` のように増やすより、必要な区切りで commit を残す方が後で追いやすくなります。

どうしてもファイル名で区別したいときは、`v01`, `v02` のように桁をそろえるか、`draft`, `submitted` など状態がわかる語を使ってください。

## 例

- `2026-04-10_meeting.md`
- `exp01_result.csv`
- `sampleA_spectrum.png`
- `slide_draft_2026-07-01.pdf`

迷ったら、「日付 + 内容」または「対象 + 内容」の形にすると失敗しにくいです。
