## 1. そもそも何をしたかったか

Totani（2025）という論文が「天の川銀河のハローから20GeVのγ線過剰が見つかった」と報告している。  
これがダークマターの証拠かもしれない。  
この卒論では、**まず同じデータを使って同じ結果を再現すること**を目標とする。

そのための最初のステップとして、**Fermi-LAT衛星が観測したγ線データを入手し、人間が読める形に変換してプロットする**ことを行った。

---

## 2. Fermi-LATとは

- NASAの**フェルミ宇宙望遠鏡**に搭載されたγ線検出器
- 2008年から現在まで稼働中
- 宇宙から来るγ線（超高エネルギーの光）を1光子ずつ記録している
- データは**週単位のFITSファイル**として公開されている

---

## 3. FITSファイルとは

| 項目 | 内容 |
|---|---|
| 形式 | バイナリ（人間が直接読めない） |
| 中身 | 1行＝1光子のイベントテーブル |
| 主な列 | エネルギー、方向（銀経・銀緯）、時刻など |
| ファイル名 | `lat_photon_weekly_w009_p305_v001.fits` |

ファイル名の意味：
- `weekly` ＝ 1週間分のデータ
- `w009` ＝ 第9週（2008年8月4日〜）
- `p305` ＝ Pass 8 Release 3（最新の解析バージョン）

---

## 4. やったこと（ステップ別）

### Step 1：データのダウンロード

HEASARCという天文データサーバーから、週次FITSファイルをダウンロードした。

```bash
# Ubuntuターミナルで実行
cd /root/grad-nakamura/fits
for w in $(seq -f "%03g" 9 18); do
  wget "https://heasarc.gsfc.nasa.gov/FTP/fermi/data/lat/weekly/photon/lat_photon_weekly_w${w}_p305_v001.fits"
done
```

取得したファイル：w009〜w018（10週分、2008年8月〜10月）

---

### Step 2：FITSをCSVに変換（フィルタリングあり）

**使ったコード：** `code/make_filtered_csv.py`

FITSファイルを読み込み、Totani（2025）が使った条件でフィルタリングしてCSVに書き出した。

**フィルタ条件の意味：**

| 条件 | 数値 | 理由 |
|---|---|---|
| エネルギー | E ≥ 1 GeV | 低エネルギーはγ線の方向がぼける（角度分解能が悪い） |
| 天頂角 | θ < 100° | 地球大気に近い方向は大気起源のγ線が混入する |
| 銀経 | \|l\| ≤ 60° | Totaniの解析領域（ROI）に合わせる |
| 銀緯（下限） | \|b\| ≥ 10° | 銀河面（銀河ディスク）は星が多すぎてDM信号が埋もれる |
| 銀緯（上限） | \|b\| ≤ 60° | 同じくROIに合わせる |

**出力ファイル：** `data/CSV/filtered_events.csv`

```
# energy_GeV: 光子エネルギー [GeV] | l_deg: 銀経 [度] | b_deg: 銀緯 [度] | ...
energy_GeV, l_deg, b_deg, ra_deg, dec_deg, zenith_angle_deg, time_met_s
1.23456, 34.567, 15.234, ...
```

- 総イベント数：**38,671光子**（10週分）
- 1行＝1光子

---

### Step 3：生のγ線カウントマップを作成

**使ったコード：** `code/plot_raw_skymap.py`

CSVを読み込み、銀経・銀緯の2次元平面を**1°×1°のマス目**に区切り、各マスに入った光子数を色で表示した。

**出力ファイル：** `data/figure/skymap_raw_*.png`（3枚）

| ファイル | エネルギー範囲 | 光子数 |
|---|---|---|
| `skymap_raw_1-100GeV.png` | 1〜100 GeV | 38,520個 |
| `skymap_raw_1-10GeV.png` | 1〜10 GeV | 37,054個 |
| `skymap_raw_10-100GeV.png` | 10〜100 GeV | 1,466個 |

## 6. 現時点での限界

現在のデータは**10週分（2008年8〜10月）のみ**。  
Totani論文は**15年分（780週）**を使用している。  
統計量が約1/78なので、現時点のマップは荒い。  
→ 次のフェーズでデータを増やす。
