# Totani (2025) 解析における「引き算」の手順

作成日：2026-04-20  
参照：Totani (2025) Section 2.2, 2.3, 3.1, 3.2

---

## 全体の考え方

Totaniの手法は「引き算」ではなく**最尤法フィット（Maximum Likelihood Fit）**。  
γ線マップに映っているものを「既知成分の足し算」でモデル化し、  
それで説明できない余り（残差）を**ハロー成分（ダークマター候補）**として検出する。

```
観測マップ = ①点源 + ②銀河宇宙線(gas) + ③銀河宇宙線(ICS) + ④等方背景 + ⑤ループI + ⑥フェルミバブル + ⑦ハロー成分
```

---

## 各成分の一覧表

| # | 成分名 | 物理的な意味 | テンプレートの作り方 | 備考 |
|---|---|---|---|---|
| ① | **点源**<br>Point Sources | 銀河外天体・パルサーなど個別の明るい天体 | 4FGL-DR4カタログ（14年分の公式カタログ）<br>各天体の位置・スペクトルから計算 | 拡張天体は半径2倍の円でマスク除外 |
| ② | **銀河宇宙線（ガス）**<br>GALPROP gas | 宇宙線陽子が星間ガスに衝突して出るγ線<br>（パイ中間子崩壊 + 制動放射） | GALPROPコード（ver.54）で数値計算 | 銀河面に集中する構造あり |
| ③ | **銀河宇宙線（ICS）**<br>GALPROP ICS | 宇宙線電子が星の光・赤外線・CMBに当たって出るγ線<br>（逆コンプトン散乱） | 同上、光学・赤外・CMBの3成分に分割 | ハローと形が似ているため縮退に注意 |
| ④ | **等方背景放射**<br>Isotropic | 銀河外の未分解天体群・宇宙線の混入 | 全方向一様なテンプレート | 初期値: E²dN/dE = 10⁻⁴ MeV cm⁻² s⁻¹ sr⁻¹ |
| ⑤ | **ループI**<br>Loop I | 太陽近傍の超新星残骸（または銀河中心アウトフロー） | 幾何モデル（半径50〜100pcの2つのシェル） | シェルA・Bを独立パラメータで調整 |
| ⑥ | **フェルミバブル**<br>Fermi Bubbles | 銀河中心から南北に伸びる巨大構造<br>起源未解明（BHジェット説など） | Totani独自手法：4.3 GeVの残差マップから作成<br>正残差テンプレートと負残差テンプレートの2枚 | 解析ステップ①で先に構築（Section 3.1） |
| ⑦ | **ハロー成分**（探索対象）<br>Halo Component | ダークマター対消滅γ線（候補） | NFWプロファイルから計算<br>ρ¹・ρ²・ρ²·⁵ の3種類を試す | 20 GeVに有意なピーク検出（13〜19σ） |

---

## 解析の流れ（ステップ順）

```
Step 1: フェルミバブルテンプレートの構築
  └─ 1.5 GeV と 4.3 GeV の2ビンでフラットテンプレート＋残差フィット
  └─ 4.3 GeV の正残差・負残差マップをテンプレートとして保存

Step 2: 全13ビンでの最尤フィット（銀河面|b|<10°を除外）
  └─ ①〜⑥ を同時にフィットして最適な係数を決定
  └─ 各ビン独立にフィット

Step 3: ハロー成分を加えた再フィット
  └─ NFW-ρ², NFW-ρ¹, NFW-ρ²·⁵ を一種類ずつ追加
  └─ 尤度比でどのプロファイルが最適かを判定

Step 4: 残差の確認
  └─ 「モデル＋残差マップ」で球対称ハロー構造が見えるか確認
  └─ 20 GeVビンで最も顕著
```
