## 授業中の疑問・全回答

### Fermi-LATとは
- 2008年6月打ち上げのFermi衛星搭載γ線望遠鏡
- 構造：①シリコンストリップトラッカー（γ線→電子対変換で方向決定）②CsIカロリメータ（エネルギー測定）③ACD反同時計数シールド（宇宙線除去）
- エネルギー範囲：20 MeV〜300 GeV以上

### Pass 8 Release 3（P8R3）とは
- Passはデータ再構成アルゴリズムのバージョン番号
- 2015年にPass 8で角度分解能・エネルギー分解能・宇宙線除去が大幅向上
- ULTRACLEANクラス = 宇宙線混入を最小化した最高純度データセット

### CSV変換で容量が激減した理由（562MB → 2.57MB、219倍）
1. **フィルタリング**：5,737,716個 → 38,671個（0.67%のみ通過）
   - E < 1 GeV を除外（角度分解能が悪い）
   - 天頂角 ≥ 100° を除外（地球大気のγ線混入防止）
   - ROI外を除外（当時。今後は全天球で保存）
2. **列削減**：23列 → 7列（イベントID・較正バージョン等の不要列を除去）

### 等方背景の信頼度・取得方法
- Fermi-LATで12年分観測した後、既知点源と銀河面拡散放射を除いた残り
- 専用論文：Ackermann et al. (2015), ApJ 799, 86
- 高銀緯（|b|>50°）は銀河拡散放射の影響が極めて小さく信頼度が高い
- **リスク：** 高銀緯にもDM信号（ハロー）が存在するため引きすぎになる可能性あり

### π⁰崩壊 vs 逆コンプトン散乱（ICS）の違い

| | π⁰崩壊 | 逆コンプトン（ICS） |
|---|---|---|
| 必要な粒子 | 宇宙線**陽子** + 星間**ガス** | 宇宙線**電子** + 低エネルギー**光子** |
| 反応 | p + H → π⁰ → 2γ | e⁻ + 光子 → e⁻ + 高エネルギーγ |
| スペクトル | 67.5 MeVにバンプ | べき乗則で高エネルギーまで伸びる |
| 分布 | ガスの濃い銀河面に集中 | 比較的広がる |

### GALPROPとは（名詞の整理）
- **GALPROP = GALactic cosmic ray PROPagation**
- 宇宙線が銀河系内をどう伝播するかをシミュレーションするソフトウェアの名前
- `gll_iem_v07.fits` はFermi公式の「GALPROPベースの拡散放射モデル出力ファイル」
- 正しい用法：「GALPROPモデル」「GALPROPによる伝播シミュレーション」

### 矮小銀河はFermi-LATで観測できるか
- **できる。** Fermi公式チームが多数の矮小銀河でDM探索論文を発表している
- 代表論文：Ackermann et al. (2015), PRL 115, 231301（15個の矮小銀河・6年間）
- Draco, Sculptor, Segue 1, Ursa Minor などが有力候補

### 矮小銀河解析で必要な差し引き成分

| 成分 | 必要か | 理由 |
|---|---|---|
| 等方背景 | ✅ 必要 | 常に存在 |
| 銀河面拡散放射 | △ 状況次第 | 矮小銀河は高銀緯が多く影響小 |
| 既知点源（4FGL） | ✅ 必要 | 点源混入の可能性 |
| フェルミバブル | ❌ 不要 | 天の川銀河中心固有 |
| ループI | ❌ 不要 | 太陽近傍の超新星残骸（局所的） |

天の川解析より**差し引きが簡単**になる。

## 教授の課題

### WIMPsの基本性質（スライド1枚）

| パラメータ | 値・範囲 | 意味 |
|---|---|---|
| 質量 mχ | 〜100 GeV〜10 TeV | γ線スペクトルの形を決める |
| 対消滅断面積 〈σv〉 | 〜3×10⁻²⁶ cm³/s | 信号の強さ（熱的起源の理論値） |
| 対消滅チャンネル | bb̄, W⁺W⁻, τ⁺τ⁻など | スペクトルの形 |
| 電荷 | 0（中性） | 光で見えない理由 |
| スピン | 1/2（フェルミオン） | 標準模型と弱い相互作用 |

Totani (2025) の結果：mχ ≈ 0.5〜0.8 TeV、〈σv〉 ≈ 5〜8×10⁻²⁵ cm³/s（bb̄チャンネル）

### フィッティング係数に関わるDMパラメータ一覧

観測量との関係式：
```
Φ = (1/8π) × (〈σv〉/mχ²) × dNγ/dE × J
```

| パラメータ | 記号 | フィットへの影響 |
|---|---|---|
| DM質量 | mχ | スペクトルカットオフエネルギー |
| 対消滅断面積 | 〈σv〉 | フラックスの絶対値（全体の規格化） |
| 密度分布 | ρ(r)（NFW） | 空間分布の形状→J-factorを決定 |
| J-factor | J = ∫ρ²ds dΩ | 視線方向のDM量。観測との結びつき |
| チャンネル | bb̄など | dNγ/dE（スペクトルの形） |
| ブーストファクター | B | サブハロー構造による増幅（不確かさ大） |
| スケール半径 | rs（NFW） | 密度プロファイルの形 |
