## よく聞かれる質問と答え

### Q1. そもそもダークマターって何ですか？

**答え：**
宇宙の質量の約27%を占めているが、光を出さないので直接見えない未知の物質です。
存在が確認されている根拠は3つあります：

1. **銀河の回転速度**：見える星だけの質量計算では銀河の端が速く回りすぎる（→見えない質量が必要）
2. **重力レンズ**：光が曲がる量が、見える物質だけでは説明できない
3. **宇宙の大規模構造**：銀河が今の形に集まるには、DMがないとシミュレーションが合わない

### Q2. なぜガンマ線でDMを探せるの？

**答え：**
WIMPというDMの候補粒子は、2つが出会うと「対消滅」してエネルギーを放出します。

```
DM + DM → b クォーク + b クォーク
              ↓ 崩壊・ハドロン化
           π⁰（パイ中間子）
              ↓ 即崩壊（10⁻¹⁶秒）
           γ線 + γ線
```

DM質量が0.5〜0.8 TeVのとき、γ線のエネルギーが20 GeV付近にピークを持ちます。
（エネルギーが dm質量の約1/20〜1/40になるため）

### Q3. 20 GeVという値の根拠は？

**答え：**
これは理論計算から来ています。Cirelli et al. (2011)「PPPC 4 DM ID」という論文が、様々なDM質量・チャンネルのスペクトルを計算した標準テーブルです。

- mχ ≈ 0.5〜0.8 TeV でbb̄対消滅 → スペクトルピーク ≈ 20〜40 GeV
- Totaniさんがデータと比較したらこの範囲に一致した

自分でやったと言える根拠：実際にBin6（20.76 GeV）のデータを解析して、その位置にシグナルを確認しました。

### Q5. NFWって何？なぜこの形？

**答え：**
Navarro, Frenk, White（1997）が宇宙シミュレーションから導いたDM密度分布の式です。

```
ρ(r) = ρs / ( (r/rs) × (1 + r/rs)² )
```

- 銀河中心に近いほど密度が高い（r→0でρ→∞）
- 外側に向かってなだらかに減少する
- 球対称（どの方向も同じ形）

DM対消滅のγ線は ρ² に比例するため、銀河中心付近に集中するはず。
→ J-factorマップ（視線積分）はまさに「銀河中心が明るい球対称のもや」の形

### Q6. 31σって本当に正しいの？Totaniさんは13〜19σだけど？

**答え：**
数値の直接比較には注意が必要です。

Totaniさんとの手法の差：
- **Totani：MCMC + Poisson尤度最大化**（より正確な統計）
- **自分：最小二乗法**（簡易実装）

最小二乗法はPoisson尤度より統計量を過大評価しやすいため、31σは過大推定の可能性があります。ただし「有意な正の信号がある」という定性的な結論は一致しています。

これは系統誤差として卒論に明記します。

### Q7. Coma Berenicesで4.54σというのは何か意味があるの？

**答え：**
天の川銀河とは独立した別の天体で、同じ20 GeVに過剰が見えたことに意味があります。

- 発見基準（5σ）には届かないが「兆候」（3σ）は超えている
- もしDMが原因なら、DM密度が高い天体では同じエネルギーで光るはず
- Coma Berenicesは質量/光度比（M/L）が非常に高く、DM支配的な天体

「天の川で31σ + Coma Berで4.5σ」→ 同じDM起源シグナルが複数天体で見えた可能性、という議論ができます。

### Q8. 露出マップって何？なぜ使わなかったの？

**答え：**
Fermi-LATは地球の影に入ったり、特定方向を長く見たりするため、同じ空でも「どれだけ観測したか」が場所によって違います。露出マップはこの不均一性を補正するものです。

使わなかった理由：週単位のFITSファイルから露出マップを別途取得・処理する必要があり、今回は省略しました。これは系統誤差の1つです。

正確な解析では gtexposure（Fermi Science Tools）を使います。

### Q9. 他の矮小銀河ではなぜ検出できなかったの？

**答え：**
主に統計の問題です。

- 矮小銀河は遠い（Draco ≈ 76 kpc）→ 光子数が少ない
- 780週でも各天体の2°内の光子はせいぜい数百〜数千個
- ポアソンノイズが大きく、微弱なDMシグナルに埋もれる

Coma Berenicesだけ4.54σ出たのは、比較的近く（44 kpc）かつM/L比が高いため。
780週フルデータでも統計が足りない→本来はスタッキング解析（複数天体を足し合わせる）が有効。
