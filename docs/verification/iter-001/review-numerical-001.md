### [N-001] W1: l0=0 の 4.96sigma は「NFWが明るい領域を削っただけ」では説明できない (C2を支持)

plot_skymap_all_subtracted.py の nfw_j_map() と同一の求積 (D_SUN=8, RS=21,
s=linspace(0.01,60,150) 矩形則) を PIXEL_DEG=0.125, B_MIN=10 で独立に再実装し、
各除外矩形が含む「halo 幾何重み」(J(l,b)・cos(b) の積分、立体角重み) を計算した。

| l0 | 除外画素比率 | halo幾何重み 除外比率 | 実測sigma |
| --- | --- | --- | --- |
| 0 (本物) | 33.00% | 59.41% | 4.96 |
| +-20 | 33.00% | 45.89% | 14.50 / 15.54 |
| +-30 | 33.00% | 33.05% | 14.34 / 16.06 |
| +-38 | 33.00% | 25.02% | 13.35 / 16.25 |

除外画素数はどのオフセットでも同じ (33.0%、面積は厳密に等しい) だが、halo の幾何学的
重みの除去率は l0=0 が突出して大きい (59.4% 対 他25-46%)。これは物理的論拠 (NFW Jは
l=0で最大) を数値で裏付ける。

問題は「この超過除去率の違いだけで4.96sigmaが説明できるか」。6個の対照点 (l0=0を除く) で
「halo幾何重み除去率 対 実測sigma」の線形回帰を取り (除外なし: 0%, 19.00sigmaを原点として
含む)、l0=0の除去率59.41%を外挿すると予測sigma約13.26。対照点の回帰残差の標準偏差は
1.03sigma。実測4.96sigmaとの乖離は8.3sigma、残差スケールの約8倍。

結論: l0=0の落ち込みは「NFWが明るい領域を削った」という一般的効果で説明できる範囲
(残差スケールプラスマイナス1sigma程度) を遥かに超えている。W1対照実験はC2の
「バブル固有」解釈を統計的に裏付ける。Managerが懸念した「NFW明るさの交絡」を数値的に
排除できている。
(近似: 露出マップと点源マスクは含めず、J・cos(b)の幾何重みのみを使用。除外画素数が
w1-control-sweep.mdの実測値 (252926-253371) と0.2-0.4%差で一致しており、この近似が
十分妥当であることを確認した。)

さらに補強材料: f_icsの挙動 (w1-control-sweep.md 項目4) を検算すると、baseline
f_ics=0.605 (真値からの乖離40%) に対し、対照オフセット (l0=プラスマイナス20,30,38) は
いずれもf_ics=0.46-0.79 (乖離21-54%、baselineと同程度かそれ以上に悪い) だが、l0=0だけ
f_ics=1.025 (乖離2.5%) と唯一物理的な値に戻る。同じ33%の画素を削っても本物のバブル
位置でしかICS-halo-バブル縮退が解消しないという事実は、「単に統計情報を減らしただけ」
という帰無仮説と非整合。この2つの独立した数値的証拠 (sigma外挿の8sigma乖離、f_icsの
一意な正常化) は、Manager自身がw1-control-sweep.md item3で挙げた「振幅が23%しか
下がらないので汚染解釈が弱まるかもしれない」という懸念に対する反証になる。振幅ではなく
「haloパラメータを制約する統計的レバレッジ (バブル領域特有の縮退解消)」が失われたことが
sigma崩壊の主因であり、これは依然として「バブル領域のテンプレート引き残しが根本原因」
というC2の物理的主張と整合する。

C1/C2のどちらに効くか: C2 (直接支持)。W1合格。
headline撤回は不要。ただし「バブルを外すと信号が消える」ではなく「バブルを外すと
haloを制約する統計的レバレッジとICS-halo-バブル縮退の解消が失われ、sigmaが不釣り合いに
落ちる」という機序の記述に修正すべき (下記N-002も参照)。

## 最終判定

C1: 注記付き維持 (実質的には撤回に近い)。headline「7-170 GeV全ビンで2.2-5.7sigma有意」は、
帰無分布補正 (N-002, 標準偏差1.362で除算) を適用すると大半が系統誤差の天井 (4.50sigma)
以下に沈み、単独では検出の証拠にならない。収束良好なビンは10/13 (Bin2,4,13は使用不可、
N-003)。「A/Cでhalo規格化が食い違う」という定性的傾向自体はC2 (N-001) と整合し実在する
