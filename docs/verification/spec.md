## 検証対象 (3つの主張)

### C1. 領域 A/C で halo 規格化が有意に食い違う

- 実装: `code/diagnose_regionAC_lrt_v20.py` (新規)
- 結果: `results/regionAC_lrt_v20_fullroi/regionAC_lrt_v20.json`
- 主張: 背景成分 (f_iso/f_gas/f_ics/f_ps/Loop I/バブル正負) を領域 A・C で共有し、
  f_halo のみ領域別にすると、**7-170 GeV の全ビンでバブル内が外の 1.3-11 倍**大きく、
  尤度比検定で **2.2-5.7σ** 有意。Bin6 (20.76 GeV) は A=1.368 / C=1.003、2.89σ。
- 領域定義: A = 10°セル中心が矩形 |l|<22°, 10°<|b|<55° の内側 (実効 |l|<20°, 10°<|b|<50°、
  32セル)。C = それ以外の有効セル (88セル)。A ∪ C = v20 の ROI 全体。
- 物理的論拠: 真の球対称 NFW なら視線積分 J の方向依存は j_map に折り込み済みなので、
  同じ物理ハローなら領域によらず同じ f_halo が出るはず。

### C2. バブル領域を除くと Bin6 が 19.11σ → 4.96σ

- 実装: `code/mcmc_fit_all_bins.py` に環境変数 `MCMC_EXCLUDE_BUBBLE` を追加 (既定 OFF)
- 結果: `results/mcmc_allbins_gasICS_v22_nobubble/mcmc_bin*.json`
- 主張: バブル矩形を尤度から外すと Bin4 16.23→5.13、Bin5 19.70→3.67、
  **Bin6 19.11→4.96**、Bin7 14.90→1.51、Bin8 10.94→2.94σ。超過は消えないが大幅に減る。

### C3. 矮小銀河では天の川の主張を検定できない

- 実装: `code/dwarf_consistency_check.py` (新規)
- 結果: `results/dwarf_consistency/dwarf_consistency.json`
- 主張: 対消滅フラックス F = (<σv>/(8π m²))·dN/dE·J において、天の川と矮小銀河で
  同じ粒子・同じエネルギービンを見る限り比を取ると粒子物理量が相殺し
  **F_dwarf/F_MW = <J>_dwarf/<J>_MW** となる。この比で予測すると、天の川の超過が
  DM 起源でも矮小銀河の期待信号は **45天体合算で 2.69σ** (実測 −0.18σ)。
  したがって非検出は DM 仮説と矛盾せず、**否定も肯定もできない**。

## Manager が自覚している弱点 (最低限ここは判定すること)

| # | 弱点 | なぜ問題か |
| --- | --- | --- |
| **W1** | **C2 に等面積の対照実験が無い** | バブル領域は銀河中心方向で NFW テンプレートが最も明るい。同面積の別領域を外しても同程度 σ が落ちるなら、C2 は「バブルのせい」を何も示していない。**最重要** |
| W2 | σ が名目値 | 2026-07-31 に本パイプラインの帰無分布が N(0,1) でないと実測済み (空領域で標準偏差 1.362)。C1/C2/C3 の σ はこの補正をしていない |
| W3 | C3 の誤差推定が粗い | 実測フラックスの 1σ 誤差を `err = |flux / significance|` で代用している。Gauss 近似が崩れる領域での妥当性が未検証 |
| W4 | C3 の J 較正の形状依存 | Pace & Strigari (2019) の J(0.5°) は彼ら自身の NFW fit に対する値。本実装はそれを、LVDB の rhalf 由来 rs・切断 10rs という**別形状**の ρ_s 較正に流用している |
| W5 | C3 の天の川 J の整合性 | `<J>_MW` に Via Lactea II (ρ_s=8.1e6 M☉/kpc³) を使っているが、v20 の halo テンプレートの絶対規格化は `calibrate_nfw_norm()` が Totani Fig.8 の1点で較正している。この2つが整合しているか未確認。不整合なら C3 の予測は系統的にずれる |
| W6 | C1 の領域分割がセル単位 | 10°セル境界と矩形境界が一致しないため、実効的な領域 A が名目と異なる (|l|<20°, 10°<|b|<50°)。この近似の影響が未評価 |
| W7 | C1 の Wilks 適用 | f_halo は符号自由なので境界問題は無いはずだが、df=1 の χ² 漸近が成立する条件を満たしているか未検証 |

## 合格条件

1. **C1/C2/C3 それぞれについて、主張が数値的に再現できるか**を独立に確認する
   (JSON を読むだけでなく、必要なら計算を再実行・別解法で検算する)
2. **W1 の対照実験を実際に行う**か、行えない場合はその旨と代替の判定根拠を示す
   - 具体案: バブル矩形と**同面積・同緯度帯**の領域 (例: 経度をずらした |l−ℓ0|<22°)
     を外した場合の Bin6 有意度を測り、4.96σ と比べる
   - `MCMC_EXCLUDE_BUBBLE` と同じ機構で経度オフセット可能にする実装を含んでよい
3. **W2-W7 のそれぞれに CRITICAL / IMPORTANT / MINOR の重み付け**を与え、
   headline 主張 (C1/C2/C3) を撤回すべきか、注記付きで維持できるかを判定する
4. 物理レビュアは特に **C1 の物理的解釈** (「球対称 NFW 仮説の棄却」と言ってよいか、
   それとも「NFW 形状が違うだけ」「バブルテンプレートの引き残し」など別解釈が
   同等に成立するか) を判定する
5. 数値レビュアは特に **収束診断の妥当性** を判定する。`fun_spread` が 1e-6 未満なのは
   13ビン中 3-4 ビンのみで、Bin13 は 4.0 と極端。どのビンの数値を使ってよいかを明示する
6. 判定は数値と根拠で述べる。「おそらく」「と思われる」で終わらせない
