# lvdb_dwarf_mw.csv — 出典

Local Volume Database (LVDB) の「天の川の矮小銀河」テーブル。

- 論文: Pace, A. B. (2025), "The Local Volume Database: a library of the observed
  properties of nearby dwarf galaxies and star clusters",
  The Open Journal of Astrophysics 8, 142. arXiv:2411.07424
- 取得元: https://raw.githubusercontent.com/apace7/local_volume_database/main/data/dwarf_mw.csv
- 取得日: 2026-07-31

**使う列**: `key`, `name`, `ra`, `dec` [deg, ICRS], `distance` [kpc],
`rhalf` [arcmin, 半光度半径], `confirmed_real`, `confirmed_galaxy`

ネットワークに依存せず再現できるよう、リポジトリ内に取り込んでいる。
更新する場合は取得日を書き換えること。
