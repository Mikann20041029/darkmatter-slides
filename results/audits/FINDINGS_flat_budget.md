# 平坦成分 (等方 + Loop I) の欠損 — 解明から解決まで

対象コミット: v17 (`db408ff`) の結果 `results/mcmc_allbins_gasICS_v17_nfwcal/`
診断スクリプト: `code/diagnose_iso_collapse.py` / `diagnose_iso_thief.py` /
`diagnose_flat_budget.py` / `audit_loopi_geometry.py`

## 結論(先頭)

1. **等方成分と Loop I は原理的に分離できない。** Loop I shell1 は太陽が殻の壁の中
   (r_in=62 < d=78 < r_out=81 pc) にあるため ROI の 100% を覆い、緯度変化 1.47 倍 =
   **等方テンプレ (1.74 倍) より平坦**。データが決めるのは**合算だけ**。
   → **単独の比 (iso 0.42 / Loop I 0.59) を議論してはいけない。合算 0.50 が正しい指標。**
2. **その合算が Totani の約半分しかない分は、バブル正テンプレートが持っている。**
   バブル正を外すと合算比は 0.55→0.90 (Bin1) / 0.43→0.85 (Bin3) / 0.56→1.04 (Bin6) /
   0.73→1.38 (Bin8) と**ほぼ 1 に復帰**する。
3. **主結果 (20 GeV の halo) はこの問題の影響を受けない。** 下表のとおり Bin6 の f_halo は
   バブルを丸ごと外しても 1.48 → 1.30〜2.39 の範囲に収まる。
   一方 **低E (Bin1/Bin3) の halo は符号すら反転**し、まったく頑健でない。

## 経緯 (何を測って何が分かったか)

### Step 1: iso の崩壊は縮退か、本当の矛盾か

f_iso を Totani 値に固定して再フィットし ΔlnL を測った (`diagnose_iso_collapse.py`)。

| bin | E [GeV] | ΔlnL | σ 相当 |
| ---: | ---: | ---: | ---: |
| 1 | 1.51 | 336.3 | 25.9 |
| 2 | 2.55 | 219.6 | 21.0 |
| 3 | 4.31 | 64.2 | 11.3 |
| 6 | 20.76 | 1.0 | 1.4 |

→ 平らな谷ではない。低E に限って本当の矛盾がある。

### Step 2: 席を奪っているのは誰か (leave-one-out)

成分を1つずつ外して f_iso が戻るか (`diagnose_iso_thief.py`)。

| 条件 | Bin1 | Bin2 | Bin3 | Bin6 |
| --- | ---: | ---: | ---: | ---: |
| 自由 (基準) | 0.000 | 0.000 | 0.000 | 0.656 |
| **Loop I を外す** | **1.431** | **1.327** | **1.392** | **1.538** |
| バブル負を外す | 0.000 | 0.000 | 0.034 | 0.598 |
| gas を 1 に固定 | 0.000 | 0.000 | 0.180 | 0.764 |
| halo を外す | 0.000 | 0.000 | 0.000 | 0.546 |
| 点源を 1 に固定 | 0.093 | 0.000 | 0.161 | 0.782 |

→ Loop I だけが iso を復活させる。幾何を検査 (`audit_loopi_geometry.py`) すると
shell1 は **太陽が殻の壁の中**にあり ROI 全域を覆う、等方より平坦なテンプレだった。
**実装は Totani §2.3 の記述どおりであり、バグではない。論文の模型が持つ性質。**

### Step 3: では合算予算はどこへ (`diagnose_flat_budget.py`)

指標を「iso + Loop I の物理フラックス合算 / Totani 合算」に変えて leave-one-out。

| 条件 | Bin1 | Bin3 | Bin6 | Bin8 |
| --- | ---: | ---: | ---: | ---: |
| 自由 (基準) | 0.551 | 0.432 | 0.563 | 0.729 |
| **バブル正を外す** | **0.899** | **0.854** | **1.035** | **1.377** |
| バブル正負とも外す | 1.093 | 1.005 | 1.127 | 1.367 |
| バブル負を外す | 0.578 | 0.457 | 0.541 | 0.647 |
| gas を 1 に固定 | 0.580 | 0.498 | 0.586 | 0.726 |
| ICS を 1 に固定 | 0.716 | 0.539 | 0.467 | 0.439 |
| 点源を 1 に固定 | 0.648 | 0.515 | 0.636 | 0.818 |

→ **バブル正テンプレートが平坦成分の予算を持っている。**

### Step 4: なぜバブル正が平坦成分を持つのか

バブル正テンプレは **ROI の 65% を覆い、総量の 42.5% がバブル矩形の外側**にある
(矩形の面積比は 33%、集中度はわずか 1.73 倍)。
Totani §3.1 は "the positive flux regions are **dominated by the Fermi bubbles**" と
**前提として述べている**が、**本実装の地図はその前提を満たしていない**。

矩形の外側での |b| 依存を測ると 1.32 / 1.00 / 0.92 / 0.71 / 1.04 で、
等方テンプレ (1.27 / 1.18 / 1.05 / 0.90 / 0.69) とほぼ同じ = **平坦な下駄**である。

## 試したが効かなかった修正 (記録)

**構築フィットで A_iso を Totani §2.3 の 1e-4 相当に固定する** (`MCMC_CONSTRUCT_ISO_FIXED=1`)。

- 動機: 構築フィットで A_iso が下限 0 に張り付き、代わりに GALPROP が
  A_gas=1.43 / A_ics=1.55 と 1.5 倍に膨らんでいた。平坦な成分を急な成分で代用すれば
  高緯度に取り残しが出て、それが残差 → バブル正テンプレに焼き込まれる、と考えた。
- **結果: ほぼ効果なし。** 正テンプレの矩形内割合 57.5% → 57.2%、集中度 1.74 → 1.73。
- 論文は等方を自由パラメータとしているので、**効果が無い以上わざわざ逸脱する理由が無い**。
  既定は 0 (論文どおり自由) に戻した。実装はフラグとして残し再現できるようにした。

## 下駄の正体 (ポアソン雑音ではない)

平滑化後の残差 rms を、同じカーネルで伝播させたポアソン雑音の期待値と比べた。

| 領域 | 実測 rms | 期待ポアソン雑音 | 実測/雑音 |
| --- | ---: | ---: | ---: |
| バブル矩形の内側 | 3.12e-11 | 3.22e-11 | 0.97 |
| バブル矩形の外側 | 4.20e-11 | 2.67e-11 | **1.57** |

→ 矩形外の構造は**雑音では説明できない実在の残差** (1.57 倍)。
すなわち **10° セル尤度では拘束されないセル内スケール (1〜10°) で、
拡散モデル (GALPROP 等) がデータとずれている**。その半分が「正の残差」として
バブルテンプレートに取り込まれ、全エネルギーへ伝播している。

## 解決 (何を変えたか)

**(1) 比較のしかたを正した。** `code/plot_component_overlay_vN.py` に
**等方 + Loop I の合算比**を黒の太線で追加し、単独の比は「データから決まらない量」と
図中に明記した。合算比の中央値は **0.50**。

**(2) 数値の解釈規約を正本に記録した。** `.dev/METHOD_DECISIONS.md` P8 /
`.dev/TOTANI_SPEC.md` §3.7a。**卒論・発表では iso と Loop I を必ず合算して示す。**

**(3) 残る不一致の所在を特定・限定した。** 「等方成分が 1/200 に潰れている」という
当初の症状は消滅し、**「セル内スケールの拡散モデル残差の正の半分が、経験的バブル
テンプレートに取り込まれ、平坦成分の予算を約半分持って行っている」**という、
はるかに限定された記述に置き換わった。これは **Totani の手法自体が持つ性質**であり
(彼も同じ手順を使う)、拡散モデルを改善しない限り消えない。

## 主結果への影響 (重要)

各 leave-one-out 条件での f_halo の変動 (点推定、基準比):

| 条件 | Bin1 | Bin3 | **Bin6** | Bin8 |
| --- | ---: | ---: | ---: | ---: |
| バブル負を外す | −0.11 | 2.32 | **1.13** | 1.11 |
| バブル正を外す | 0.10 | 2.56 | **1.27** | 1.21 |
| バブル正負とも外す | −2.00 | 5.37 | **1.61** | 1.51 |
| gas を 1 に固定 | 0.63 | 2.03 | **1.15** | 1.21 |
| ICS を 1 に固定 | −0.48 | 2.21 | **0.88** | 0.80 |
| 点源を 1 に固定 | 0.79 | 1.20 | **1.02** | 1.01 |

- **Bin6 (20.8 GeV、主結果) は 0.88〜1.61 倍に収まり頑健。** バブルテンプレートを
  丸ごと外しても壊れない。
- **Bin1 / Bin3 (低E) は符号が反転するほど不安定。**
  → **低エネルギー側の halo 値は卒論の主張に使えない。** 20 GeV ピークのみを主張し、
  低E は「モデル依存性が大きく決定不能」と明記するのが正しい。
