# 低E で等方成分が潰れる問題 — 原因の確定

対象: v17 (`results/mcmc_allbins_gasICS_v17_nfwcal/`)
参照値: Totani Fig.6 の**機械読み取り** (`code/digitize_totani_fig6.py`, commit eb94cf3)

## 結論(先頭)

**ずれているのはバブル残差テンプレートだけである。** 全成分を Totani Fig.6 と直接比べると、
gas・ICS・点源・Loop I はいずれも **20% 以内**で一致する。**バブル正が 1.3〜1.6 倍、
バブル負が 1.6〜2.1 倍明るく**、その超過分を等方成分が払わされて 0 に潰れている。

## なぜバブルが明るすぎるのか

バブルテンプレートは「データ − (バブル以外の全成分)」の残差を σ=1° で平滑化し、
正負に分けて作る**データ駆動**のテンプレートである。したがって
**拡散モデルが説明しきれなかった分がそのままテンプレートに入る**。

測定した事実:

1. **正テンプレは ROI の 65% を覆い、総量の 42.5% がバブル矩形の外側**にある
   (矩形の面積比は 33%、集中度はわずか 1.73 倍)。
   Totani §3.1 は "the positive flux regions are **dominated by the Fermi bubbles**" と
   **前提として**述べているが、本実装の地図はその前提を満たしていない
2. **その台座はポアソン雑音ではない**。平滑化後の残差 rms を、同じカーネルで伝播させた
   ポアソン雑音の期待値と比べると、バブル矩形の**内側 0.97 倍**に対し**外側 1.57 倍**。
   すなわち矩形外には**実在の構造**がある
3. **10° セル尤度では 1〜10° スケールの残差が一切拘束されない**。その正の半分が
   「バブル正」、負の半分が「バブル負」として全エネルギーに伝播する

## 棄却した仮説 (すべて実測で否定)

| 仮説 | 検定 | 結果 |
|---|---|---|
| 参照値 (Totani 側) の読み取り誤り | Fig.6 を機械読み取り (commit eb94cf3) | **一部当たり** (ICS 高E が 5.0 倍誤り)。**ただし iso の比は 0.006 のまま**。棄却 |
| iso と Loop I の縮退が原因 | Loop I を外す leave-one-out | 「片方を外せば他方が肩代わりする」だけで、原因の説明にならない。**論証として不成立** |
| 構築フィットで A_iso が 0 に潰れているのが原因 | A_iso を Totani §2.3 の 1e-4 相当に固定 | 正テンプレの矩形内割合 57.5% → **57.2%**。**効果なし**。棄却 |
| GALPROP の緯度形状のずれが原因 | gas/ICS に緯度傾き 1 パラメータ `T'(b)=T(b)(1+a(\|b\|−35°)/25°)` を追加 | 最良の a でも **iso は 0.000 のまま**、ΔlnL の改善は 16.6 / 26.1 / 0.0 (iso 固定の罰則 336 / 220 / 64 に遠く及ばない)。**棄却** |

## 残る打ち手と、その可否

| 案 | 可否 |
|---|---|
| 拡散モデル (GALPROP) を改善して残差を減らす | **不可**。GALPROP webrun は停止中で、教授提供の出力が唯一。Totani 本人の出力は入手不能 |
| バブルテンプレをバブル矩形の近傍に限定する | **Totani §3.1 の明示的な指示に反する** ("regardless of whether it is inside or outside the boundaries")。再現から外れるので採らない |
| 系統誤差として明記する | **採る**。低E の等方成分と halo は「モデル依存性が大きく決定不能」と書く |

## 主結果への影響

**20 GeV (Bin6) の halo は影響を受けない。** バブルテンプレを丸ごと外しても f_halo は
基準比 0.88〜1.61 倍の範囲に収まる (`results/audits/flat_budget_*/`)。
一方 **Bin1/Bin3 は条件により符号が反転**するので、**低エネルギー側の halo 値は主張に使えない**。
