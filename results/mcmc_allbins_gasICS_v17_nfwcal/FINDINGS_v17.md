# v17 所見 — NFW 規格化の基準点を b = 90° に修正

再現コマンド (v16 と `MCMC_ALLBINS_OUTDIR` 以外は同一):

```bash
MCMC_ULTRACLEAN=1 MCMC_PIXEL_DEG=0.125 MCMC_DISK_BUBBLE=1 MCMC_CELL_LIKELIHOOD=1 \
  MCMC_SIGNFREE_HALO=1 MCMC_ALLBINS_OUTDIR=results/mcmc_allbins_gasICS_v17_nfwcal \
  python code/mcmc_fit_all_bins.py
```

## 結論(先頭)

NFW ハローの絶対規格化の基準点を、**ROI 内の最高緯度画素 (b = −59.9375°) から
論文どおりの b = 90° (銀河北極) に修正**した。目盛りは 2.10 倍変わったが、
**物理結果は完全に不変**であることを全13ビンで実測確認した。

| | 旧 (v16 まで) | 新 (v17) |
|---|---|---|
| 基準点 | b = −59.9375°(ROI 端で代用) | **b = 90°**(Totani Fig.8 と同じ) |
| J(視線積分 ρ²) | 29.365 | **13.964** |
| NFW 規格化定数 | 2.316e-15 | **4.872e-15** |

## なぜ基準点がずれていたのか

Totani Fig.8 は b = 90° での値 (21 GeV で E²dN/dE ≈ 3e-5 MeV cm⁻² s⁻¹ sr⁻¹) を与える。
一方 ROI は |b| ≤ 60° なので **b = 90° の画素は配列に存在しない**。
旧実装 `jb_ref = np.argmax(np.abs(B_C))` は「手持ちで最も高緯度の画素」で代用していた。
**意図的な逸脱ではなく、論文の基準点が地図の外にあったことによる代用**である。

修正は `nfw_j_los(l, b)` を新設し、b = 90° の視線積分を直接計算するだけで済む
(画素が無くても積分自体は計算できる)。マップと**同一の求積**
(s = 0.01〜60 kpc を 150 分割の矩形則) を使い、目盛りをマップと揃えている。

## 不変性の実測検証 (`code/audit_nfw_calibration_invariance.py`)

ハローの寄与は常に `f_halo × norm × j_map` の積の形でしか現れないため、
norm が c 倍になれば f_halo が 1/c 倍になり予測カウントは変わらない、というのが主張。
**これを主張で終わらせず、v16 と v17 の全13ビンを突き合わせて確認した**
(結果全文: `INVARIANCE_CHECK.txt`)。

- **有意度の変化: 全13ビンで 0.0000σ**(点推定は L-BFGS-B でスケール同変なので厳密に不変)
- **f_halo の変化率は全ビンで期待値 J_new/J_old = 0.4755 に一致**
- 中央値の残差は相対で最大 3.7%(Bin2)だが、**事後分布の幅を単位にすると最大 0.076**、
  すなわち 1σ の 8% 未満。**MCMC のサンプリング揺らぎの範囲**である
  (残差が大きいのは Bin2 / Bin12 / Bin13 = 有意度 1.2〜1.8σ の、f_halo がほぼ 0 で
   事後分布が広いビンに限られる。相対 % で判定してはいけない典型例)
- 成分比 (本研究/Totani 中央値) も不変: gas 0.89→0.88, ICS 0.92→0.94, iso 0.42→0.42,
  Loop I 0.59→0.59, **halo 1.19→1.19**

## 追記: iso の「0.42 倍」は中央値が実態を隠していた

分解したところ、**中央値 0.42 は 2 つのまったく別の症状を平均していた**と判明した。

- **低E 3 ビン (1.5 / 2.5 / 4.3 GeV) だけ桁で潰れている**。「少し低い」ではなく事実上ゼロ。
- 中〜高E (Bin4–9) は 0.32〜0.65 で、これは別の (軽い) 症状。
- **iso が潰れているビンと halo が負になるビンが一致する**。等方成分 (一様) と halo
  (なだらかに広がる) は形が似ており奪い合いになりやすい。
  「iso が 0 に潰され、その分をどこかが過剰予測し、halo が負で打ち消す」という
  縮退の機序が疑われる。**次に検証すべき最有力仮説**。

## 図が食い違いを隠していた問題を修正した

`code/plot_component_overlay_vN.py` の表示レンジが、**最大の食い違い 3 つを全部フレームの
外に追い出していた**。ユーザの「そこまで大きいずれは見えない」という所見は、図の設定に
起因していた。修正内容:

1. 上段の縦軸下限 3e-6 → **3e-7** (iso の Bin1–2 = 1.5e-6 が枠外だった)
2. 下段 (比) の縦軸 0.05〜12 → **0.002〜30** (iso 比 0.005 が枠外だった)
3. **負の値を「絶対値 + 破線 + ×印」で明示**する (log 軸に負は描けず、
   従来は線が黙って消えるだけだった。halo が Bin1–2 で負)

**「線が消えている」= 有意度が低い、ではない**点に注意。Bin1 は σ = 20.9 で全13ビン中最大
であり、消えていたのは値が負だったからである。

## 発表・卒論での注意

**`f_halo` の値そのものには絶対的な意味が無い**(目盛りの取り方で変わる)。
v15 までの記録にある「Bin1 で f_halo = −354.8」のような数値は、
**その大小を物理的な議論に使ってはいけない**。物理的に意味があるのは
`f_halo × norm × j_map` の積、すなわち成分スペクトル図に描かれている
物理フラックスと、有意度である。
