# v18 (§3.4.2 系統チェック) — 等方成分を潰していた犯人の確定

再現コマンド (v17 に `MCMC_FB_FLAT=1` を足しただけ):

```bash
MCMC_ULTRACLEAN=1 MCMC_PIXEL_DEG=0.125 MCMC_DISK_BUBBLE=1 MCMC_CELL_LIKELIHOOD=1 \
  MCMC_SIGNFREE_HALO=1 MCMC_FB_FLAT=1 \
  MCMC_ALLBINS_OUTDIR=results/mcmc_allbins_gasICS_v18_flatbubble \
  python code/mcmc_fit_all_bins.py
```

## 結論(先頭)

**構造ありのバブル正残差テンプレートが等方成分を吸っていた。** Totani §3.4.2 の系統チェック
(正残差テンプレを**単純な平坦テンプレ**に置き換える) を実施すると、**等方成分が復活する**。
相関ではなく**介入実験による因果の確認**である。

| bin | E [GeV] | iso/Totani (v17) | **iso/Totani (v18)** |
| ---:| ---:| ---:| ---:|
| 1 | 1.51 | 0.006 | **0.270** |
| 2 | 2.55 | 0.007 | **0.099** |
| 3 | 4.31 | 0.039 | **0.517** |
| 4 | 7.28 | 0.367 | **0.853** |
| 5 | 12.29 | 0.425 | **0.825** |
| 6 | 20.76 | 0.524 | **0.955** |
| 7 | 35.06 | 0.530 | **1.136** |
| 8 | 59.22 | 0.493 | **0.848** |
| 9 | 100.0 | 0.508 | **1.167** |

中央値は **0.43 → 0.85**。Bin4–9 では **0.83〜1.17** と Totani とほぼ一致する。

## ただし v18 は headline にはできない

低エネルギー側で σ が桁で爆発する (Bin1 199σ)。平坦テンプレでは低E の空間構造を
説明できず、その分を halo が (負で) 肩代わりするため。**採用できる構成ではない。**

## Totani との違い (重要)

Totani §3.4.2: baseline 13–19σ → 平坦テンプレ置換で **9.1σ に減少**。
本研究: baseline 19.04σ → 平坦テンプレ置換で **20.32σ とほぼ不変(微増)**。

f_halo 自体は 1.479 → 1.359 と**減少**しており、
"The halo component has decreased compared to the baseline analysis" という
Totani の記述とは整合する。σ が下がらないのは**負残差テンプレの振る舞いが異なる**ためと
考えられるが、未検証。

## この結果が意味すること

1. **低E の等方成分崩壊の原因は、構造ありバブル正テンプレートで確定した** (介入で回復)
2. そのテンプレートは**データ駆動**なので、拡散モデルが説明しきれない残差を吸い込む。
   実測でも Totani の 1.3〜2.1 倍明るく、ROI の 65% を覆い総量の 42.5% がバブル矩形の外側
3. **しかし平坦テンプレに置き換えるのは代償が大きすぎる** (低E で σ が桁で悪化)。
   Totani の baseline も構造ありテンプレを使っているので、**baseline は v17 のまま**とする
4. v18 は **Totani §3.4.2 と同じ系統チェックとして卒論に載せる**のが正しい位置づけ
