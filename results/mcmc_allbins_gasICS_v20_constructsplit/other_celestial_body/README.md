# other_celestial_body — 他天体への v20 手法の適用 (79 箇所の統計検証)

天の川の baseline (v20) と**同じ選別・同じ成分・同じ尤度**で、多数の天体と
「何も無い対照領域」に NFW-ρ² ハローを当てた結果。

## 対象 (79 箇所)

| 区分 | 数 | 出典 |
| --- | --- | --- |
| 天の川の矮小銀河 | 54 | Local Volume Database (Pace 2025, OJAp 8 142; arXiv:2411.07424) の確認済み銀河。LMC/SMC を含む |
| 近傍銀河 | 2 | M31 (Tamm+2012 の R₂₀₀≈200 kpc と c=13 → rs=15.4 kpc) / M33 (Corbelli+2014 の M₂₀₀=3e11 M⊙ と c=8 → rs=17.1 kpc) |
| 対照フィールド | 23 | 既知の標的が無い無作為の領域。\|b\|>20°、互いに 20° 以上離して ROI を重ねない |

**主結果は 1° セルに束ねた尤度**を使う (このディレクトリ直下)。画素単位 (0.125°) 版は
`systematics_pixel0125deg/` に置く。理由は下の「なぜ 1° セルが主結果なのか」を参照。

## 結論 1: どこにも検出は無い

使用可能な 77 天体 x 13 ビン = **833 個の有意度のうち最大は +3.46σ** (矮小銀河)。
天の川の 19.1σ とは桁が違う。

## 結論 2: この手法の名目 σ は、実データでは σ ではない

対照フィールド (空の領域) 23 箇所・250 個の有意度の実測:

| 指標 | 実測 | 期待 (N(0,1)) |
| --- | --- | --- |
| 平均 | **-0.021** | 0 |
| 標準偏差 | **1.362** | 1 |
| \|σ\| > 2 の割合 | **12.0%** | 4.6% |
| \|σ\| > 3 の割合 | **2.4%** | 0.27% |
| **最大** | **+4.50σ** | — |

**平均は 0 で偏りが無いが、分布は N(0,1) より 1.36 倍広い。**
合成データでの較正 (`results/audits/target_fit_calibration_*/`) では N(0,1) と一致したので、
**この広がりは統計ではなく実データの系統誤差 (拡散モデルの誤差・点源の消し残り) の床**である。

**空の領域で +4.50σ が出ている。** 3σ 超えは期待の 9 倍の頻度で起きる。
この手法で得た σ を額面どおりに読んではいけない。

## なぜ 1° セルが主結果なのか (画素単位には偏りがある)

画素単位 (0.125°) で尤度を組むと、**対照フィールドの平均 σ が -0.401 に偏る**。
原因は小計数アーティファクトである: 20 GeV では 1 画素あたりの事象数が 0.10 しかなく、
中心付近の画素はほとんど「0 個」になる。ポアソン尤度はゼロ観測の画素で予測値を下げたがり、
**中心だけを下げられる成分は符号自由なハローしかない**ため、ハローが系統的に負へ倒れる。

検証 (`results/audits/target_null_bias_20260731/`):

| 束ね方 | 平均 | 標準偏差 |
| --- | --- | --- |
| 画素単位 (0.125°) | -0.401 | 1.141 |
| **1° セル (主結果)** | **-0.021** | 1.362 |

偏りはエネルギーとともに強まる (1.5 GeV で +0.10、20.8 GeV で -0.58、35 GeV で -0.80)。
1 画素あたりの事象数と対応する。PSF 幅を ±30% 振っても、背景の非負拘束を外しても変わらない。

**天の川の解析 (v20) は 10° セルなので、この問題は起きない** (1 セルに数千個入る)。
Totani がセル束ねを採用している理由が実測で裏付けられた形である。

## 数値の作り方

```bash
python code/apply_v20_method_targets.py \
  --out results/mcmc_allbins_gasICS_v20_constructsplit/other_celestial_body
```

- 入力: `data/CSV/allsky_events_ultraclean.csv` (全天 UltraClean 779/780 週・3,555 万事象)
  と `data/fermi_exposure/expmap_targets.npz` (6 天体 ROI の露出、同 779 週)
- 成分: `f_iso·IGRB + f_gas·gas + f_ics·ICS + f_ps·点源 + f_halo·NFW-ρ²`
  (フェルミバブルと Loop I は銀河中心の構造なので入れない)
- 画素 0.125°、ROI は接平面投影の半径 10°、f_halo は符号自由

## 読むときの注意

1. **矮小銀河は、この手法では点源と区別できない。** θ_s = 0.20–0.39° は PSF より小さく、
   PSF 畳み込み後の 68% 収容半径はいずれも 0.198° で同じ位置の点源と一致する。
   形状フィットに意味があるのは M31 だけ (0.442°)
2. **M31 の低エネルギー側の負値 (Bin1 −5.34σ / Bin2 −5.82σ) は系統誤差**。
   M31 自身の 4FGL 天体を点源として置いたことによる (M31 の放射は実際には円盤起源で
   広がっており、点源だと中心に集中しすぎる)。点源から外すと −1.20σ / −2.51σ まで落ちる。
   **20 GeV には影響しない**ので主結果は変わらないが、低E の値は主張に使えない
3. **事象数 20 未満のビンは解釈しない**。図では白抜きマーカーで区別している
4. **f_halo の数値を天体間で比べない**。ρ_s = 1 に規格化しているので、
   f_halo は「その天体の ρ_s² に比例する量」でしかない
